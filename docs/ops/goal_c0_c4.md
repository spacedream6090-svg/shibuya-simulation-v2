## 短縮投入形(リモートコントロール等で長文を貼れないとき)

評価器は会話に表示された内容だけを判定するので、条件文をファイル参照にし、親が最初のターンで全文を会話に表示する。

```text
/goal docs/ops/goal_c0_c4.md のコードブロック内の条件文(Claudeが最初のターンで全文を会話に表示する)をすべて満たす。停止句に該当して停止した場合も達成とみなす。or stop after 200 turns
```

## 開始前チェック(ユーザー側・一度だけ)
1. Claude Code が 2.1.234 以上であること(09-08時点: CLI 2.1.263・VS Code拡張 2.1.263=済み)。
2. PCのスリープを無効にし、VS Code(セッション)を開いたままにする。約30分超のスリープで自動継続が「Enter待ち」になる。
3. 自動モード(権限プロンプトが出ると止まる)。
4. (任意)`/usage-credits` で使用量クレジットを有効にすると制限待ちが発生しない(有料・ユーザー判断)。
5. 週次制限(リセットが24時間超先)は自動で待たない=手動再開が要る。
