## 読み方
1. **制約違反の半分は無信号**: ⑥の45場面は拘束的制約(所持金・営業時間・条例)を含まない設計だったため違反率は全変種0。制約半分の判定には①(制約つき8場面)のv0/v1変種が必要(未測定・48呼で可)。
2. **行動分布の半分**: 8B・32Bは v0→v1 で分布が変わらない(JSDが帰無の中央値並み)。**14Bは変わる**が、内訳は plain(答えが決まらない場面)0.342・tail 0.235 に集中し、**mid(答えが決まる場面)は0.009=不変**。つまり14Bのシフトは「削られた情報が判断を変えた」のではなく「決まらない場面での既定の選び方(移動→待機/休憩)がプロンプト長で揺れる」現象。情報欠落の検出には該当しない。
3. **full(約3,100tok)との距離はv0→v1より大きい**(8B 0.138・14B 0.074・32B 0.082)=役割知識の上位集合を含むfullは別物で、B0を同一化したv0/v1対比が清浄な比較であることを裏づける。
4. 注意: 14Bの行動分布は購入47%と偏り(v0/v1同値)・32Bは移動53→67%。モデル間の「性格差」は削減の効果より大きい。

## 暫定ゲート(B)の提案(事後設定=Phase 2の新規場面で事前登録して確認する)
- 分布: JSD(v0,v1) ≤ 帰無95th(n=45で≈0.09 bits)。判定: 8B ✓・32B ✓・14B ✗(ただしmid層は✓)。
- 制約: |Δ違反率| ≤ 0.05(95%CI上限)。判定: 未測定(①のv0/v1変種が必要)。
- 32B AWQ TP4は温度0でも4.1%非再現のため、32BのJSDには約0.01-0.02 bitsのノイズ床が乗る[推測]。

## 結論(暫定)
契約書v1の観測削減(1,300tok)は、**答えが決まる場面の行動分布を変えない**(3モデル共通)。変わるのは「決まらない場面の既定挙動」で、これはT0習慣/計画境界の設計(§6)が受け持つ領域。W1判断(v1採用)の品質側の裏付けとして**条件付きで成立**——条件=①制約半分の追試(48呼)と、Phase 2実データ場面での事前登録つき再測。

### 読み方
1. **v1の削減が制約違反を増やす証拠はない**: 合算のΔは−0.042(v1の方がわずかに少ない)・不一致対は3対2で方向性なし。ただし**n=8/モデルでは95%CIが±0.3以上に広く、ゲート|Δ|≤0.05を「通過」とは言えない=「差を検出せず」**が正確な表現(検出可能な最小差は約0.35)。
2. **違反が起きる場面はモデル固有で、水準に依らない**: F1-06(両手ふさがり)は8B・14Bが両水準で違反、F1-05(徒歩12分を3分で)は14Bが両水準で違反=足切り表の「①△辛勝」と同じ像。**不一致対5件のうち3件がF1-01(空腹8で所持金不足)**=欲求と制約が衝突する場面では周辺情報の増減で判断が反転する(両方向)。これは削減の代償ではなく「衝突場面の判断が脆い」という**モデル側の性質**。
3. **制約の種類で意味が違う**: 所持金・所持スロット・営業時間・物理距離はエンジンが取引/移動レベルで強制する(保存則運用②・購入は成立しない=世界は壊れない・LLMの「購入」は失敗行動として記録される)。**行動そのものが違反になるのは条例だけ**(F1-03路上飲酒・F1-07騒音)で、条例違反は3モデル×2水準×2場面=12件中0件(手動裁定後)。
4. **行動一致 v0=v1 は14/24**=⑥と同じく、制約に触れない場面の既定の選び方(移動/待機/購入)がプロンプト長で揺れる。

### 指標Bの判定(暫定・事後設定=Phase 2で事前登録して再確認)
- 分布半分(⑥・n=45): 8B ✓・32B ✓・14B ✗(mid層は✓)。
- 制約半分(①・n=8): 3モデルとも**差を検出せず**(点推定はv1が少ない側・CIは広い)。
- **結論**: 契約書v1の観測削減が制約充足を悪化させる兆候はなく、答えが決まる場面の行動分布も変えない。W1判断(v1採用)の品質側の裏付けは**「反証なし」**として成立。確証にはPhase 2の実データ場面で n≥50/制約種の事前登録つき再測が必要(検出可能差0.35→0.15へ)。
