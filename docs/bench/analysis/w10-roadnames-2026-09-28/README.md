## 2. 突合の規則と結果(絞り込みなし=段 1c の規則)

### 2-1 規則(`build/field/road_names.py` の docstring に全文)

1. **辺 → way**: 辺の折れ線の**弧長の中点**から全 way の折れ線までの最短距離を取り、**名前の有無に関わらず最も近い way** を「その辺自身の way」とする(≤ 8 m=D-W9 のバッファと同値)。
2. **way → センサス路線**(正規化の規則): (a) `normalize_jp`=NFKC(全角英数→半角)・漢数字→算用数字・空白除去 (b) name/official_name に「区道」→ 区道(センサス対象外) (c)「国道N号」または `highway=trunk`+ref の数字 → 一般国道 N(道路種別 3) (d) `highway=motorway` → 高速(W1 に motorway の辺は無い) (e) ref の数字(`;`/`,` 区切りは先頭から)→ 都道 N(道路種別 4・6) (f) ref が無く名前だけ → センサスの路線名(正規化)と完全一致(実データでは 0 件)。
3. **区間**: 渋谷区 → 目黒区 → 港区 → 世田谷区 → 新宿区 → 都内全区間の順に、最初に区間がある区のものの**列ごとの下側中央値**(`median_section`=較正と同じ)を路線全体に当てる。
4. **適用**(切替口 `USE_ROAD_NAME_MATCH`・**既定 False**): True なら当てうる辺に路線の値、それ以外は klass 既定表。False なら全辺 klass 既定(段 1c 前と同じ騒音場)。
