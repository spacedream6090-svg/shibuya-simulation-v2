### 5. 宣言と問い

- **Q55 EVENT_KINDS v0**(§1 の表)。記録しないもの(退去・断る・計画の就寝・移動の開始)を含めて確認したい。
- **Q56 importance の「初回 +1」**: 鍵が同じなら行を作らない(統合)ので、全部の行が「初回」になる=実質 一律 +1。「その種類(kind)の最初の行」など別の読みにするか。
- **Q57 会話の要旨**: mock v3・classical は「ひと言」を出さない=要旨は 0 件。v3 の書式に「ひと言」は無いので、実 LLM(v3)でも空になる。要旨の源を「活動」欄(10 字)や応答全文の先頭 40 字にするか、v3 に ひと言 を戻すか。
- **Q58 看板の初見の判定**: 親しみの表(入った回の露出を含む)で判定すると描画の時点で既知の看板が大半(15,608 → 2,296)。描画による露出だけで判定する(親しみの表の「描画の露出」だけを見る)か、いまの形か。
- **Q59 気づきの供給**: テープでは 0.22 件/体/日(上限)で、見込みの 1.9 と合わない。見込みの出所の確認(R-48 の計算)と、顕著行為の発生率の既定(3/万/日)の扱い。
- **Q60 会話の行の数え方**: 会話の行は「開いたセッションの参加者ごと」に作る(招待者の 会話 の成功は記録しない=二重にしない)。発話は `mem_n`+1(`mem_last` 更新)。招待が保留のまま断られた・期限切れになった場合は、エンジンが体の `last_result` に書いた分だけ記録される。
- **Q61 1 行の実バイト**: アジェンダ §1-1 の「27 B」は数え直すと 25 B(1+4+4+4+4+4+1+1+2)。宣言は 32 B/行のまま(詰め物は予算の側)。
- 宣言(expedient): 気づきの object=事象のセルの場所・通報/就寝の object=今いるセル・手伝いの partner=intent の対象・結果の走査は `last_result_tick == tick` の配列比較(体数の配列演算・逐次ループではない)。

### 4. τ の提案(問い Q62)

A=ln(n/(1−d))−d·ln(L+1)(L=最初の出来事からの分)で、τ ごとに「想起できる古さ」は:

| τ | n=1 | n=2 | n=5 | 1 日後に残る行 |
|---|---|---|---|---|
| −0.5 | 10 分 | 42 分 | 4.5 時間 | n ≥ 12 |
| −1.0 | 29 分 | 2.0 時間 | 12.3 時間 | n ≥ 7 |
| −1.5 | 79 分 | 5.3 時間 | 33.5 時間 | n ≥ 5 |
| **−2.0** | **3.6 時間** | **14.5 時間** | **91 時間** | **n ≥ 3**(n=2 は −2.25 で落ちる) |
| −2.5 | 9.9 時間 | 39.6 時間 | 247 時間 | n ≥ 2 |

**親への提案: τ=−2.0(感度 −1.5 / −2.5)**。**親の決定(第295)=採用・`RECALL_TAU=-2.0` を既定に**(表の「既定」の印も付け替えた)。理由: (1) −1.0 だと 1 回きりの出来事は 29 分で想起できなくなり、B5「直近」/B6「直前の結果」と重なる「いまさっき」の記憶になる(リプレイで 54% の呼が 0 件)。(2) −2.0 は「今日のうち(半日)」の窓で、リプレイで 88% の呼に平均 1.6 件・24 tok(予算 60 の 4 割)。(3) −2.0 でも使用中の行の 42%(mock)は τ で切れる=τ が効いている(−2.5 は 11% しか切れず、ほぼ score の順だけになる)。(4) 複数日では「1 回きりは翌日に落ち、3 回以上繰り返した鍵は残る」=習慣(K-2 のモチーフ)が残り一過性の出来事は薄れる形になる。既定は −1.0(宣言の仮置き)のまま置いてあり、決まったら `RECALL_TAU` を 1 か所変える(テスト 1 本の期待値も)。

### 5. 宣言と問い

- **Q62 τ の値**: 上の §4(提案 −2.0・感度 −1.5/−2.5)。
- **Q63 q の 4 つ目の鍵**: アジェンダは「partner ∨ object ∨ cell」で候補を絞るとし、q に「直前の結果」を含める。本実装は直前の結果を**種類 × 結果の一致**(例: 直前に食事で品切れ → 過去の「食事・品切れ」の行)として 4 つ目の ID 一致に入れた。これでよいか(外すと直前の結果は q に入らない)。
- **Q64 「候補が k 未満なら全行から補う」の τ**: 補いも `A ≥ τ` の行だけから(τ はすべての想起に掛かる読み)。τ を無視して全行から補うと τ −1.0 でも 0 件の呼がほぼ消える(=τ の意味が薄れる)。
- **Q65 項の文面**: HH:MM=その行の**最後**の出来事(`mem_last`)・B3 と同じ 5 分切り捨て。場所=POI 名かセルの ID(B2 は「セルg1_-1_UG」と「セル」を前に付けるが、記憶の項は付けていない=「g1_-1_UG で移動(成功)」)。成立した会話は結果を書かない(「P-12と話した: <要旨>。」)・気づき/看板も結果を書かない。失敗の会話で相手がいない行は「<場所>で会話(<結果>)」。乗車の行はセルが範囲外なら「範囲外で乗車(成功)」。「セル」を付けるか・会話の失敗の文型でよいか。
- **Q66 K-2/K-5 の読み方**: 上の §2 の表のとおり、記憶を読まない mock/classical でも K-2 の比は 5.7〜30、K-5 は方策で符号が変わる。合格線を「同じ方策・同じ seed の off(記憶を読まない)との差」で読む形(差の差)に直すか。K-2 の一様の期待は鍵の粒度(乗車・手伝いは鍵がほぼ 1 種類)で大きく動く=種類を限る(購入・食事・会話・並ぶ)かも問い。
- **Q67 K-5 の「再訪」の定義**: 同じ相手 > 対象 > セル(相手も対象も無い行)の行で、失敗の最初の tick より後に最後の出来事があるもの+同じ失敗の反復(n>1)。成功側は購入・食事・並ぶ・会話・乗車の成功の行。ランの終わりに体ごとのループ 1 回(逐次ループ宣言 6)。
- **Q68 ⑥ 省略記法の代わり**: POI 名に禁止語 → セルの ID・要旨に禁止語 → 要旨なし(§0)。「高等学校」の「等」のような語中の字も弾く(既存の規則のまま)。
- 宣言(expedient): 60 tok は**行全体**(頭の「[B5 記憶] 」を含む)で守る・k=3 は `CONVERSATION_TURN` の呼だけ(会話の級はこの入口だけ)・艦隊の経路でも同じ列を書く・テープの `schema_version` はメタデータが無ければ列で推定(版3 の列 → /3・版2 の 3 列 → /2・それ以外 /1)。
