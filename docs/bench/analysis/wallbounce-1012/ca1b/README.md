## 0. 結論

- 腕 `--calendar {w17,1b}`(環境変数 `SHIBUYA_CALENDAR`・既定 w17)を足した。1b のランでは、W20 の時刻つきの**勤務の約束**を
  持つ体(5,000 体の月曜で 2,712 体)の「出発するか・いつ出発するか・帰るか」を、候補の口 J0 の候補(源 plan・continue・
  deliberate)として判断の口(仮のモデル=mock/古典)に出す。入力は本人が知っている予想(約束の時刻・場所の言葉・見積りの幅・
  余裕)と観測(読んだ時刻=時計を見れば分・手帳はおおよそ・今いる所)を並べた形(CA5 問い 1)。
- 出発した体は、域外からは「出発+域外の時間」より後に**最初にホームへ入る自分の路線の便**で着き(来た電車)、舞台の中は
  行き先へ歩く。帰りは自分の路線のホームへ歩き、待ち行列と受容関数で**来た電車に乗る**。エンジンは逆算して起こさない・便を
  選ばない・時刻で退出させない。歩きが途切れた体は消さずその場に居続け、本人の次の機会に決め直す(E4 を外す)。
- 管理する体の計画実行層の到着・退出(W17 の ARRIVE/DEPART と張り直しの到着)は実行しない(口 `PlanExecutor.io_hook`)。
  **就寝・起床は W17 のまま**(5,000 体で就寝の境界の事象 6,337 件=既定と同じ)・来街者の来訪も W17 のまま・出勤率のくじは残す。
- **既定(w17)は 19/19 構成で 25 欄とも HEAD と同じ**(最後の直しの後も 4 構成で同じ=§8)。
- 腕 1b(mock・5,000 体・1 日・w6_v3_default): 最後まで回る(55.5 秒)・出発 2,708・着いた 2,706・帰る 2,627・家 2,610。
  **エンジンがしないこと 3 つの検査はどれも 0**(時刻で消えた体 0・逆算して起こした機会 0・間に合う便を選んだ到着 0/2,582)・
  E4 の消去 0・急に現れた体 0。負の対照(それぞれを植えた写し)では検査が数えて試験が落ちる(§5)。
- 道具の台帳に「時計」「天気予報」を足した(段 6-2・既定の世界では使わない=final 不変)。天気予報の中身は空欄(ランの日の
  府県天気予報の本文が無い=つなぎ `DOC-ca1b-forecast-blank`)。
- 状態台帳に腕の行 `C1B`(本人の予定の器=behavior・required)と `C1BM`(判断の記録と計器=diag・required)。再開=通し(2 日・
  日の境目)。つなぎの台帳に本段の行 18(`DOC-ca1b-*`)と、`BR-W17-IO-SLEEP`・`BR-E4-EXIT-VANISH` に「腕 1b で外れる部分/
  残る部分」の注(status と外す段は不変=既定で生きている)。
