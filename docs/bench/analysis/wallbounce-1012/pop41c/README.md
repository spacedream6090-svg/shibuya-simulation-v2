## §9 限界と仮採用(10-13b §0-3)

近似の宣言は `W21C_EXPEDIENTS`(16 行・つなぎの台帳と 1 対 1)。主なもの:

1. **国籍**: 住民の外国人だけを区の国籍の人数の比で引く(年齢と男女で条件づけない=T2 を取り出していない)・外から来て働く人の国籍は空欄。
2. **第一言語**: 国籍 → 主な言語の写像(上位 20 の国籍だけ・多言語の 3 国とほかの国は空欄)=未リサーチ。
3. **人物の文の型**(行の並び・語の表・年齢の言い方・2 桁の有効数字・短い版と長い版の分け・TIPI-J の 3 段)=自前。勤め先の種類と町丁目の名は英語の型でも日本語のまま。
4. **運輸の二重**: W16 の運輸の行を残す案のままだと、W21 の駅員・電車運転士・車掌の体 223 と二重(§3-2)。

7. **分の言い方**: 文は四捨五入(丸めた言葉)・W20 は切り上げ(整数の分)=同じ関数 `walk_seconds` を通す。
