## 4. 読み取りの計画(まだ実行しない・10 行)

1. 道具は手元にあるものだけ: システムの python の PyMuPDF(1.28)と Pillow(AVIF も可)。pip で足すもの(OCR など)は無しで組む。
2. テキスト PDF(JR 18 本・メトロ 4 本)の読み 1: `get_text("words")` で語と座標を取り、時の列と分の行を座標で組む。種別と行き先の記号は、上に付く小さな字を座標で分に結ぶ。
3. 同じ PDF の読み 2: 頁を画像にして Claude が目で起こす(読み 1 の結果を見ずに)。2 つの CSV を 1 行ずつ突き合わせて食い違いを並べる。
4. 東急 8 本(文字なし・ベクタの輪郭)の読み 1: `get_drawings()` の塗りの図形を字ごとにまとめ、形の指紋(正規化した輪郭の hash)で数字 0〜9 と記号を分ける。指紋ごとに 1 回だけ目で名前を付ければ、残りは決定的に読める。
5. 東急の読み 2: 300 dpi で画像にし、時の帯ごとに切り出して目で起こす(読み 1 を見ずに)。種別は色(急行・準急・各停)、行き先は小さな字で判別。
6. どちらの種類も、時ごとの本数を図で目で数えた値と、2 つの読みの本数を 3 つ並べて照らす。
7. 直通の二重計上(半蔵門線・副都心線 × 東急・ODPT)は、時刻と行き先で突き合わせて 1 本にまとめ、まとめた件数を記録する。成田エクスプレスと湘南新宿ラインも同じ。
