### 3-2 割り当ての規則

1. 住民の勤め先: 自宅=家のセル・自宅外の区内=区の町丁目を経済センサスの従業者の比で引き被覆率の確率で舞台の中(距離の重みなし)・区の外=舞台の外(駅まで)。
