# 10e E4 の住人の入れ替わり(5,000 体のうち 4,191 体)の属性の分布の比較(第330・発注 E)

## 結論

**偏りなし**。属性 19 個(区分は延べ 989)を比べた。属性ごとの判定(標本と二層抽出の期待との総変動距離 TVD を、別の seed 100 本のフロアと比べる)では、旧(stateful)と新(counter)のどちらも、全属性で 100 本の最大を超えなかった(経験 p ≥ 0.02)。旧と新の差も、全属性で「同じ seed の stateful と counter の差」のフロアに収まった(経験 p ≥ 0.089)。

- いちばん外寄りだったのは新の **synthetic(合成体=W16 が素材を複製して足した体)** で、新は 1,260 体(25.2%)、期待は 1,201 体(24.0%)、counter のフロアは 22.95〜25.05%。フロアの上端を 0.15 点(約 7 体)超えた。経験 p = 0.020、カイ二乗 p = 0.049(多項近似)、Cohen の h は新−旧で +0.020。比べた属性のうち抽出で値が揺れるのは 14 個あるので、Bonferroni の線は 0.05/14 ≈ 0.0036 になり、この値は届かない。counter の 100 本の平均は期待どおりだった(z = −1.32)。旧↔新の差もフロアの中にある(経験 p = 0.21)。抽出の仕組みの偏りではなく、seed 1 の偶然と読む(**推測**: 100 本中 1 本がこれ以上に外れた)。エンジン(`src/shibuya` の build 以外)は `synthetic` の列を読まない(grep で確認)。同じ素材を持つ体の数は旧 41・新 41 で、フロア 37〜56 の中にある。
- 区分ごとのフロア(2.5〜97.5%)の外に出たのは、旧 33 / 989・新 25 / 989・旧↔新の差 34 / 989。無作為でもおよそ 5%(約 49)は外に出る数なので、それより少ない。外に出た区分の大半(旧 30・新 22・差 30)はセルの区分で、その 58 区分のうち 47 区分は期待が 5 体未満(中央 1.2 体)である(§4)。
- 種類・年齢 5 歳階級・性別・プール層・舞台内に住むかは、旧・新・100 本のどれでも同じ値になる。抽出が (種類 × 年齢階級 × 性別) の層に最大剰余法で定員を割るので、seed では動かない。

**全体と標本の差は抽出の設計によるもので、偏りではない**。定員先取り層の 769 体(駅員・乗務員・警察・消防・議員・指令)は縮尺せず全員入るので、5,000 体の標本では CREW が 14.3%(全体 0.32%)・勤務が 46.9%(全体 55.3%)になる。新と全体の h は CREW で +0.662、職務の役割「なし」で −0.692 になる。定員先取り層を除いた統計層(4,231 体)と、全体の非先取り部分(389,298 体)を比べると、町丁目・セル以外の属性の |h| は旧・新とも 0.033 以下だった(大きい順に 産業 AM の旧 −0.032・合成体の新 +0.032・産業 MW の旧 +0.031・路上生活者の新 −0.029=全体 80 体・期待 0.87 体・新 0 体)。町丁目は 0.035 以下、セルは 0.057 以下(Cohen の目安で「小」は 0.2)。

**共通の 809 体は偶然と変わらない**。809 体のうち 769 体は定員先取り層で、seed にかかわらず必ず共通になる。残りの統計層の共通は 40 体で、層ごとの超幾何の期待は 46.1 体(sd 6.7・z = −0.91)。全体の期待は 815.1 体で、同じ seed の stateful と counter の共通を 100 本数えると 798〜834(2.5〜97.5% は 802〜830・中央 816)。単純無作為を仮定した 5,000²/N は 64.1 体だが、この抽出には当てはまらない(定員先取り層が両方に入るため)。

## 1. 何を比べたか

- **旧** = `load_population(data/world/v2, 5000, seed=1, rng_scheme="stateful")`(E2 までの既定)。`population_hash` = `44e413cccb3386d6…`。
- **新** = 同じ呼び出しで `rng_scheme="counter"`(10e の既定)。`population_hash` = `9d698e81339f3039…`。
- **全体** = `data/world/v2/w16_population.parquet` の全行 = **390,067 体**(`population_hash` = `dec0e86812284b64…`)。発注書の「R-109 は 108,142 体と数えた」は、`synthetic=True` の体数(108,142)と一致する。全体の体数は 390,067(W16.header.json の `n_total` と同じ)。
- **フロア** = `sample_population(全体, 5000, seed, rng_scheme=…)` を seed 2〜101 の 100 本、stateful と counter の両方で回したもの。旧は stateful のフロア、新は counter のフロアと照らす。旧↔新の差は「同じ seed の stateful と counter の差」の 100 本と照らす。`load_population` と `sample_population(全体, …)` が seed 1 で同じ標本になることは、スクリプトの中で assert している。
- **期待(二層抽出)** = 定員先取り層の全員 + 層ごとの (定員 ÷ 層の体数) × 層の構成。層の定員は seed に依らない。
- **属性**(19 個): 種類・目的・年齢 5 歳階級・性別・住所の町丁目(`chome_key`。空=域外常住)・勤め先の産業(`industry_key`)・職務の役割(`duty_role`)・プール層・合成体・外国籍・方面の節点・世帯人数(`w16_households.size`)・勤め先の組織の体数(`org_id` ごとの全体の体数を 5 段に束ねた。expedient の束ね方)・舞台内に住む/勤める/通うか・住む/勤める/通うセル。年齢は平均と標準化平均差も出した。`home_building`(5,672 区分)と `org_id` そのもの(9,873 区分)は区分が多すぎるので表にしていない(組織は体数の段で見た)。
- **統計量**: 区分ごとの割合・フロアの 2.5〜97.5%・Cohen の h(新−旧・新−全体・統計層どうし)。属性ごとに、期待との TVD とカイ二乗(期待 5 体未満の区分は 1 つに束ねた適合度)を出した。経験 p = (1 + フロアの中で観測以上の本数) / 101。
- **多重比較の注**: 区分は延べ 989 あり、無作為でも約 5% はフロアの外に出る。属性の判定は 19 個(抽出で揺れるのは 14 個)を一度にしているので、1 個が p ≈ 0.02 になるのは珍しくない(14 個がすべて独立なら、どれか 1 個が 0.02 以下になる確率は約 25%)。カイ二乗の p は多項分布(単純無作為)を仮定した近似で、層別抽出では分散が小さくなるので p は大きめに出る。主な判定は経験 p で行った。

## 5. 抽出の仕組みそのものの偏り(stateful と counter)

各区分について、100 本の平均が期待(二層抽出)からずれるかを z = 差 ÷ (標準偏差 ÷ √100) で見た(100 本が全部同じ値の区分は二項の sd で代えた)。|z| > 3 は stateful 4 / 989・counter 4 / 989 で、どれもセルの区分(期待 0.04〜6.1 体・最大 |z| は stateful 3.54・counter 3.56)。正規近似で 989 区分なら約 2.7 区分が |z| > 3 になる数で、希な区分は正規から外れるので、これより多少多くても不思議はない。セル以外の属性では |z| の最大が 2.94(counter の産業)。**どちらの並べ方も、100 本の平均は期待と合う**。

フロアの幅も 2 つの並べ方でほぼ同じだった(例: 町丁目の TVD の 97.5% 点は stateful 0.0117・counter 0.0118、勤めるセルは 0.0528 と 0.0520)。stateful は隣の層の流れが 1 ブロックずれて重なる(10c 検収 P1〜P3)が、標本の構成のばらつきには表れなかった。
