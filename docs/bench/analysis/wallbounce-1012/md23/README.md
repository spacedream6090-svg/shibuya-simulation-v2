## 0. 結論

- **体の出来事を記録に載せた(腕 a=`--memory-store events` のときだけ)**: 口 `engine/events/body.py`(`BodyEventLink`)が、記憶の書き手が書く体の出来事(行為の成否・移動の到着・会話の始まりと番・顕著行為への気づき・強い看板の初見)と会話の終わりを、1-3 の出来事の記録に 1 行ずつ書く。原因は **この刻みに適用した判断の呼 `LlmCall(call_id)`(テープの call_id と同じ形)か過程 `resolve`・`conversation`・`perception`** だけ。語彙は末尾に 3 語(`行為:会話の始まり`・`行為:会話の終わり`・族を足して `知覚:気づき`)と過程の名 2 つ(`resolve`・`conversation`)を足した(版 `events-vocab/2-3`・本体の 3-3 の後の 62〜64=前の 62 語のコードは動かない・§15)。
- **器の目印の先を記録の出来事にした**(出どころ None)。M0 の「書けるのは legacy だけ」の守りを「記録にある出来事の id だけ」に替え、無い id・本人でない出来事・種類の合わない出来事は `ValueError`(負の対照の試験)。5,000 体・5 日の腕 a で器の行は全部が記録の目印(1 日目 55,465 行 → 5 日目 193,608 行・legacy 0・先が記録にある 100%)。`DOC-memory-store-legacy` は removed(2-3)。記録 off の道(腕 events+`SHIBUYA_EVENTS=off`)は 1-6 と同じ legacy の行のまま(試験)。
