## 2. 属性から作る関数

### 2-1 式

体 i(属性=W16 の種別・年齢・セル・産業の鍵・duty_role と、ペルソナの `employment`・`workplace_scope`・`school_stage`・
`arrival_lead_min`)について、週 w・曜日 d の約束を次で決める(抽選はどれも `core.rng.philox_array` の counter=鍵は体・週・曜日・
10c と同じ形=体の数に依らない)。

1. **約束の種類**: 授業(学校のセル・授業のある学校段階・学齢 6〜14 歳の住民・通学者)/ 勤務(W16 の事業所の体・指令・
   勤め先のある duty_role・ペルソナの employment が勤務の語の住民)/ なし(=空欄)。W16 の席(種別 0・2)があってもペルソナの
   employment が非就業の体はなし(親の判断 第336 (3)・`seat_nonworking` に数える)。〔第337 中 1〕W16 の席(種別 0・2)が
   あってペルソナが学校段階か学校のセルを持つ体は**席を優先して勤務**(授業は空欄・`seat_and_school` に数える・非就業の
   ペルソナは空欄のまま)。
2. **地位**(§2-2 の 3・4): duty_role の体は第6-2表(渋谷区・中分類)の 6 区分の人数比で引き直す。ほかの体はペルソナの
   `employment` を写す(正規=無期・非正規=有期・役員=有給役員・自営業主=個人業主・家族従業者=無給の家族)。→ 第 31/36 表の行
   (無期=正規の職員・従業員・有期=非正規 5 つを第 31 表の全国の人数比で按分・臨時=アルバイト・有給役員=会社などの役員・
   個人業主=業主 28:72・無給の家族=家族従業者)。
3. **曜日の予定の率** p(平日・土・日)= 第74-6表(東京都)の地位・勤務形態の行の「仕事」の行動者率そのもの(正規・役員・
   契約・嘱託・派遣=雇用されている人のフルタイム 87.9/32.4/20.4%・パートとアルバイト=短時間勤務 61.1/31.2/18.9%・業主と
   家族=自営業主 73.9/53.8/41.1%)。duty_role の体だけ第74-9表の職業/総数の比を掛ける(上限 1)。第74-6表は「その曜日に仕事を
   した人」=休んだ後の実現値なので予定の率の下限=予定はこれを下回らない(親の判断 第336 (1))。
4. **週の日数** D = 5 p_平日 + p_土 + p_日(正規の行で 4.92 日・パートとアルバイトで 3.56 日・業主で 4.64 日)。
5. **その曜日に勤務の予定があるか**: u(体, 週, 曜日) < p(その曜日の型)。正規(毎週固定)は鍵の週を 0 に固定=毎週同じ曜日・
   非正規とシフトは週ごとの抽選。〔第337 中 2〕**週 1 日の休み**: 規則の表の行 `labor.weekly_rest_day`(労働基準法 第 35 条
   1 項「毎週少くとも一回の休日」・e-Gov の法令 API の版 2026-07-17・親が 1 項と 2 項の逐語を確認)を構築のときに読む(build は
   engine を import しない=JSON を直に読む)。対象は行の `applies_to_status`=9 条の労働者(無期・有期・臨時)で、その週に 7 日とも
   勤務を引いた体は 1 日を休みにする。休みの曜日 = その曜日の働かない率 1 − p(曜日)に比例して引く(一様変数の鍵=体と週・
   毎週固定の体は週 0=毎週同じ休み・どの曜日も p = 1 の体は率の最も低い曜日)。有給役員(9 条の労働者でない=親の判断
   第337 (1))・自営業主・無給の家族は対象の外=週 7 日を制約しない(役員は自営業主と同じ扱い)。2 項(4 週 4 日の変形休日制)は
   入れない。休みの曜日の選び方と 2 項を入れないことは当てはめ(`W20cal#9`)。
   **年間の整合の計器**(診断・合否なし): 予定の日数 D × 365/7 と第19表(特別区部)の年間就業日数(休暇を含む実現値)を行ごとに
   並べる(関数 `annual_check`・段のヘッダの `notes.annual_check_t19`=§4-1)。
6. **時刻**: 第 31/36 表の行の逆関数法で出勤 dep=Q31(u)・帰宅 ret=Q36(u)(同じ u=順位の相関 1)。始業=dep+lead・
   終業=ret−lead(lead=ペルソナの片道の通勤時間・無ければ 30 分・自宅で働く体は 0)。勤務の長さを [4 h, 12 h] に切る。
   〔第337 低 1〕切った体の帰宅は終業+lead に作り直す(どの勤務の行も 出勤+lead=始業・終業+lead=帰宅・終業 ≤ 帰宅)。毎週固定は
   u を体ごとに 1 回・週ごとは体・週・曜日。
7. **場所**: duty_role は表(駅・乗り物・担当区域・建物)・W16 の事業所の体は建物(W16 に職業の列が無い)・舞台の外で働く住民は
   域外・自宅で働く体は自宅・学校のセルのある体は学校(セルの無い体は住まいが舞台の中なら学校・外なら域外)。
8. **授業**: 月〜金(規則)・時刻は空欄(公式の時程は取得の許可の後)。保育所は授業でない=空欄。
9. **欄**: 確かさ(確定)・繰り返し(毎週固定/週ごと/規則)・置き場所(CA3=1a は空欄)・元の会話(なし)。
