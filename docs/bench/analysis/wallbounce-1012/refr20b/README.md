## 0. 結論

**既定(語彙 v3)では、不応期を外すと呼数が 1.26〜1.28 倍になる(seed 1〜3。seed 1 は 1.264 倍)。39 万体に比例で外挿すると、1 シム日あたり約 647 万呼(seed の幅 647〜654 万。7 日で約 4,528 万)。判断モデルと LLM の仮の割りでは、判断モデル約 613 万呼・LLM 約 33 万呼/日。**

T3 の驚き駆動では「何かあった人だけ」が呼ばれるので、これは上限の見積りです。ただし上限になるのは、不応期の表の外にある門(§6 の 4・§11-3。主なものの一覧で網羅ではない)が残る場合に限ります。語彙 v1(活動層なし)では 8.44 倍(39 万体で約 3,412 万呼/日)になりました。v1 の増えの大部分は場所の変化の起床で、v3 では活動層がこの候補を落としています(§4-2)。

追記(§11): 語彙 v3 で活動層を層ごと off にした構成では 7.89 倍になりました(増えの 95% が場所の変化)。層ごと off は、活動中の場所の変化の候補を落とす門だけでなく、活動の満了の起床・活動の設定・あたり歩行なども一緒に外すので、腕 A も 65,597 → 50,301 に変わります。門だけを外す口は src に無く、門だけの重みは測っていません。倍率の差(off − on)は +6.63 です(比なら 6.24 倍)。2 万体の既定 v3 では体あたりの倍率が 1.243 で、5,000 体の 1.264 より 0.021(1.7%)低くなりました。体数に比例する外挿は 2 万体までは 2% 以内で合いますが、39 万体は確かめていないので推測の印は外しません。

### 4-2 v1 と v3 の差(活動層の門)

v3 では、活動層が「活動中(`activity_until > 刻み`)の体の場所の変化の候補」をアービタの前に落とす(`engine/activity.py` の `suppress_cell_block`)。この門で落ちた候補は、seed 1 で A 211,925 件・B 253,778 件/日。発射した場所の変化(A 5,790 件)の約 37 倍にあたる。v1 には活動層が無いので、場所の変化の不応期(30 分)だけが歯止めになっていて、それを外すと 6.99 倍に増えた。

### 4-3 設計書の予想との照合

知覚契約書 [§6 の不応期表](../../../../design/v2-perception-contract.md) は、近接入替(15 分)を「最大の暴発源(混雑セルでは毎秒入替)」と予想している。**今のエンジンではこの予想を確かめられない。** 近接入替・被注視・傍受は、起床候補を出す処理がどこにも無い(D-49・C10 の資料 `v2-c10-relations-brief.md` と同じ事実。`grep` でも `commit.py` のクラスの写像にしか現れない)。だから C8〜C10 は final まで A と同じになった。知人出現は関係 on の構成でだけ結線されている(C10 R7 (a))。今の版で測れた暴発源は、v3 では内受容、v1 では場所の変化。回答 10-13b §4-2 の 1 により、近接入替などは起床の条件ではなく知覚の事実として扱う。その値が入った後に、それが起床につながる道が残るかどうかで、ここに足す呼数が決まる。

## 6. 限界

1. **mock の挙動**: mock は凍結の規則で応答する。LLM なら選ぶ行動や活動の長さが違い、内受容の段の跨ぎ・活動の満了・計画境界の起き方も変わる。倍率は「mock の応答の下で、エンジンの側で何倍になるか」である。
2. **1 日・seed 3 本**: seed のばらつきは既定 v3 だけ(倍率 1.264〜1.279)。曜日・天気・2 日目以降は測っていない(7 日は 1 日の 7 倍)。
3. **体数に線形(推測)**: 5,000 体は 39 万体の約 1.3% の標本で、セルあたりの人の数は全員のランの約 1/78。場所の変化や会話はセルの混み方で起き方が変わるので、体あたりの呼数が全員のランで同じとは限らない。2 万体では倍率が 2% 以内で合った(§11-2)が、39 万体は確かめていない。
4. **不応期の表の外の門は残る**: 腕 B で外したのは 11 行の不応期だけ。就寝抑止(D-56)・域外抑止(D-66)・活動層の場所起床の門(v3)・アービタの合流(1 体 1 刻み 1 呼)・会話の招待の間隔(`conversation.py` の同じ対 60 分・同じ招待側 30 分=知覚契約書 §6 の「同一相手」「同一話者」を会話の管理が別に持つ分で、`--refractory-scale` の外)は残る。どれも「いつ考えるか」をエンジンが決めている門で、つなぎの台帳の `BR-REFRACTORY-*` には載っていない。ほかに、意図の保持(`engine/intent.py` の `suppress_wakes`・既定 v3 で働く)と D-62 の就寝の実行(`systems/body.py` の `to_bed`)も残る(一覧は §11-3。主なもので網羅ではない)。T3 でこれらも外すなら、v3 の上限は今の 1.26 倍より大きくなる。活動層を層ごと off にした量は測った(§11-1・7.89 倍。門だけの量ではない)。門だけの重みとほかの門の重みは測っていない。
5. **結線されていない起床条件**: 近接入替・被注視・傍受は 0(§4-3)。知人出現は関係 on のときだけ。
6. **判断モデルと LLM の割り**: manifest の `calls_by_model` は判断モデル 0。見積りの割りは仮(§7 の 1)で、よく考える判断を LLM に上げる分は含まない。LLM は下限、判断モデルは上限。
7. **範囲外の気づき(記録だけ)**: `agents/state.py` の `REFRACTORY_MINUTES` の注「同一相手 60 分は C2 未実装」は古い(`relations.py` の `REL_ACQ_PAIR_REFRACTORY_MIN` が関係 on で働く)。src は触らないので、扱いは親に任せる。

## 7. 仮採用(未リサーチ=expedient)

1. 判断モデルと LLM の仮の割り: 会話ターン(`CONVERSATION_TURN`)の呼を LLM、それ以外を判断モデルに数えた(CLAUDE.md §3「日常の判断は判断モデル、会話とよく考える判断は LLM」に合わせた。manifest の欄は変えていない)。
2. 39 万体への外挿は体数に線形(10e と同じ約束)。7 日は 1 日 × 7。

### 11-1 活動層を層ごと off にした量

構成 `w6_v3_activity_off`(`byte_check_10e` の表の kw={語彙 v3・活動層 off})の腕 A・B を seed 1・5,000 体で足した。腕 A は 10e の `ret.json` と final・呼数が同じ(`e0054a837c6ec4c1`/50,301)。

この構成は活動層を層ごと外す。外れるのは、活動中の場所の変化の候補を落とす門だけではない。活動の満了の起床・活動の設定・あたり歩行・B4b の活動の 1 行も一緒に外れるので、腕 A も 65,597 → 50,301 に変わる。src には門だけを外す口が無い(`suppress_cell_block` は知覚の系から条件なしで呼ばれる)ので、門だけの重みは測っていない。

| 構成 | A 呼数 | B 呼数 | 倍率 B/A | 場所の変化の発射 A → B | 場所の変化の増分 | B − A に占める割合 | 活動層の場所起床の抑止 A → B |
|---|---|---|---|---|---|---|---|
| w6_v3_default(活動層 on) | 65,597 | 82,919 | **1.2641** | 5,790 → 9,248 | +3,458 | 20% | 211,925 → 253,778 |
| w6_v3_activity_off(活動層 off) | 50,301 | 396,991 | **7.8923** | 18,915 → 349,205 | +330,290 | 95% | 0 → 0 |

- 倍率の差(off − on)は +6.63(比なら 6.24 倍)。場所の変化の増分の差は +326,832 呼(5,000 体・1 日)。
- 活動層 off の腕 B は v1(8.44 倍)に近い。v1 と同じく、場所の変化の不応期(30 分)が外れると場所の変化の起床が歯止めなく増える。増えの 95% が場所の変化なので、層の中で主に効いているのは場所の変化の候補を落とす門と読める(**推測**・門だけの腕は作れていない)。
- 39 万体に比例させると、活動層 off の腕 B は約 3,097 万呼/日(L4 の線の 7.7 倍)。これも層ごと off の量で、T3 で層を残して門だけを外す場合の量ではない。
- 腕 A の差(on − off)15,296 呼の内訳(起床条件ごと・道具の `calls_A_diff_on_minus_off_by_condition`):

| 起床条件 | on − off |
|---|---|
