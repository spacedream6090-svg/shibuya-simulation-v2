# LLM 呼び出しが 7 回/体/日で止まり、会話がほぼ起きない理由(親の統合報告・2026-09-24・第262)

> 問い(ユーザー): 「検証ランや本番の 1 日ランで LLM の呼び出しが 1 体あたり 1 日 7 回ぐらいしかなかったのはなぜか。会話などが極端に少なかったのはなぜか。LLM の出力が何に使われたのかを調査し、なぜこの結果になったのかを分析してほしい。サブは Opus 5.5 で」。
> 分担: [sub_a_calls_and_usage.md](sub_a_calls_and_usage.md)(呼数と出力の使い道)・[sub_b_conversation.md](sub_b_conversation.md)(会話)。どちらも書き手は **Claude Opus 5.5(1M context)** と申告(Agent ツールの `opus` 指定で起動)。数値の置き場: `sub_a_numbers.json`・`sub_b_numbers.json`。
> **親の検収**(§6): 結論を変える主張の引用行 15 か所を実読し、要の数値 4 つをテープから再計算した。**全部一致**。サブの空欄はそのまま空欄(§5)。

## 0. 答え(先に)

1. **7 回は「上限」の値であって「需要」の値ではない。** 呼数の予算 L4(10 呼/体/日が制御目標・上限 400 万呼/日)を 1 日 1,440 tick に**均等に割り、余りを 2 tick ぶんしか持ち越さない**実装のため、需要の少ない夜に枠が余り、需要の多い昼(07〜20 時)は枠に張り付く。5,000 体で 10 − 2.56(夜の余り)≈ 7.4、39 万体で 10 − 3.06 ≈ 6.9。
2. **上限を外しても 15 回で止まる。** 起きる入口が 4 つ(場所の変化・体の状態の変化・日課の切れ目・会話の番)しか動いておらず、社会的な入口 4 つ(知人が現れた・近くの人が入れ替わった・見られている・耳に入った)は**候補を作るコードが無い**。就寝中・舞台の外の体は呼ばない。何も起きなければ呼ばない設計(周期的な呼び出しは 09-03 に廃止)。
3. **会話がほぼ起きないのは予算のせいではない。** 会話が始まる道は「LLM が普段の呼び出しで自分から『会話』を選ぶ」の 1 本だけで、8B は 36,906 呼のうち 25 呼(0.07%)しか選ばない。観測に載る人物は「P-123(未知)」の ID だけで、距離も関係も相手の発話も無い。選んでも成立は 10〜18%(対象欄に人の ID を書かない・相手が期限 3 tick 内に呼ばれない)。成立しても 1 体 3 呼で終わり、**相手の「ひと言」は相手に届かない**。予算を外しても 0.006 セッション/体/日。
4. **LLM の出力で世界を動かしているのは「行動」の 1 語だけ**(会話のときだけ「対象」の人 ID も)。「理由」は誰も読まない。「ひと言」は会話の関数に渡るが使われない。移動先と購入先は既定の腕ではエンジンが決める(職場/自宅のうち今いない方・現在セルの最小 id の POI)。役割語(補充・開閉店・発車…)は 8B が選ばず、選んでも「待機」に落ちる。日次内省は数を数えるだけで LLM を呼ぶコードが無い。
5. **写しの誤りを 3 件訂正した**(§4): 「07〜19 時は艦隊上限 162,528/h で飽和」は L4 の按分値で艦隊には余裕があった/「会話 0.0021 セッション/体/日」は参加数で、セッション数は 0.00105/「無制限でも 25 呼」の見込みは抑止を二重に数えていた(実測 14.6)。

## 1. なぜ 7 回か(4 つの層)

| 層 | 何が決めているか | 効果 | 種類 | 出所 |
|---|---|---|---|---|

| ④ 艦隊 | 78 応答/s ≈ 28 万呼/h。07〜19 時の 162,528 呼/h は艦隊でなく L4 の按分値(2,708.8 呼/tick × 60)。艦隊が決めたのは壁時計(tick の 89% が応答待ち) | 呼数には直接効いていない(繰り延べ 0.5%) | 資源(間接) | sub_a §2(e)・[build-report-C7 §1h](../../../ops/build-report-C7.md) |

検証: 時刻ごとに min(無制限の需要, 現行の枠) を足すと **37,224 ≈ 実測 36,906**(親が再計算・一致)。現行 ×1 は 07〜20 時の毎時 2,083 呼で枠に張り付き、0〜6 時は需要が枠の 17%。

## 2. なぜ会話がほぼ起きないか(漏斗)

| 段 | 何が落とすか | 現行 ×1(5,000 体)の値 | 種類 |
|---|---|---|---|
| 起点 | 会話の番(会話ターン)の呼び出しは「既に話しかけられた側」にしか起きない。始めるには普段の呼び出しで LLM が「会話」を選ぶしかない。社会的な入口 4 つは no-op | 会話を選んだ 25 / 36,906 呼(0.07%)。mock は 1/12 一様 | 実装の未完+モデルの挙動 |
| 材料 | 人物行は「P-<id>(未知)」だけ(知人表がレンダラに渡らない・距離なし・相手の発話なし)。役割知識は「会話は 1 m で成り立つ」と教えるが距離は見せない | 同 tick 同セルに別の呼ばれた体がいる呼 41.9%(下限)→ その場面で会話を選ぶのは ≈0.1% | 実装の未完(知人・被注視の結線)+設計(固定枠・k=3/2/1) |
| 動機 | 選んだ理由の過半が食事(店員らしき人に尋ねる)。社会的な動機からではない。看板行 1 行を消すと ×3〜4・行動欄の 1 句で ×6 | 自分から始めた 16 件中 11 件が食事絡み | モデルの挙動(判断が材料に支えられていない) |
| 成立 | 対象欄が人の ID でない(物のカテゴリ・「食事」・セル ID)/ 相手が期限 3 tick 内に呼ばれない / 招待を見る前の応答が返事として消費される / 相手が別の行動で答える | 会話を選んだ呼 100 本あたりセッション 10〜18(×1 は 25 → 3) | 設計の expedient(TTL 3・先着 1 件)+実装 |
| 中身 | 1 体 3 呼が上限。相手の「ひと言」は相手の観測に載らず、届くのは定型の起床文だけ。話題は本数だけ | 成立した対の会話呼 中央値 3(挨拶の繰り返し) | 設計(MAX_TURNS=3 は予算由来)+実装の未完(発話の受け渡し) |
| 予算 | 無制限で会話 ×7.6(25→190)・セッション ×10(3→31) | それでも 0.0062 セッション/体/日。39 万体でも 0.00105 | 倍率は動くが桁は埋まらない |

人の錨は覚醒時間の 27.9% が会話([思考頻度ノート](../../../research/v2-thought-frequency-anchors-note.md))。C6 の A/B では、招待が相手の観測に**載れば**承諾 87/101 だった=承諾の文面は効いている。落ちているのは起点と材料。

## 3. LLM の出力は何に使われているか

| 出力の欄 | 消費者 | 世界への効果 | 実測(現行 ×1) |
|---|---|---|---|
| **行動**(1 語・12 語) | parser → `llm_bridge` → `commit.intents_from_responses` → `resolve` | **世界を動かす唯一の欄**。未定義の語は同義語辞書で写し、写せなければ「待機」 | 移動 45%・購入 44%・休憩 4.4%・待機 3.6%・乗車 2.5%・会話 0.07% |
| **対象**(人 ID) | 会話の相手の解決だけ | 会話のときだけ | 人 ID 22 件/36,906 |
| 対象(セル・物カテゴリ・駅) | 既定の腕では**使われない**(注意の切替口 ON=辺幾何∧語彙 v2 のときだけ) | 移動先=職場/自宅のうち今いない方・購入先=現在セルの最小 id の POI(エンジン) | 物カテゴリ 19,318・なし 17,482 |
| **理由** | **無し**(切り出した後に読むコードが無い) | 効果なし(テープの原文に残るだけ) | 平均 10.4 字 |
| **ひと言** | `conversation.utterance(comment=…)` に渡るが**関数の中で使われない** | 効果なし。相手の観測にも載らない | — |
| 役割語 12 語 | 選ばれても「待機」に落とす(expedient) | 役割行動は世界過程の代替規則(conf 0.5)が全件担う | 8B は 0 件(39 万体で「並ぶ」152 のみ) |
| 日次内省(熟慮層) | `n_reflections` を数えるだけ。LLM を呼ぶコードは無い | 効果なし | 0 回 |
| ビルド時 | W14 看板文(32B・4,674 呼)・W15 場所の定型文(32B・1,040 呼)・W17 日課表(8B・390,067 呼) | 観測の共有部と日課(在圏の骨格・移動の行き先) | 1 回限り |

**世界の実行に占める LLM 判断の比 9.6〜19.3%(予算 ×0.5〜無制限)**。ただし「エンジン継続 87.6%」は移動中の体の 1 tick 1 歩の延べ数で、LLM の判断 1 回と単位が違う(その多くは LLM が選んだ「移動」の実行)。比較の指標としては使わない。選んだ行動の成立率: 購入 36〜41%・乗車 28〜80%(予算を増やすと下がる)・会話 10〜18%。

## 5. 含意(判断材料・実装はしない)

- **枠の配り方は結果を駆動する expedient**(方法論のゲート対象)。10 → 7.4 の差の大部分。決定 D-99 (a′)(無制限を既定・L4 は監査線)を採れば消える。採らないなら「需要に合わせた配分」を切替口で測る腕が要る → **D-110** を新設。
- **需要の天井 14.6 は入口の数で決まる**。会話・社会的な入口(C10 の R5〜R7)と熟慮層の内省(記憶 M7)が実装されるまで、上限を外しても人の思考量(4,000〜6,240/日)には近づかない。判断層(D-101)で「安い器」を足す方向と整合。
- **会話は「起点」と「材料」の問題**。予算・呼数ではない。C10 の R5(会話の起点)・R6(知人の結線)・R7(社会系の起床)・R11(会話の記録)と D-105(会話の意味は LLM)にそのまま材料になる。「ひと言」を相手に届けない現状は憲法 3「実文のない会話が世界を動かすことを禁止」の観点でも要修正(記録のみ)。
- **「理由」欄は費用だけ払っている**(出力 37 tok の約 1/3)。判断層の教師データ(D-101 (iv))としては価値があるので、捨てるかどうかは D-101 と一緒に決める。
- **役割語は 2 段で死んでいる**(8B が選ばない+選んでも待機に落ちる)。C6 の「役割語率 0」の原因は両方。
