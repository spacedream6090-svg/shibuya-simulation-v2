## 1. ① パーサが別名表に無いラベルを対象の値として読む(第266)

**欠陥**: `parse_two_line` は「理由/行動/対象/ひと言」のラベルを別名表([parser.py](../../../../src/shibuya/llm/parser.py) `LABEL_ALIASES`)で走査する。表に無いラベル(「目標:」)は走査に掛からず、行動欄の値が「移動 目標: 飲食店」になる。位置引数の回収 `_fill_positional` が余りの先頭トークン「目標:」を**対象の値**として採り、`format_ok` は True のまま(=書式エラー率に出ない)。値「飲食店」は捨てられていた。

**修正**(切替口は無し=パーサは決定論の純関数。受入指標 `strict_format_ok` は V0 表のままで分母を動かさない):
1. テープで実測された表層 7 語を別名表 `LABEL_ALIASES_D113` に足す(→ 対象): 目標 32,736 呼・カテゴリ 1,984・目的先 523・ターゲット 378・对象 127・目标 57・行く先 19(8 テープ合計・修正前の対象欄に「語+コロン」だけが入っていた 36,123 呼の内訳上位)。C6 の別名と同じ扱い(`alias_used`・`strict_format_ok` は False)。
2. 一般則: 位置引数の回収で「語+コロン」だけのトークン(`^[^\s:：]{1,10}[:：]$`)は**値ではなく未知のラベル**として読み飛ばし、診断 `unknown_label:<表層>` を `errors` に残す。後ろに値が無ければ欄落ち(`format_ok` False)。
3. `positional_used` は `positional:` の診断があるときだけ True(未知ラベルの読み飛ばしだけでは立てない)。
- テスト: [tests/llm/test_parser.py](../../../../tests/llm/test_parser.py) に D-113 の 6 本(+別名表の形の検査を更新)。parser 系 134 passed。

## 2. ② 通報の前提「当該事象を知覚済み」が未検査(第267)

**欠陥**(第263 ②): 行動契約書 §2.1 の通報の前提は「通報先が存在・当該事象を知覚済み」だが、`resolve._apply_record_only` は検査せず必ず成功にしていた。C7 の 39 万体テープでは通報 423 呼のうち観測に事象があったのは 7 呼。D-57(過剰通報)の (b) と同じ処方。

**修正**(切替口 `--report-precondition {on,off}`・既定 on・`run_day(report_precondition=)`・`resolve.apply(salient=, report_precondition=)`):
1. `SalientProcess.event_seen_tick`(体ごとに「顕著行為の行が自分のセルの B4 に載った最後の tick」・−1=未)。B4 の事象の行は**セル単位**(`_build_cell_lines`)なので、事象のセルに居た全員=観測に行が出た全員を知覚済みとする(`p_notice` は起床の到達判定で別)。予算で落ちた事象・報道(broadcast)は載らないので数えない。
2. `resolve._apply_report`: `tick − event_seen_tick ≤ REPORT_WINDOW_TICKS`(5 tick)なら成立、それ以外は `BAD_TARGET`(通報すべき事象が無い)。窓 5 tick は t_apply = 起床 + δ_perc + δ_think の最長レーン L3(300 s)からの導出値(mock/L1 は 1 tick)。効果先(事象レコードに通報 1 件 → 検知確率)は未実装のまま=成立しても状態は変えない。過程 OFF(`salient=None`)なら従来どおり(C2 互換)。
3. 診断: `ResolveOutcome.n_report_ok / n_report_no_event` → `RunResult` に集計し summary に 1 行(通報 0 のランでは summary 不変)。
- テスト: `tests/engine/test_resolve.py` +4(前提・窓の境界・切替 off・断るは不変)・`tests/engine/processes/test_salient.py` +2(事象のセルの全員に tick が付く・窓は閉区間)。resolve+salient 47 passed。
