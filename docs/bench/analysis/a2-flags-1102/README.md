## §2 定義

- 範囲: W6 の POI のうち、主のタグが経済センサスの民営の大分類に写るもの **2,112 件**。対象外は、生タグなし 78・店でないもの 51・業種が決まらない事務所 70・公務と公営 20・空き店舗 6 の計 225 件。写像の表は設計の文書 §2-3 とスクリプトの `major_of()` にあります。
- OSM の割合(物差し 3 案):
  - (a) `brand`・`brand:ja`・`brand:en`・`brand:wikidata` のどれかがある(A2 の 2 の文言どおり)
  - (b) `brand:wikidata` がある
  - (c) (a) から shop=convenience と「operator が brand と別の名」を除いたもの=値付けの旗が本社になる数
- センサスの法人の割合 = (会社 + 会社以外の法人) ÷ 総数(民営の事業所数)= 100 − 個人の割合。渋谷区の全産業では総数 27,624 = 個人 3,262 + 会社 22,803 + 会社以外の法人 1,559(和が合う)。
- 差 = OSM の割合 − 法人の割合(ポイント)。
- 参考の列 = 渋谷区に本所のある企業等のうち、複数の事業所を持つ企業の割合(`0003449701`)。数えるのは本所の所在地なので、渋谷区の店の数え方とは違います。

## §4 読み方

1. **向きは崩れていない**: brand の割合が法人の割合を上回った業種は 0(12 業種すべてで brand ≤ 法人。JSON の `upper_bound_check_brand_le_corp`)。チェーンの店がほぼ法人であれば、法人の割合は本社の旗の割合の上限になります。
2. **「ずれが大きい」は全業種で成り立つ**: 二つの量は物差しが違うためです。法人には 1 店だけの会社が入ります。差が 20 ポイント以上という一覧は全業種になり、業種を見分ける働きをしません。比べる相手をどうするかは設計の文書 §7 の題 4 です。
3. **差の中身は二つ**で、いまの表では分けられません。
   - 法人だが brand の無い店(1 店だけの会社・小さなチェーン)。
   - OSM のタグの抜け。郵便局 11 件は brand が無く `operator=日本郵便` でした。名の照合では、brand の無い POI のうち 11 件が他の要素の brand の名を含んでいました(不二家 2・丸亀製麺・Kirin City 2・土間土間・L'Occitane・Ueshima Coffee House・TOM FORD。「LIFE」の 2 件は誤当たり)。
4. **参考の列(複数事業所の企業の割合)は brand の割合に近い**: I 20.3% 対 38.2%、M 12.2% 対 16.0%、N 11.7% 対 14.2%。ただし本所の所在地で数えた企業の割合で、店の割合ではありません。近いのは偶然かもしれません(推測)。
5. **operator はフランチャイズの印にならない**: brand と operator の 43 組を目視で読むと、本社の法人名(セブンイレブン・ジャパン・シャノアール・ドトールコーヒー・ゼンショー・すかいらーく・元気寿司・KDDI ほか)か、入居する建物の名(Shibuya Hikarie 5 件)でした。加盟者と読める名は見当たりません。文字の比べ方(正規化+包含)で「別の名」とした 32 件も、本社の名の書き方の違い(7-ELEVEN とセブンイレブン・ジャパンなど)です。物差し (c) は実質「コンビニ 91 件を値付けだけ店に戻す」案になります。

## §5 限界

- **brand はチェーンかどうかの代理で、法人格と同じではない**(R-134 §5): 1 店だけの会社は法人で brand を持ちません。加盟店(フランチャイズ)の多くは加盟者の事業所として数えられるはずですが、調査の定義書は読んでいません(推測=R-134 §8 の 5)。
- **フランチャイズは契約で値付けが店に残りうる**: 公取委の排除措置命令(平成 21 年(措)第 8 号)は、加盟店基本契約では加盟者が販売価格を自ら決めると認定しています(R-134 §5-2。本書では原典を読み直していない)。旗を「権利の事実」で書くか「実際の慣行」で書くかで、コンビニの値付けの旗は逆になります。
- **OSM の網羅率**: brand のタグの付け方は地域と編集者で偏ります。W6 の 2,337 POI がセンサスの事業所(渋谷区 27,624)のどれだけを覆うかも分かりません。範囲も違います。OSM の取得範囲は経緯度の箱(渋谷駅の周り)で、区の一部だけを覆い、区の外を含む可能性があります(推測)。センサスは区全体です。
- **業種の大分類が粗い**: センサスの I(卸売業，小売業)は渋谷区の卸売の事務所を含みます。OSM の I はほぼ小売の店だけです。小分類の表 9-2 が無いので分けられません。
- **写像の推測**: JSIC の項目を確かめていない行が 6 つあります(internet_cafe・studio・copyshop・printing・craft・library の公営の扱い。W6 で 17 件)。
- **表の範囲**: 表 2-1 は「売上(収入)金額等」の集計の表です。事業内容等が不詳の事業所の扱いは確かめていません(推測)。
- **名の照合**は expedient です(ASCII の名は語の境で 4 字以上、ほかは 3 字以上を含めば当たり)。誤当たりを含むので、数は目安にだけ使います。
