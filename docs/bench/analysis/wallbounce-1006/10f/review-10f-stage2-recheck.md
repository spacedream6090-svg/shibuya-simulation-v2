### `world.synthetic` を母集団の側にした理由の是非

**是**。中身は格子の上の店の種別と初期在庫で、世界資産(固定のデータ)の代わりの舞台の構造にあたる。日ごとに変わる出来事ではない。環境の側に置くと「天気も変える」比較で地図そのものが salt ごとに変わる、という理由は筋が通る。ユーザー決定の環境の範囲(気象・催し・工事)とも食い違わない。ただし、理由の 2 つ目「mock の日課の拠点はこの世界のセルの上に引く」は弱い。`synthesize` が読むのはセルの数だけで、世界の中身は読まない。名前の `population_seed` が「体の属性+代用の舞台の構造」を決めることは、表の説明に書いてあるのでよい。

## 5. 欠陥(重さ順)

### T1 道路工事の過程に `day_index` が渡っていない(既定以外で今と違うラン)

- どこで: `engine/processes/runner.py` の `RoadWorksProcess(...)` の行。
  ```
  world, self.assets, master_seed=_env_seed,  # 10f(S1): 環境の側 day_index=day_key,
  ```
  `day_index=day_key,` がコメントの中に入り、既定の 0 が使われる。
- 影響: 0 日目の工事の辺は、`relay_day` が呼ばれない(1 日目から呼ぶ)ので、構築のときの日の鍵で決まる。`day_index` が 0 でないラン(`run_day(day_index=…)`・`cli.run(day_index=…)`・`python -m shibuya.engine.run --day`)では、0 日目の工事の辺が HEAD と違う(§1 の 7)。`real` の暦は `day_key(0)=0` なので同じ。「省略すると今と同じラン」が既定以外で崩れる。自分で回した 2 本(300 体・2,000 体 edge)では final は変わらなかったが、工事の辺と夜の封鎖は違う。byte-check の 19 構成は全部 `day_index=0` なので出ない。
- 直し方: `master_seed=_env_seed, day_index=day_key,  # 10f(S1): 環境の側` にする(写しで直して HEAD と同じになることを確かめた)。試験を 1 件足す: `day_index=3` のランで、0 日目の `road_works.planned_edges` が `stream(環境の seed, "world.road_works", 3)` から引いた辺と同じ。

### T3 README §11 の設計書への注記の案文は、気象について言い過ぎ

- 案文の「上の 3 本の根拠(salt 間 JSD)は 10f より前の値で、**母集団の抽出と環境のばらつきを含む幅**である」について:
  1. 気象: 既定のランは影のある日に絞る(`prefer_shadow_days`。第111 からある。第202・第204 より前)。今の資産では、seed を変えても実日は 2026-07-28 の 1 日に決まる(§1 の 2)。当時の W9 の再生日の数は確かめていないが、「気象のばらつきを含む」とは言えない見込みが高い。seed で変わっていた環境は、大きな催しの会場と道路工事の辺。
  2. 母集団の抽出: 39 万体の行は、W16 の母集団 390,067 人とほぼ全数なので、抽出の揺れはほとんど無い(体数が 390,067 以上なら `sample_population` は全数を返す)。5,000 体の行(AB7)は抽出を含む。
- 直す案(親が写す前に): 「10f より前の値で、母集団の抽出(5,000 体のとき)と、大きな催しの会場・道路工事の抽選のばらつきを含む幅である。気象の再生実日は影のある日への絞りで seed に依らず同じ日だった」。ほかの文(salt=動きの seed・省略で salt と同じ値・`--environment-mode fixed|salt`・入荷は動きの側のつなぎ)は事実どおり。

### T4 静的な網羅の試験に残る穴(低い)

- `_IGNORE` の `"?domain"` は全部のファイルに効く。`core.rng` の外で `def f(seed, domain): stream(seed, domain)` の形の関数を足すと、静的には拾わない(実行時の試験で回る経路なら落ちる)。案: `"?domain"` の無視を `core/rng.py` だけに絞る。
- seed の近くのハッシュの検査は、関数の中で、引数か呼び出しの式に `seed` の字があるものだけを見る。塩を別の名前の属性に持って後でハッシュする形と、モジュールの直下の呼び出しは拾わない。今の src に該当は無い。
