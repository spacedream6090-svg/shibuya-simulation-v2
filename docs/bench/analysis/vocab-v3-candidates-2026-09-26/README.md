## 0. 読み方(区分の定義)

| 区分 | 意味 | 落ち先 |
|---|---|---|
| **エンジンで実行可能** | 効果を書き込む欄が世界状態(registry・POI・crowd・内受容)に**ある**か、既存の機構(候補の絞り込み・在店・観測)の組み合わせで前提/効果/失敗が書ける | 契約行(前提・効果・コスト・失敗・台帳照合)+エンジンの適用分岐+テスト+パターン台帳 1 行=D-92 (a) の「手続きの門」 |
