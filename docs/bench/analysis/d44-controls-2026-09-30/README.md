## 7. 読み(親への材料)

1. **分布の JSD は対ごとの入れ替えを見ない**: W2#3(代表ノード)と W3#1(ノード対の中央値)は距離の分布では帰無内だが、対ごとには平均 40 m・24 m 動く(6〜7 割の対が 10 m 以上)。エンジンは距離表を対で読む。片側規則の「入力側の分布」を対単位の量にするか(例: 対ごとの差の分布)は親判断。
2. **W12 の切替口 `PM_PEAK_ASSUMED_EQUAL_TO_AM` は効かない**: `peak_tph_pm=None if PM_PEAK_ASSUMED_EQUAL_TO_AM else tph` はどちらでも朝と同数を渡す(src は触っていない)。
3. **山手線 18 本/h は実質 20 本/h**: 等間隔ダイヤの間隔が `round(60/18)=3` 分に丸められ、18 と 20 が同じダイヤになる。
4. **W17 の時刻修復(切替口)は on でもほとんど動かない**: 不一致 36,039 行のうち動いたのは 686 行(最小ブロック長の条件で飛ばされる)。

6. **N の大きい指標では帰無がほぼ 0**(W8・W9・W16#9 など)=小さな決定論の差も検出=ラン対照へ(保守側)。境界上: W9#3(0.0000617 vs 0.0000662)・W12#2(0.00509 vs 0.00565)。
