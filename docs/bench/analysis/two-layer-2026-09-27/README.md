## 3. 読み(事実だけ・推奨ではない)

1. **v1 の既定 checkpoint は段 1〜3 を通して不変**(`2f3969cf`・(c) と台帳 §0-1)。旧 6 種も切替口で完全再現する。
2. (a) は (b) より呼が **+11.1%**(36,460 vs 32,808)。内訳は、満了が 12,151 呼(全体の 33.3%)増え、場所が −87.6%(737 vs 5,946)・日課が −20.6%(13,076 vs 16,464)・会話が −12.7%(1,330 vs 1,524)減った。体(内受容)はほぼ同じ(9,166 vs 8,874)。
3. 満了候補 24,594 のうち呼になったのは 12,151(49.4%)。残りは同じ tick の他の条件との合流・予算の繰り延べ・就寝抑止(満了は就寝抑止の例外にしない=第276 #4)のどれか(内訳は数えていない=§4)。
4. **失敗即時は 0**(段 2 時点の v3=mock が v1 形を返し活動が常に「なし」だった版では 17,545)。mock v3 は活動を常に 6 語のどれかで返すので、この規則(失敗+活動なし)は発火しない。段 2 時点の v3 の呼 38,734(7.75 呼/体/日)は 36,460(7.29)に下がった。
5. 書式エラー率は 3 本とも 0.000(mock v3 の 5 ラベル形がパーサ v3 の厳密判定を通る)。
6. 行為の分布は (a)(b) とも 12 語でほぼ一様(LLM 由来の行為は (a) 各 2,498〜3,123・(b) 各 2,365〜2,793)。(a) の 移動 6,253 のうち 3,196 は**あたりで着いた体の次の歩**(エンジンが出す 移動)で、LLM 由来の 移動 は約 3,057。エンジン継続(経路の 1 歩)は (a) が 162,812 と (b)(c) の約 1.4 倍=あたりの歩行で歩いている体が増えた。
7. 購入+食事の成立は (a) 3,901・(b) 4,016・(c) 1,497(v1 は 食事 が無く、食べる→購入 の辞書も mock では働かない=mock は語彙語だけを返す)。
8. 相手で満了は 0(mock の「まで」に「相手」が無い=この経路は mock では通らない)。到着で満了は 704。
