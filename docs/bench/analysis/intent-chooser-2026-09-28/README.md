## 1. 何を足したか

- **口**(`engine/chooser.py`): `Chooser.probs(candidates, context) -> 確率`(和 1・候補が空なら空)。`ChoiceContext`=体 id・tick・現在セル・現在ノード・行為コード・対象の種類(名指し/カテゴリ/なし)・対象の文字列・空腹の段・可視(W8 の視点数)・距離(W3 `cell_dist`=**実行時に初めて読む**・同じセルは 0)。抽選は `core.rng.stream(seed, "engine.chooser", tick, agent_id)`(one-hot でも抽選を通す)。
- **既定の選び手 `NearestChooser`**(憲法⑥の宣言つき暫定): 距離の昇順 → 可視(視点数)の降順 → POI 索引。可視=`World.poi_visibility`=W8 `w8_t1_cell` の「その POI の自分のセルの視点のうち見えている数」(実資産 2,309/2,337 が > 0)。
- **候補**(`engine/poi_target.py`): 現在セルの POI のうち **意図に合う**(食事=`eatery_mask`・購入/並ぶ=**店舗系 cat `BUYABLE_CATS`**=food・shop・nightlife・service・leisure・cinema・attraction。除く office・hotel・school・landmark・hall・education=Q12。合成世界の 3 種 コンビニ/飲食/物販 は作りからして店なので候補に入れる=`SYNTHETIC_BUYABLE_CATS`・実資産の cat とは重ならない)∧ カテゴリなら**カテゴリ一致** ∧ **営業中**(`open_mask`)∧ 購入(と並ぶの飲食店以外)は**棚在庫 > 0**。名指しは候補を**その店**に絞る。セル外の名指しは段 2c=いまは失敗。
- **対象欄の読みの順**: (a0) 総称語(店・店舗・ショップ・お店)→ なし (a) 全体がカテゴリ語 → カテゴリ (b) `food1954` 形(描画の合成名=cat+索引)→ 名指し (c) POI 名(完全一致 → 名⊂入力 → 入力⊂名・C9b の目印照合と同じ順)→ 名指し (d) カテゴリ語を含む → カテゴリ (e) それ以外(なし・説明語・セル ID・人 ID・自由文)→ なし。
- **落選の理由**(候補 0): 合う店が無い → 対象 −1(購入/並ぶ=`BAD_TARGET`・食事=`NOT_IN_EATERY`)/ 合う店は全部閉店 → その代表 1 件(`CLOSED`)/ 開いているが全部在庫切れ → その代表 1 件(`OUT_OF_STOCK`)/ 名指しがセルに無い → −1(理由 `named_out_of_cell`)。結果コードは `engine.resolve` の既存の判定がそのまま付ける(新しいコードは作っていない)。
- **計数**(manifest `target_resolution`): `i_named`・`ii_category`・`iii_none`・`iv_no_candidate`(理由別)・`iv_by_kind`(対象の種類 × 理由)・`attempts`(種類別)・`chooser_entropy_mean_bits`(nearest は one-hot=0)。`--poi-target legacy` のランは空 dict。
- **切替口 `--poi-target {candidates,legacy}`**(Q13・既定 candidates): `legacy`=段 2a 前の「現在セルの最小 id」(`commit._poi_in_cell`)をそのまま通す=**旧 checkpoint の再現用**。
- **触っていないもの**: 移動の行き先(2b)・意図の保持(2c)・乗車のホーム選択(A13)・C9b の近づく・語彙・契約表・B0・W7・W17・W10 の切替口(既定 OFF のまま)・資産。

## 5. 対応表 v0(第286・宣言・59 語・`engine/poi_target.CATEGORY_WORDS`)

POI が「cat が集合に入る **または** subcat が集合に入る」とき一致。長い語から照合。総称語(店・店舗・ショップ・お店)は「なし」。

| 飲食 | 夜間営業の飲食店 → nightlife・飲食店/レストラン/食堂/飲食/ラーメン → food・カフェ/喫茶店/喫茶 → food・居酒屋/バー → nightlife・食事 → food |
| 食品・飲み物(買う物) | 食品カテゴリ/食料品/食品店/食品/食料/食べ物/飲み物/ドリンク/飲料/コーヒー → food ∪ subcat convenience |

## 6. 問いと空欄

- Q11〜Q15 は親が決めた(冒頭)。
- 空欄: 実 LLM で選び手が効く場面((ii)(iii) の候補が 2 件以上)の割合(nearest は one-hot=エントロピー 0)。在庫切れの理由はリプレイでは測れない(テープに在庫の状態が無い)。対応表 v0 の語の過不足(実 LLM の対象欄の語の被覆)は GPU 後。
