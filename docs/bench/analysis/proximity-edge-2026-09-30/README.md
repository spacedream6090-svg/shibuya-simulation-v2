## 0. 先に結論(親への要点)

1. **edge 幾何でも、止まっている体はノードの座標の上に居る。** そのため edge は「実距離の正解」にならない。
   - `resolve.py:1459-1470`: 位置を確定するとき、「MOVING かつ目的あり」でない体は `snap_to_nearest_node` でノードへ吸着する。
   - `resolve.py:1392-1403`: 新しい行動を選んだ体も同じく吸着する。
   - 辺の上の位置を持つのは歩いている間だけ。
   - 結果として、2 m 内の組のうち距離がちょうど 0 の割合は **node 99.95%・edge 99.94%**(mock off)で、ほとんど変わらない。同席の検出も両方の幾何で **99.9% が 0 m**。
   - つまり「同セル ∧ 2 m 内」は、止まっている体どうしでは**どちらの幾何でも「同じノード」と同義**。node ÷ edge の比は「重なりの水増し」を測っていない。
2. **node ÷ edge で重なりの水増しが本当に見えるのは、歩行中の体どうしの量だけ。**
   - 瞬間の群れ歩き: mock 0.281 → 0.023(12×)・classical 0.207 → 0.013(15×)。
   - 5 分連続の同行: 0.115 → 0.0009(125×)・0.037 → 0.00007(531×)。
   - C10 の量(偶然・知人出現・同席・B5)は **0.68〜1.18 倍**。edge の方が多いものもある。この差は重なりではなく、歩く速さの違いで生活の動きが変わったことによる(下の 3)。
3. **Q155 の推定(変位 0 の体を数えない)は主因ではない。**
   - 主因は歩く速さ。node は 1 tick に 1 ノード進む(`resolve.py:1519` `step_once`)=歩行者 1 体・分あたり **24.5 m**。edge は距離の予算で進む(`resolve.py:1523-1533`)=**65.3 m**。
   - 同じ移動を 2.7 倍速く終えるので、1 回の移動が 18.3 分 → 6.5 分になり、移動中の体・分が半分以下になる。
   - 変位 0 を含めて数え直しても、node ÷ edge は 2.30 → 2.08 にしか縮まらない(mock)。
4. **会話は「同じ 100 m セル」で成立している**(v3 × edge では `attention_on` が偽=`run.py:2103`。edge でも同セル代用のまま)。
   - 成立した時点の 2 体の距離が 2 m を超える会話: node 22〜40%・edge 14〜20%。
   - 10 m を超える会話: node 18〜26%・edge 14〜20%。最大は 108 m。
   - 逆に「2 m 内に居るのに別セル」の組は tick あたり node 4.6〜25.6・edge 0.16〜1.9(小さい)。
5. **知人出現の起床は、実距離ではなく「同じセルに現れた」で起きる**(`relations.py:955`)。
   - 起床のとき知人までの距離の中央は node 28 m・edge 19 m。2 m 以内は 20〜30% だけ。p99 は約 100 m。
   - 「知人が目の前に現れた」ではなく「同じ 100 m 升目に入った」の計数である。
6. **本当の水増しの率は、既存の腕では測れない。** 止まっている体に連続の位置を与える計器(§5)が要る。

## 3. 読み

- **近接の水増しには 2 つの源があり、edge 幾何が取り除くのは 1 つだけ。**
  - (i) 歩行中の体がノードに重なる → edge で消える(群れ歩き・同行)。
  - (ii) 止まっている体がノードに重なる → edge でも残る(`resolve.py:1459-1470` の吸着)。偶然・同席・B5 の 0 m・2 m 内の組の 99.9% はこちら。
  - (ii) を取り除くには、止まっている体に連続の位置を与える必要がある(D 層・物理/ナビメッシュ=指示書 §1-4 の「位置の正本は物理の xy」)。
- **C10 の量は、2 m を使っていても「同じノード」の判定になっている。** どちらの幾何でも、2 m 内の判定は「同じノードに居るか」とほぼ同じ意味(0 m が 99〜100%)。「2 m」という値は効いていない。
- **会話と知人出現は、100 m セルの粗さに支配されている**(§1-3 の「141 m 離れても会話でき、1 m 隣でもできない」を実測で確かめた)。会話の 14〜40% は 2 m 超・14〜26% は 10 m 超・最大 108 m。知人出現の起床の 70〜80% は、知人が 2 m より遠い。
- **node ÷ edge の比は、(ii) の水増しの率として読めない。** edge は歩く速さが 2.7 倍で生活の動きが変わる(呼数 −5%・セッション ±20%)ので、比には動きの差が混ざる。C10 の量の比 0.68〜1.18 は「水増しが無い」証拠ではない。

## 7. 親への問い

- **P1**(追加 B の範囲): 印を「node 幾何」ではなく「ノード座標の位置(node 幾何・edge 幾何の止まっている体)」で出た近接の値に付けるか。edge の値も止まっている体の近接は 0 m が 99.9% で、同じ重なりを含む。
- **P2**(同席の腕の測り場所): 指示書 §3-1 Q91 の「測るのは edge 幾何か物理の上で」は、本回の結果では「物理(または止まっている体に連続の位置を与える腕)の上で」だけが成り立つ。ユーザーへの訂正の報告が要るか。
- **P3**(§0-5 順番 2 の口): 「会話と近接を実距離で判定(まず既存の edge の腕で)」は、v3 では edge でも `attention_on` が偽(`run.py:2103`)なので、そのままでは実距離にならない。加えて、止まっている体どうしは 2 m 内=同じノードなので、実距離の判定を入れても止まっている体の会話は「同じノードの人とだけ」になる(1 m 隣の別ノードとは話せず、同じノードなら 0 m 扱い)。滞在点を散らす腕を先に置くか、会話の判定の口を先に置くか。
- **P4**(Q155 の結論): 「変位 0 を数えない」は主因ではなく、主因は node の 1 tick 1 ノード(平均 24.5 m/分=0.41 m/s)。node 幾何の「移動中の体・分」「移動中の呼」を使う他の量(移動中の広告露出の 6 割など)にも速さの歪みが入る。これも暫定の印の対象にするか。
- **P5**(8b の +37〜45%): いまのエンジンでは node +28%/+34%・edge +36%/+54%。記録の値を書き換えず「第300 時点」と注記するか。
