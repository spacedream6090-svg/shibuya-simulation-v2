## 2. 読み(親)

- **時刻軸(M3)は入力を本物にするだけで動く**(P1a)。勤務開始の :00/:30 は現実の帯に入り、出勤代理のエントロピーは 1.7→3.6 bit(現実 4.7)。ただし :00/:30 は現実より少ない側へ行き過ぎ(0.51 vs 0.675)=「ビン内 15 分一様」の expedient が現実の丸め癖を消し過ぎ。**ビン内分布を現実の :00/:15/:30/:45 比(40.8/15.7/26.8/16.8)に合わせる**のが次の一手(expedient の較正)。
- **活動数(M4a)は文法を緩めた腕でしか動かない**(事前予告どおり)。P1b は sd 0.67→2.06、P2 は 1.69。
- **並びの多様性(M2)は P1b/P2 で大きく増える**(種類率 0.22→0.85・上位 1 型 10%→1%)。**モチーフ(M1)は P1b/P2 で現実より細分化**(39/32 個で 70〜80% 被覆・現実 17 個で 90%)=上限側の門番に触れる。原因候補=文法緩和で場所の遷移が増える・cell 未解決の近似。
- **個人内一貫性(M6)**: P0 は平日 96% が完全一致(週次表が 1 日のコピー)。P2 は 81%・P1b 54%。現実側の直接アンカーは無いが、Song の「規則性は活動に内在」と Schneider の少数モチーフを踏まえると、**P2 の「平日はほぼ同じ・週末が違う」形は方向として自然**。P1b の 54% は文法緩和による日ごとのばらつき(切断 45% の影響を含む)。
- **弊害**: P2 のみ被覆率 1.0・深夜違反 0.5%(文法で禁止)・就寝行 94%。P1a/P1b は被覆・就寝行が悪化(時刻を細かく渡すと 4〜5 行では 1 日を覆えない)。
- **注記(第159・親)**: P2 の段2 は旧規約(同一性文 200 字未満は投入しない)のため **同一性が入っていたのは 976/2,000 体・1,024 体は事実だけ**で書いていた(段1 実応答の p50 198 字)。P2 の値は同一性の効果を半分しか含まない。P2′ では下限を 80 字に下げ 2,000/2,000 を投入。
- **同一性文(P2 段1・2,000 本)**: 完全重複 0・文字 2-gram の平均 Jaccard 0.205。**表層は型に寄る**(88% が「朝は」で始まる・47% に「起きまして」・58% にコンビニ)=8B の類型化+質問 3 つの型。行動レベル(M2/M6)では多様性が出ている。
- **費用**: 8B・7 基で 2,000 呼 ≈ 6〜7 分(約 4.7 呼/s・出力 600 tok)。P2 段2 は 1024 tok で 13 分。本番 390,067 呼なら P1 ≈ 5.5 h・P2 ≈ 2 段で 14〜16 h(切断を減らすため max_tokens を上げるとさらに)。

## 3. 32B 比較腕(P2 と同じプロンプト・GPU 5/6 を Qwen3-32B-AWQ TP2 へ一時切替)

## 4. 採否(親案・ユーザー判断・32B は §3 の追記後に確定)

**合格線候補(設計 §5)との照合**: M3b :00+:30 の帯 0.55〜0.82 → P1a 0.51・P1b 0.49・P2 0.41=**帯の下に出た(到達せず)**/M3b H ≥4.0 → 3.6(到達せず)/最頻ビン ≤0.20 → 0.24〜0.45(到達せず)/M6 完全一致 ≤0.20 → 0.54〜0.81(到達せず)/M4a sd ≥1.0 → P1b 2.06・P2 1.69(到達)/門番: 被覆 ≥0.999 → P2 のみ・深夜違反 0 → P2 0.5%(ほぼ)・parse 失敗 <0.02 → 全腕 OK。**線をそのまま当てると採れる腕は無い**が、動いた向きと原因ははっきりしている。

**親案**: **P2 の型(本人が書くブロック形式・切れ目なし・深夜禁止文法・{3,10}・面接形式の同一性)を W17 v2 の生成経路として採り、下の 3 点を直した P2′ を 1 回(艦隊 約 30 分)回してから本番へ**。
1. ~~ビン内の分の散らし方を現実の比に較正~~ **取り下げ(第159)**: 15 分ビン単位では第31表の分布どおりに引いており、ビン水準の :00/:30 は構成上ほぼ現実に一致する。下振れの主因は **8B が渡した分を丸める・出勤時刻に支度を置いて移動を後ろへずらす**こと(32B が同じ入力で 0.695 を出した=§3)。ビン内一様は expedient のまま宣言。
2. **`block_kind` を LLM に書かせない**(域外/自宅/在圏はエンジンが居住区分と場所語から導く)。P2 の LLM 由来修正率 0.287 はほぼ全部この欄の矛盾で、出力も短くなる。
3. **切断(P2 65%)を減らす**: `max_tokens` 1024→1536 か、行の書式を短く(HHMM-HHMM 活動語 場所語)。
4. **8B が分を丸める癖への手当**(§3 の 32B 比較で判明): 段2 の指示に「事実行の出勤・帰宅の時刻は分までそのまま使う」を足す。効かなければ「時刻は事実から置く」規則(ユーザー選好に反するので判断)。
- 8B のまま(32B の結果は §3 で確認・同一性文は 32B の方が語彙は散るが冒頭の型は同じ)。
- 本番費用: P2′ ≈ 2 段 × 390,067 呼 ≈ 14〜16 h(8B DP7)。P1 だけなら 5.5 h だが被覆・就寝行が悪化するので採らない。
- raking: 12% と 0% の両方を本番でも報告し、JSD_before(P2 自宅－勤務 0.069)を見て予算を決める(設計 §8-9)。
