## 3. 判定と含意

1. **L4=10 呼/体/日(5,000 体で 7.4)は結果を駆動している**。実現購入/体/日が ×0.5→無制限で 2.5 倍、売上 2.6 倍、乗車 −37%、購入 % 14 pp。expedient に課している「結果を駆動していない」検査に**予算行は落ちる**(D-44 の規則で言えば「ラン対照で駆動が出た」側)。
2. **これまでの ablation・holdout 照合(C7 本番 6.9 呼/体/日)は、上限の影の下で測っていた**。特に「購入 %」の差は起床構成の差を含む。以後の腕比較は D-98 の実現量/体/日で読む。
3. **上限をどこに置くかは設計判断**: (a) 無制限(5,000 体で壁時計は同じ 37 分・艦隊は余裕・40 万体では 2.1 倍=約 19 h/日で W1 24 h 内)/ (b) ×2(飽和の 96%)/ (c) 現行 ×1 のまま宣言に「結果を駆動する」と書く。親推奨は **(a) を 5,000 体の腕の既定・40 万体は ×2 を当面の既定**(理由: 上限が結果を作る量なら、上限の値を設計者が選ぶより外す方が指紋が薄い。40 万体は W1 の壁時計で決める)。ただし既定 checkpoint が動くのでユーザー判断(§2-6)。
4. 看板の効果(AB6b/AB6c)は予算の有無で符号が変わる小さな量だった=**予算の影が ±0.5 pp の幅で ablation の結果に混ざる**。AD1 の 1 pp 線は「予算の影 ±0.5 pp」を併記して読む(フロア併記)。
5. 思考の階層(D-101)の前提が固まった: 予算を外しても 15.5 呼/体/日・会話 0.006/体/日。**起床の口を増やさない限り量は増えない**。
