# D-91 (a) 診断 — 語彙 v2 で乗車が半減・休憩が倍増した原因(AB7c seed 1 テープ・2026-09-18・第235)

- **材料**: [AB7c seed 1 親報告](ab7c_s1_parent_report.md) のテープ 2 本(`data/tape/c8_ab7c_s1/AB7c-VOCAB-V2__vocab_v1` / `__vocab_v2`・calls 36,906 / 37,165・繰り延べ行 0)。読み取りのみ・追加ラン 0(PENDING D-91 (a)「進めてよい範囲」)。行動語は `parse_two_line(vocab_version=腕の版)` で読み直した(段0 辞書の写像は当てていない=移動が runner より ≤167 少ない。第227 と同じ)。
- **テープに無いもの(限界)**: 個体ブロック(B5 内受容=空腹・B6 直前の結果=失敗理由)はテープの block に入っていない(6 block 合計 807 tok vs 入力 1,403 tok)。**実現した乗車 `n_boarded` と食事の失敗理由は runner が記録しない**。以下は「LLM が何を選んだか」の分析で、「何が起きたか」ではない。

## 1. 2 腕の差は静的ブロックの 1 語(「/ 食事」)だけ

## 4. 乗車は「通勤の予定に結びついた行動」ではない(v1 でも散発的な選択)

- 06〜10 時に乗車を選んだ体: v1 380 体・v2 162 体・**共通 25 体**。v1 で朝に乗車した 380 体は v2 でも朝に平均 2.71 呼受けており(v1 では 2.27 呼)、その行動は 食事 454・移動 407・購入 70・休憩 34・乗車 25。
- 全日の乗車 907 呼(v1)は 812 体に散らばる(1 体 1〜2 回)。種別は 通勤者 422・来街者 251・居住者 189・従業者 44=**来街者・居住者も同じ率で「乗車」を選ぶ**。
- **乗車の選択の 9 割は駅が見えないセルで出る**: v1 907 中 B2 可視に駅 85(9.4%)・v2 485 中 48(9.9%)(**第263 訂正**: 旧記載 81/46 は転記誤り。v1 は親が再計算=907−822)。駅が見える呼での乗車率 2.7% / 1.6% vs 見えない呼 2.4% / 1.3%=場所依存がほぼ無い。B2 場所行はセル ID だけで駅・ホーム・改札の語を持たない(テンプレートに無い)ので「ホーム上か」はテープから判定できない。
- 駅の無い場所での乗車は D-51 の意図保持で「ホームへ歩く」に変わる(`resolve.py` `_BOARD_KEEP_ACTIONS`・打ち切り 30 tick)。**実現した乗車数は未測**=乗車 907→485 が在圏形状(holdout H1/H2)に効いたかは、この数字からは言えない。
- **訂正**: 第227 親報告 §2 の「通勤の乗車が半減」は誤読。半減したのは「乗車という語の選択」で、通勤に結びついた行動ではない。

## 5. 休憩 ×2.2 は「食事 → 休憩」の連鎖(8B の物語)

| 直前の行動 → 次手 | v1 | v2 |
|---|---|---|
| 購入 → 休憩 | 1,028 / 14,352 = **7.2%** | 125 / 1,632 = 7.7% |
| 食事 → 休憩 | — | 3,154 / 14,349 = **22.0%** |
| 購入 → 移動 | 61.6% | 28.5%(購入 → 食事 55.0%) |
| 食事 → 移動 | — | 65.7% |

- v2 の休憩 3,562 のうち **直前が食事 3,154(89%)**。v1 の休憩 1,616 は直前が購入 1,028(64%)・移動 463。13 時以降に集中するのは、食事の絶対数が昼以降に多い(13 時 1,049・14 時 995…)ことと「昼食後の休憩」という 8B の常識。食事が成立したか(選択の 57% が失敗)で次手が変わるかはテープでは分からない(B6 が無い)。
- 移動 −8.2 pp(13〜22 時)は休憩の増分と同じ時刻帯。食事の次手の移動率 65.7% は購入の次手 61.6% と変わらないので、**移動が減ったのではなく休憩が枠を食った**(呼数上限は一定)。

## 6. 結論(D-91 の判断材料)

1. **乗車半減は語彙 1 語の追加による選択の薄まり**(全状況で一様・呼数と起床は不変)。「朝の通勤乗車の消失」ではなく、v1 の乗車自体が予定に結びつかない散発的な選択(9 割が駅の見えない場所)。在圏形状への影響は「実現した乗車」で測るべきで、それは runner の記録に無い。
2. **休憩倍増は食後連鎖**(食事の 22% が休憩へ・購入の 7%)。人の食後休憩として不自然ではないが、休憩の解決(在店のまま/歩道で)は別途。
3. **未測 2 つ**: (i) 実現した乗車 `n_boarded`・待ち打ち切り `n_board_timeout`(`RunResult` にはある・runner の出力欄に無い) (ii) 食事の失敗理由別の次手(B6 がテープに無い)。(i) は runner の欄追加(tool 側・シミュレーション挙動は不変)で seed 3 以降に取れる。走行中の seed 2 は同じ制限。
4. **語彙 v2 の既定化について**: 診断の結果、v2 の付随変化は「LLM の選択の癖」で、世界状態の欠陥ではない。既定にするなら (i) を先に足して「実現乗車」を記録する構成で回す方が、次の holdout 照合(事前登録 v2)で帰属が濁らない。
