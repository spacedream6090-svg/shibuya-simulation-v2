## 3. 含意

1. **D-59 は閉じてよい**(親推奨・据え置き): AD1 は上限あり(2 seed)・無制限(1 seed)とも内側。較正(p_see 0.30/0.14)は購入を動かさない。切替口は残す。
2. 看板 → 休憩・会話の付随効果は**文面の注意配分の効果**として記録し、D-60(固定枠 vs 単一ランキング)と C10(会話率)へ渡す。
3. **L4 上限は「購入 %」の水準を 7.5 pp 動かす**(起床の構成が変わるため)。ablation の指標は D-98 の実現量/体/日へ。AB8(0.5×/1×/2×/無制限)で実現量の予算依存を確定する。
4. 無制限でも 15.5 呼/体/日で止まる。人並みの思考量には**起床の口そのもの**が要る(D-101)。

## 4. 限界

- seed 1 のみ(無制限)。同構成 seed 差は上限ありで 0.15〜0.40 pp。
- 5,000 体・1 日・現行文面(語彙 v1)。
- 「抑止」の内訳(就寝/域外/不応期)は runner の診断が合計しか出さない=内訳は次の課題。
