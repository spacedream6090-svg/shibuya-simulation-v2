## 2 指標(変更なし・`PREREG_V0`・JSD は底 2)

| 指標 | 内容 | 合格線 |
|---|---|---|
| H1 相関 | 5 エリア×24 時間シェアの JSD 平均・Pearson r | JSD ≤ 0.0122 かつ r ≥ 0.80 |
| H2 ピーク時刻 | エリア別ピーク時刻の差・順序の τ | 5/5 が ±1 h かつ τ ≥ 0.60 |
| H3 平日休日比 | **測定不能**(KDDI に曜日軸なし)→ 代替=深夜残存率(1〜4 時÷終日)の値と順序 | \|Δ\| ≤ 0.05 かつ τ ≥ 0.60 |
| H4 エリア構成 | 1 日シェアの JSD・シェア差 | JSD ≤ 0.0122 かつ \|Δ\| ≤ 0.05 |
| H5 属性構成 | エリア×(居住/勤務/来街)の JSD 平均・シェア差 | JSD 平均 ≤ 0.02 かつ \|Δ\| ≤ 0.10 |

固定する入力: 5 エリア写像 `tools/c7/area_axes_v0.json`(D-41・expedient・±50 m の感度を併記)/ 種別→属性写像 `c7lib.KIND_TO_ATTR` / 在圏の標本=毎正時の journal(`--occupancy-every 60`)→ `tools/c7/occupancy_series.py --journal` の JSON。時間帯は KDDI の 24 区分(5〜28 時)に合わせる(`holdout_compare.py` の既定)。

## 3 開封の手順(1 セッション・1 回)

1. c7-day-4 完走 → 受入表 `tools/c7/c7_accept.py`(HOLD/SEAL 以外の判定行が PASS)→ T2-c テープ再生の一致 → 在圏の物差し(c7-day-3 との前後比較)→ 層2(別 Fable)の独立検収(受入表と読み口 v2.1)。
2. 各腕の series JSON を作る(c7-day-2 は `docs/bench/c7/occupancy_series_c7-day-2.json` が既にある)。
3. **ユーザーの明示**(「開けてよい」)を待つ。親は実行の直前に確認する(D-43)。
4. 同一セッションで `tools/c7/holdout_compare.py --open-seal` を **主張腕 c7-day-4 から**呼ぶ(`--run-id c7-day-4 --manifest docs/bench/c7/accept_c7-day-4/checkpoints.json --write-manifest --out docs/bench/c7/holdout/c7-day-4`・開封記録 `docs/bench/c7/holdout_open_record.json` の初回=forced=false)。続けて c7-day-3・c7-day-2(・回してあれば c7-day-5)を `--force --run-id <腕名> --out docs/bench/c7/holdout/<腕名>` で呼ぶ(記録は `previous_openings` に積まれ初回の証跡が残る・v1.1)。`--force` の理由は「事前登録 v1.1 の腕集合の同一セッション照合」と登録簿(PENDING D-43 の行)に書く。生データを読む回数は腕の数だけだが、腕は本書で固定済みなので 1 回の開封と同義。
5. 結果は `docs/bench/c7/holdout/` に腕ごとの表+腕間の差(c7-day-2→3=計画実行層の効果・3→4=読み口 v2.1 の効果・4→5=出勤率の感度)。受入表 HOLD/SEAL 行を埋める。

## 4 開封前に書いておく予想(外れたら外れたと書く)

- c7-day-2 は H1・H2 を落とす(昼夜比 1.19=形状が平ら)。
- c7-day-3→c7-day-4 で朝の到着の山が約 40 分遅く・夕方の退出が早くなる(計画上の在圏 08 時 −41%・18 時 −12%)。H2 の朝側ピークは遅れる方向。H1 の JSD は下がる見込み(確信は低い=LLM 側の行動で在圏の骨格からずれる分がある)。
- 絶対水準(昼間 1.6〜1.9 倍・D-67)は H1/H4 がシェア形状なので直接は効かない。H5 属性構成は W16 の構成(従業者の概念差)が効くので落ちる可能性が高い=落ちたら D-67 (c)(第2陣)の根拠。
- c7-day-5(0.88)は H5 のシェア差を縮める方向だが、H1/H2 はほぼ変わらない見込み。

## 5 開封後の規律

- 開封後に読み口・W17 表・母集団・出勤率・計画実行層の設定を変えて回したランは「開封後の較正」=本 holdout に対する主張には使えない。次の主張には**新しい封印データ**(次の取得)が要る。
- c7-day-5 は本書で構成を固定しているので、開封後に回しても本書の腕として扱える(感度腕・主張腕ではない)。
- 本書の変更は、開封前なら版を上げて理由を書く(v1→v2)。開封後は変更しない(追記のみ)。
