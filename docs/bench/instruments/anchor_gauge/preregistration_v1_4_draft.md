- 記号: 体 i、エリア a(5 エリア)、時間帯 h、刻み t(Δt = 1 分)、種別 k。

## 1. 母集団

| 名 | 定義 | 扱い |
|---|---|---|
| P′(本則・仮採用) | { i : age_i ≥ 20 かつ is_foreign_i でない } | 合否の母集団 |
| P(継続の列) | { i : kind_i ≠ 7 かつ age_i ≥ 20 } | R-115 §4 の草案の形。P′ と並べて記録する |
| F(訪日の列) | { i : is_foreign_i かつ age_i ≥ 20 } | 別の列に記録し、合否に入れない |

- P と P′ の差は、W16 の業務来街(kind 1)のうち is_foreign で 20 歳以上の 5,268 体である(全年齢では 5,315 体=R-115 §5 主張 1。差の 47 体は 20 歳未満で、P と P′ のどちらにも入らない)。回答 10-13b §1 1-1 の文言は「訪日(kind 7)と 20 歳未満を除く」なので、is_foreign で除く形は親の指示による仮採用。ユーザーの確認が要る。
- 標本の 5,000 体は二層抽出なので、種別の構成が W16 と違う。体ごとに拡大係数 ω_k = N_k / n_k を掛けて W16 の規模に戻す。N_k は W16 の種別 k の体数、n_k は標本の体数(未リサーチ(expedient))。`expansion_factors`・`population_masks`

## 2. 属性(R-56 §2 の判定順)

エリア a について、次の順で決める。`attr_by_area`

1. area(home_i) = a なら居住者
2. そうでなく area(work_i) = a か area(school_i) = a なら勤務者
3. どちらでもなければ来街者

- area(c) はセル c の 5 エリアの索引。`tools/c7/area_axes_v0.json`(expedient)で決め、5 エリアの外と域外は −1。±50 m の膨張と収縮の感度を並べる。
- kind の写像(`c7lib.KIND_TO_ATTR`)は継続の記録として並べ、合否に入れない。`attr_by_kind`

## 3. 滞在(1 日単位)

- 体 i がエリア a に居た分: m_{i,a} = Σ_t 1[transit_{i,t} = 0 かつ area(cell_{i,t}) = a] · Δt
- 数える体: D_a = { i ∈ P′ : m_{i,a} ≥ 30 分 }。**合計**で数える(本則・仕分け C §2-1 の 5)。
- 原典の「30分以上滞在した人を１日単位でカウント」が連続か合計かは書かれていない [要確認]。そのため、最長の連続が 30 分以上の腕を感度として並べる。

計器の関数: `hour_minutes`・`daily_qualified`(`sum` / `cont`)

## 4. 時間帯別

- N^θ_{a,h} = Σ_{i ∈ D_a} ω_{k_i} · 1[ Σ_{t ∈ h} 1[transit_{i,t} = 0 かつ area(cell_{i,t}) = a] ≥ θ ]
- θ は 1 分(既定・仮採用)と 30 分(腕)の 2 つ。原典の「時間帯別の人数については１時間ごとにそれぞれカウント」の細部(その時間帯に何分いれば数えるか)は [要確認]。
- 正時の標本(v1.3 の数え方・1 日単位の条件なし)は継続の列として並べる。

計器の関数: `presence_hourly`・`presence_on_hour`

## 5. 時刻

- KDDI と同じ 5〜28 時の 24 区分を使う(`c7lib.KDDI_HOUR_BINS`)。
- 1 日ランの 24〜28 時は、同じ日の 0〜4 時で代える(宣言)。

## 6. 曜日

- シミュは平日 1 日で、W17 v2 は月曜の d0 を使う。KDDI の手元の表は年合算で、日種を持たない。そのため「平日のシミュ対全日の現実」の比較だと宣言する。
- 週末のランが 10-12 CA10 の条件を満たしたら、合成の腕を足す。重みは暦の年の平日の日数 n_wd と土休日の日数 n_re(内閣府の祝日の表)から n_wd/365・n_re/365 とする。

## 7. 指標の形(定義だけ・線は書かない)

| 量 | 定義 | 計器の関数 |
|---|---|---|
| ピーク時刻 | argmax_h N^θ_{a,h}(同点は早い時刻) | `peak_hour` |
| ピークの順 | 5 エリアをピーク時刻の昇順に並べる(同点はエリアの番号順) | `peaks_block` |
| 来街者/居住者の比 | V_a / Res_a。V_a = Σ_{i ∈ D_a, 来街者} ω、Res_a も同じ形 | `ratio_block` |
| 勤務者/居住者の比 | W_a / Res_a | `ratio_block` |
| 5 エリアの計 | 比はエリアの数の和どうしで割る | `ratio_block` の `total` |

## 8. 不足の宣言

都市圏の外の国内客(国内の宿泊客を含む)はシミュに居ない(R-109)。PT の調査対象も都市圏の居住者だけである。

## 9. 記録

主張に使う腕のランでは、体の journal を必ず書く。中身は刻みごとのセルと transit_state・kind・age・is_foreign・自宅/職場/学校のセルである。計器の `record` の段が書く。

## 10. フロア

現実同士のずれを、合否にせず併記する。来街/勤務の比は PT 2018 で 0.16〜0.27、KDDI で 1.66 である(`attr_arms.py` :57-59)。
