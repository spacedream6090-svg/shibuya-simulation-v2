- **一次確認**: 本書は規則の写しで主張をしない。正は [CLAUDE.md](../../CLAUDE.md) §5・§7
- **索引**: [INDEX.md](INDEX.md) ・ **作法**: [RESEARCH-STATE.md](RESEARCH-STATE.md) §5

> 2026-11-04・第344 起草([指示書 11-04](../design/prompt-2026-11-04-reply4.md) §1)。親は研究役(Opus 5.5)への発注文の末尾に、次の行をそのまま入れる。題ごとの中身(問い・範囲・既存答申・出力の形)は発注文の本文に書く。

## 発注文に必ず入れる行

```
- 子サブを起動しない。読んでいない項目は空欄のまま残し、記憶で埋めない。
- Web は読むだけ。リポにも data/ にも保存しない(許可された取得は CLAUDE.md §7 の一覧だけ)。
- サイトが取得を断った・403 を返した・規約や robots で禁じている場合、名乗り(User-Agent など)・経路・ミラー・キャッシュを変えて取りに行かない。取得せず「読めなかった」と §読めなかったもの に書く。
- 公開されている要旨の索引(Crossref など)は別の出典として可。web.archive.org・ミラー・キャッシュで、断られた頁や応答しない頁を読みに行かない。
- 索引のサイト(DOAJ・PubMed など)が断ったとき、原典の発行元の頁は別の出典として読んでよい。発行元の robots と規約を先に読むこと。原典そのものが断ったら読まない。索引の代わりに公開の索引(OpenAlex・Crossref)を使うのも可(11-09 §1-4 で追加)。
- curl などで頁を読むのは、許可の一覧の内側のドメインで、robots.txt と規約を先に読んでからだけ。robots や規約で断られていれば読まない。
- Web の道具が利用の上限に当たったら、別の道具に替えずに止まり、それまでの分を書いて「読めなかった」と報告する。
- 出典ごとに等級(本文を読んだ/要旨だけ/検索の抜粋だけ)を付ける。自分の組み立ては【見立て】、根拠のない置き方は【推測】と書く。推薦は書かない。
- 封印の層(holdout・test の層)に触れない。コード・台帳・設計書・INDEX を変えない。commit も git add もしない。
- 次の文書は開かない(開封の値が平文で載っている=[一覧](../reference/opened-values-in-docs-2026-11-09.md)・11-09 §6-3 の 2・⑥ 検証の封の壁打ちまで): IMPLEMENTED.md・docs/ops/build-report-C7*.md・docs/ops/build-report-C8*.md・docs/design/v2-g1-backtest-plan-2026-11-02.md・docs/design/v2-pattern-ledger.md。
```

## 親の検収で確かめること(断られた頁)

1. 答申の冒頭の取り方の注と「読めなかったもの」を読み、403・拒否・禁止の頁を挙げる。
2. その頁を別の名乗り・経路・ミラー・キャッシュで読もうとしていないか(注・研究役の報告)。 Web の道具の上限の後に別の道具へ替えていないか。curl を使った頁は robots と規約を先に読んだか(11-04c §2 の 2)。
3. その頁の内容が本文と出典の表に入っていないか(代わりに読んだ出典で書いているか)。
4. 結果を答申末尾の「親の一次確認」の表に 1 行で残す。
