## §1 人間移動科学の型 — 「戻る/探す」は 2 つの式で書けている

### 1-1 Song, Koren, Wang & Barabási 2010, Nat. Phys. 6:818-823 — EPR [実読]

文献メモ: [lit/mobility__song2010_epr.md](lit/mobility__song2010_epr.md)。出典 https://doi.org/10.1038/nphys1760 / 著者版 https://arxiv.org/abs/1010.0436(PDF を pymupdf で全文抽出)。

**2 つの式がすべて**:

```
探索: P_new = ρ · S^(-γ)          S = それまでに訪れた相異なる地点数
回帰: P_ret = 1 - ρ·S^(-γ) 、戻り先 i の確率 Π_i = f_i (その地点の過去訪問頻度)
```

| 記号 | 値 | 出所 | 備考 |
|---|---|---|---|
| **γ** | **0.21 ± 0.02** | Fig. 3a | 探索の逓減指数。**D2(1,000 人・2 週間)で測定** |
| **ρ** | **⟨ρ⟩ ≈ 0.6**・`P(ρ)` はほぼ正規分布 | 本文 | **個体差はここ 1 個に入る**。分散は本文に無い(空欄) |
| α | 0.55 ± 0.05 | 本文 | 跳躍距離。カットオフ Δr ≈ 100 km |
| β | 0.8 ± 0.1 | 本文 | 待ち時間。**カットオフ Δt = 17 時間** |
| μ | 実測 0.6±0.02 / 予測 0.67±0.07 | Fig. 1a・式(5) `μ = β/(1+γ)` | 既存答申の値の出所 |
| **δ**(既存答申の表記は ζ) | 実測 **1.2±0.1** / 予測 **1.21±0.02** | Fig. 1b・式(6) **`δ = 1+γ`** | **写し訂正**: 原典の記号は δ。値は同じ |
| 拘束 | **β = μ·δ**(δ>1) | 本文 | 3 指数が独立でないことの明示 |

- **優先的回帰は実測で直接確認されている**(Fig. 3b・逐語): 「The plot indicates that **Π = f**, confirming the validity of preferential return」。
- 標本: D1 = 携帯 **300 万人・1 年**。D2 = 位置情報サービス **1,000 人・2 週間・1 時間ごと**。**γ と ρ は D2 だけ**。
- 1 年で **89% の利用者が S < 148**。MSD の飽和は **t_s ≈ 5 年**後。

**本プロジェクトへの含意(3 点)**:

1. **「常連/探索の比」は 1 個のスカラー(ρ_i)と 1 個の状態(S_i)で書ける。**設計者の指紋が極小。
2. **戻り先の重みは訪問頻度そのもの**(`Π_i = f_i`)。ここに趣味や性格の重みを掛けると**先行の機構から外れる**(§4)。
3. **δ = 1+γ** なので、**γ を決めたら Zipf 指数は決まる**。Zipf を別に較正すると同じ量を 2 回較正することになる。

### 1-2 Pappalardo ほか 2015, Nat. Commun. 6:8166 — returners / explorers [実読]

文献メモ: [lit/mobility__pappalardo2015_returners-explorers.md](lit/mobility__pappalardo2015_returners-explorers.md)。

- **判定(二等分法・逐語)**: 「the bisector method classifies an individual as a k-returner if **r_g^(k) > r_g/2**」。`r_g^(k)` = 上位 k 頻度地点だけで計算した回転半径。SVM・EM でも同じ結果。
- **標本**: GSM = 欧州 CDR **3 か月・67,000 人**(約 300 万人から抽出)。GPS = 中部イタリア **約 46,000 台・1 か月**。
- **均衡する k(逐語)**: 「The population reaches a balance of k-returners and k-explorers **for k = 4** for GSM.」GPS は k≥2 で常に returner 優位。
- **k=2 の人口比**: **本文に直接の記述が無い**。Fig. 7 の無作為化基準線から **2-returner ≈ 21% / 2-explorer ≈ 79%**(GSM)と読める(逐語: 「obtaining **RR_rand ≈ 0.21**」「**EE_rand ≈ 0.78**」)。**この読みは本書の推論**=補足 Fig. 3 で親が確認すること(§7 ①)。
- **社会的同類性**: 2-returner の親友が 2-returner である割合 **RR ≈ 0.27**(無作為 0.21・p<10⁻⁵)。explorer 側 **EE ≈ 0.81**(無作為 0.78)。n 番目の友人まで n ≤ 15 で有意。
- **EPR では二分が出ない**(逐語): 「For k ≈ **60**, we have the perfect balance … as for the GSM data set for k = 4」「the EPR model **overestimates by more than an order of magnitude** the number of locations needed」。重力則を入れた **d-EPR で k ≈ 9**。
- **d-EPR も Song の値をそのまま使っている**(Box 1): β=0.8・τ=17 h・**ρ=0.6・γ=0.21**。探索先だけ重力則 `p_ij ∝ n_i n_j / r_ij²`(n = 集団の人気)、回帰先は訪問回数比例。

**含意**: **EPR を素で入れると「探索者だらけ」になる。**現実の二分は「**探索が集団の人気に引かれる**」ことで初めて出る。v2 の設計ドクトリン(世界の変化はエージェント行動の結果)と同じ向きだが、**d-EPR は重力則を外から押し込んでいる**ので、v2 では「人気」を観測(在圏・行列・看板)から LLM が受け取る形にするのが筋(§3-4)。

### 1-3 Schläpfer ほか 2021, Nature 593:522-527 — 訪問の普遍則 [実読・**新規**]

文献メモ: [lit/mobility__schlapfer2021_visitation-law.md](lit/mobility__schlapfer2021_visitation-law.md)。**既存答申に 1 行も無い**(`v2-pattern-ledger-deep-research.md` に別の Schläpfer 論文=社会的相互作用スケーリングへの言及があるだけ)。

- **式(1)**: `ρ_i(r,f) = μ_i / (rf)^η`、**η ≈ 2**。`ρ_i(r,f)` = 場所 i を、**自宅が距離 [r,r+δr) にあり期間 T のうち f 日訪れた**一意利用者の面積あたり人数。`μ_i` = その場所の魅力度。
- **当てはめ**: 全地域まとめ **K = 2.05(SE 0.018)・R² = 0.993**。Back Bay(Boston)単独 **K = 2.17(0.055)・R² = 0.973**。
- **対象**: Greater Boston / Lisbon・Porto・Braga / Singapore / Dakar / Abidjan。格子は **Boston と Singapore が 500 m**、他 1 km。
- **人気の場所ほど遠くから来る、ではない**(Fig. 2): 訪問者数 vs 訪問者あたり平均距離の回帰 **R² = 0.0115(Boston)/ 0.0298(Singapore)/ <0.001(Dakar, Abidjan)/ 0.001(Lisbon)**。例外は港と観光地。**フロア併記**: 原典は「実データ同士のばらつき」を別に報告していない=**比較フロアは空欄**。5 都市の R² の幅(<0.001〜0.0298)を散らばりの目安とする。
- **微視モデル PEPR** は **α=0.55・ρ=0.6・γ=0.21**(Song 2010 の値を明示的に流用)+ R=10・ν=4(実験的)・n_a=10⁵。
- **EPR 単体の弱点を著者が明言**(逐語): 「as the agents choose their locations **independently of each other**, the EPR model is unable to reproduce the heterogeneity in the attractiveness of locations」。

**含意**: **v2 は `ρ_i(r,f)` をそのまま計算できる**(§6)。しかも **η ≈ 2 は 5 大陸で成立**しているので、渋谷でも成り立つ見込みが高い=**「常連率」を 1 個の定数でなく 1 本の指数で照合できる**。

## §3 選好の表現 — 数値ベクトルか、文か

### 3-1 先行の 5 つの型

| 型 | 代表 | 選好の実体 | 更新 | 一次確認 |
|---|---|---|---|---|
| **① 効用の切片(frozen)** | MATSim の destination choice(**frozen randomness**) | 体 i × 選択肢 j ごとの誤差項 `ε_ij` を**種から 1 回だけ引いて固定** | しない | [二次](§7 ⑥) |
| **② 効用の項(観測変数)** | MATSim Charypar-Nagel scoring | 活動の効用 `β_dur·t_typ·ln(t_dur/t_0)` + 移動の不効用 | しない | [二次] |
| **③ 切片 + 状態依存ダミー** | Dubé+2010 式(2.1) `u = α_j + η·p + γ·I{s=j} + ε` | **α_j = 選好**・**γ·I{s=j} = 習慣** | s は直前選択で動く | **[実読]** |
| **④ 頻度そのもの** | EPR `Π_i = f_i` | 選好を持たず、**訪問回数が選好の代わり** | 訪問のたび | **[実読]** |
| **⑤ 文 + 数値状態の混成** | AgentSociety / Generative Agents / OASIS | profile = 自然文(名前・年齢・性別・学歴・性格)、status = 数値(感情 0-10・態度 0-10・関係強度 0-100・消費性向) | LLM の出力で更新 | AgentSociety **[実読・HTML]**、GA/OASIS は既存 lit メモ |

**MATSim の重要な自己申告**(Horni & Axhausen 2012, IVT WP 836・逐語 [実読]): 「Apart from these few examples, **MATSim agent heterogeneity is very low at the moment** … Usually, **identical utility functions have been used for all agents**.」
→ **較正の効く大規模交通 ABM は、体ごとの効用関数を持たせていない。**異質性は (a) 目的地選択の誤差項 `ε_ij`(frozen)と (b) 所得階級ごとの α・γ の 2 か所だけ。**「選好ベクトルを全員に持たせる」は先行では標準ではない。**

**AgentSociety(arXiv:2502.08691 v2・HTML 実読)**: profile は「name, age, gender, and education, as well as personality」= **自然文**。status は **数値の key-value**(感情 6 種を **0-10**、態度を **0-10**、関係強度を **0-100**)。消費の選好は「**consumption propensity** determines their monthly consumption budget」= **スカラーの性向**。規模「over **10k** agents … **5 million** interactions」。**プロフィールの生成元(調査データか LLM 生成か)は取得範囲に記載が無い(空欄)**。

### 3-2 数値ベクトル vs 文 — 本 repo の実測が決め手

| | 数値ベクトル(エンジンが持つ) | 文(プロンプトに書く) |

| 決定論 | ◎(ハッシュ固定・再生可能) | △(同じ文でも温度で揺れる) |

| 設計者の指紋 | 中(次元と重みを決める) | 大(語彙と言い回しを決める) |

**本 repo の実測(既存の記録・再掲)**:
- **8B は事実の時刻を 25% しか守らない**(W17 P2′・第160)。

→ **推奨: 選好は「エンジンが持つ数値」+「LLM には結果だけ見せる」**。これは決定台帳の背骨(状態と集約はエンジン、意思決定と発話だけ LLM)と、ユーザー選好(2026-09-11「行動の分散はエンジン規則でなく LLM から自ずと」)の両方と両立する。**LLM に見せるのは「この店には前に 6 回来た」「いつもの席が空いている」といった観測の事実**であって、「あなたはラーメンが好きです」という性格づけではない。

### 3-3 選好ベクトルの「次元」をどこから取るか(**指紋の最小化**)

先行の 3 つの道:

- **(a) 次元を決めない(EPR ④)**: 選好ベクトルを持たず、**訪問回数の表だけ**。`Π_i = f_i`。→ **指紋ゼロ**。ただし「初回の店をどう選ぶか」に答えない。
- **(b) 選択肢ごとの frozen 誤差(①)**: `ε_i,poi = f(blake3(seed ‖ agent_id ‖ poi_id))` を Gumbel から 1 回引いて固定。**次元 = POI 数**だが**保存しなくてよい**(種から再計算)。→ 指紋は「Gumbel スケール 1 個」だけ。
- **(c) カテゴリ重みベクトル(P1 趣味)**: 「ラーメン 0.8・カフェ 0.3 …」。→ **次元と初期分布が指紋**。しかも **P1(趣味)と同じ量**(§4)。

### 3-4 「人気」をどう入れるか

Pappalardo の d-EPR も Schläpfer の PEPR も「**探索先は集団の人気に引かれる**」を入れて初めて現実に近づいた。ただし両者とも**重力則/方向バイアスという外生の式**で入れている(ν=4 など)。
**v2 で筋の通る形**: 人気は**世界の観測可能な状態**(在圏密度・行列の長さ・看板・会話で聞いた店名)としてプロンプトに載り、**LLM が選ぶ**。これなら (i) 外生の式を足さない (ii) 「世界の変化はエージェント行動の結果」を守る (iii) 広告・情報伝播レーン(収益化の主要領域)と同じ経路に載る。**未検証(expedient ではなく未実装)。**

## §4 二重計上の回避 — 「戻る/探す」を 4 回数えない

### 4-1 先行の変数分解(正典は Heckman 1981 の区別)

- **真の状態依存(true state dependence)** = 過去の選択そのものが今の効用を変える(習慣・切替費用)。
- **見せかけの状態依存(spurious state dependence)** = 恒常的な個人差(選好)が持続を生んでいるだけ。
- 出典: Heckman, J. J. "Heterogeneity and State Dependence", in *Studies in Labor Markets*, Univ. of Chicago Press, 1981, pp.91-140 **[二次・本文未読]**。区別の実証は Keane 1997, *J. Bus. Econ. Statist.* 15(3):310-327 **[要旨のみ]**、**Dubé+2010 [実読]**。
- Keane の警告(**[二次]**): **Guadagni & Little 1983 の「ロイヤルティ変数」(過去購入の指数平滑)は、平滑定数が大きいと異質性を吸ってしまう**=状態依存と選好が混ざる。

**Dubé+2010 の式が v2 の設計図そのもの**:

```
u_jt = α_j        ← 選好(体ごと・不変)          = P3
     + η·p_jt     ← 観測変数(価格・距離・混雑)
     + γ·I{s_t=j} ← 習慣(経歴で動く)            = K-1
     + ε_jt
```

**選好と習慣を両方持つこと自体は二重計上ではない**(先行では両方が共存し、両方が有意)。**二重計上になるのは、同じ「戻りやすさ」を 3 つ目・4 つ目の変数にも入れたとき。**

### 4-2 v2 の 4 つの候補と、機構/従属の割り当て案(**推奨**)

| 候補 | いま何か | 「戻る/探す」への効かせ方 | **推奨** | 理由 |
|---|---|---|---|---|
| **K-1 訪問回数カウンタ**(既決・D-81) | 未実装 | **回帰先の重み `Π_i = f_i`**(比例のみ・変換しない) | **機構(データ由来)**。EPR の式(4)そのまま | Song 2010 が `Π = f` を実測で確認済み。掛け算を足すと原典から外れる |
| **P3 選好**(本答申) | 未実装(設計書 §7 に名前だけ) | **初回選択の切片** `ε_i,poi`(frozen・種から再計算) | **機構(乱数の凍結)**。**探索率には触れない** | MATSim の frozen randomness と同型。保存不要・決定論 |
| **探索率 ρ_i** | 無い | `P_new = ρ_i·S_i^{-γ}` の ρ_i | **機構(母集団分布から)**: ⟨ρ⟩≈0.6 の正規分布から体ごとに 1 回引く | Song 2010 が `P(ρ)` を実測。**性格から作らない** |
| **P2 性格(開放性)** | 未実装 | 探索率に掛ける? | **従属変数(=何も掛けない)**。**観察するだけ** | Alessandretti+2018 の外向性×容量の相関は **ρ=0.22**(既存答申 §1-4)。0.22 の相関に構造を賭けるのは過大。**性格→探索率の係数を置くと、ρ_i と二重** |
| **P1 趣味(カテゴリ重み)** | 未実装 | カテゴリごとの重み | **観測の入口に限定**: 趣味は「**どの POI カテゴリが観測ブロックに出るか**」にだけ効かせ、**選択確率には掛けない** | カテゴリ重みは `α_j`(=P3 の切片)と同じ量。両方置くと二重 |

**1 行でまとめると**: **戻りやすさ = K-1 だけが数える。探しやすさ = ρ_i だけが数える。P3 は「どれを最初に選ぶか」だけ。P1・P2 は選択確率に一切掛けない(観測と発話にだけ効く)。**

### 4-2b **同日の P1 答申との衝突(親が必ず突き合わせること)**

同日に書かれた [v2-hobby-preference-research.md](v2-hobby-preference-research.md)(趣味・P1)は、**「L2 選好ベクトル(POI カテゴリ × 重み)を社会生活基本調査の種目行動者率から個体ごとに抽選する」**を提案している(同書 §・「W17 の『娯楽』活動の中身(どこへ行くか)を決める」)。

- **これは本書 §3-3 (c) と同じ量**であり、本書 §4-2 が「**選択確率に掛けない**」と推奨した P1 の使い方と**正面から食い違う**。
- **どちらか一方しか採れない**というわけではないが、**両方を選択確率に掛けると `α_j` を 2 回置くことになる**(Dubé+2010 の式で言えば切片が二重)。
- **本書の側の案**: P1 のカテゴリ重みを **`α_j` の「平均」**に使い、**P3 は同じ `α_j` の「個体内のばらつき(frozen 誤差)」**に使う。つまり `α_{i,poi} = w_{P1}(体 i, カテゴリ(poi)) + ε_{i,poi}`。**この 1 本の式に畳めば二重にならない**。ただし **P1 の重みと P3 の誤差スケールの比が指紋**になるので、感度試験(比 ×0.5 / ×2)を宣言してから入れること。
- **判断はユーザー**。本書は「両立させるなら 1 本の式に畳む」までを示す。
