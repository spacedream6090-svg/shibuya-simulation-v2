# v2 LLM起点の人流生成リサーチ答申(2026-08-31・Opusサブエージェント・全出典URL付き)

> 「LLM/エージェントの行動から人流を生まれさせ、現実整合を調べる」方針の実現可能性を先行実測で検証。
> [事実]/[推測]区別。結論=**部分的に実現可能・鍵は地理の忠実さ**。

## 1. 先行研究の実測整合値(事実)

- **LLMob**(東京チェックイン100人・GPT-3.5): 時間・意味は強い(Step Distance JSD 0.049)が
  **時空間分布JSD 0.559=空間が最弱**。
- **CoPB**: 意図だけLLM・行き先は重力モデルの分業=意図誤り57.8%→19.4%・トークン97.7%削減。
- **CityReal**(東京3,000体・渋谷ケーススタディ): 生活時間JSD 0.0016(社会生活基本調査比)。
  **ただしtime-use・手段シェア・POI人気を目的にMCTS調整済み=論理的には純holdoutではない**。
- **GATSim**(70体・13ノード): 混雑を知覚して再計画するループを実装した最先端。ただしマクロ定量検証なし。
- **GenWorld**(東広島196,608体): センサス属性は完璧(就業者数R²>0.99・生活時間相関r>0.86)でも
  **通勤距離はKS距離0.359で合わない**(短距離過少・5-15km過剰)=属性接地だけでは距離分布は出ない。
- **TrajGenAgent**: LLMを活動チェーン構造だけに限定し距離JSD 0.0006=分業型が最も費用対効果が高い。

## 2. 「創発需要」の成否(最重要の実測)

**When Plausible Is Not Realistic(2606.13835)**: AgentSociety/CitySimをパリ・上海実データに突合し、
**実データ同士の別サンプル間ばらつきをフロアとして併記**した初の系統評価。
- 合った: 訪問目的の粗い構成比(JSD 0.0296)・日内ルーチン(0.0110)・home-workモチーフ・距離分布の見た目の裾
- 合わない: **OD行列は実質ゼロ相関**(CPC 0.04-0.14)・滞在時間は桁違い(W₁ 4.8-36h vs 実サンプル間0.26h)・
  移動距離W₁ 8.73km(実サンプル間0.48km)・活動遷移行列・行動多様性(退化個体と外れ値が同居)
- 原因診断: ①**無制約POI選択が主犯**(意味も距離もチェックせず全POIから選ぶ)②地図品質(OSM POIの57%が
  ベンチ・ゴミ箱等・Overture補強で施設相関0.55→0.80)③LLMに空間制約の理解の証拠なし。
- 結論: 「現実的な行動多様性は汎用プロンプトからは信頼できる形で創発しない」

**COMPASS(2602.16726)**: 統計則の自発再現を正面から測った唯一の研究。答えは**No**——
LLMobの距離指数β≈1.22 vs 実測β≈1.75±0.15・**EPR(探索と回帰)が突出して最悪**(JSD 0.39/0.25)。
「個々の軌跡はもっともらしいが集計は人流を再現しない」。

**要点: 一次モーメント(何を・いつ)は創発するが、二次以降(どこへ・どれだけ離れて・どの順で・
どれだけ留まるか)は全先行で創発していない。**

## 3. 人間移動の統計則(検証対象の台帳)(事実)

González+2008(切断べき則)・Song+2010 EPR(S(t)~t^μ, μ=0.6±0.02・Zipf ζ=1.2±0.1)・
Simini+2012 radiation(パラメータフリー)・Alessandretti+2018(**常用地点数~25で保存**)。
**Decoupling(Nat Hum Behav 2025・2405.08746)=v2に決定的**: 地理(機会の空間配置)の効果を差し引くと
5桁のべき則が現れる=**観測される距離分布の相当部分は「行動」でなく「地理」に由来**
→**実地図・実POI・実ダイヤを極限まで忠実にすること自体が、需要モデルを注入せずに統計則の一部を供給する
=v2最大の武器**。

## 4. 接地の許容線(結論)

**許容(初期条件・物理制約として正当)**: ①自宅・勤務先/通学先アンカーの実データ固定(国勢調査従業地・通学地=
全先行が実施・「需要モデル」でなく個体の初期状態)②実POI・実道路網・実時刻表そのもの(Decoupling根拠)
③**到達可能性による候補集合の制約**(徒歩n分圏・実所要時間・営業時間・カテゴリ整合=「無制約POI選択」の是正
であり距離減衰の重みではないので機構的に正当。POIはOSM+Overture補強)。
**不可(holdout破壊)**: 時間帯活動確率・重力/放射モデル・実OD行列・**人流実データのJSDを目的関数にした
プロンプト/アダプタ最適化**(COMPASSやCityRealのMCTSはこれ)。
**グレー→推奨**: 生活時間調査は「センサス属性のみ較正・生活時間も人流もholdout」側に置く。

## 5. v2が先行を超える要点

1. **「純holdoutの事前登録」は先行に存在しない**(COMPASS/CityReal/GenWorld全て実質較正込み)
   →指標セット(β・ζ・μ・回転半径・CPC・滞在時間・モチーフJSD・EPR)を**先に凍結して一発測定**するだけで
   方法論的新規性。
2. 実サンプル間ばらつきをフロアとして必ず併記(When Plausible方式)。
3. 観測可能性=v2のjournal/全記録は構造的優位(AgentSociety最大の批判=記録がなく再現不能)。
4. **スケール注意**: 渋谷2km四方では距離べき則はカットオフ支配でβ検証は無意味→検証対象を
   **滞留時間分布・訪問頻度Zipf・EPRのμ・常用地点数~25・混雑応答弾力性**に置き換え[推測]。
5. 40万体で毎意思決定LLMは非現実(GenWorldは蒸留で回避したが**蒸留は創発を凍結する**)→
   「LLMを呼ぶ個体・時刻の階層化」(=認知3層LOD)を設計判断として明示。
6. **混雑フィードバックループ(需要が物理に反応)の数万体規模の定量検証は空白**=先行に対する明確な機会。
7. Too Human to Model(npj Complexity 2026)の警告=「創発した」の主張には事前登録した反証可能な統計則を必ず紐づける。

**総括**: v2方針は部分的に実現可能。成功の鍵は「需要モデルを注入しない」ことに加えて、
**地理と到達可能性という物理制約を極限まで忠実にし、LLMには「機会集合からの選択」だけをさせる**こと。
これは重力モデル注入とは異なり、地理由来成分を正当に取り込む手段である。
