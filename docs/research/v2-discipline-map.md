# 分野地図 v0 — このシミュレーションが借りている/借りる学問分野(2026-09-14・第180)

> 位置づけ: ユーザー依頼(09-14「構築・実装していく上で必要となってくる学問分野をリストアップ」)。リサーチ残務台帳の **R-1「分野地図の答申」の骨組み**にあたる。
> **これは親の自前(expedient)**。各分野に「検証済みの定量モデルがあるか」「日本の公的データに錨があるか」を体系的に確かめる作業は**まだしていない**(R-1 の本体)。本書がしたのは、**既存の答申 74 本と照らして、どの分野に答申があり どこが空いているか**を数えたところまで。
> 読み方: 「答申」欄 = `docs/research/` に該当する答申があるか(あり / 部分的 / **なし**)。「錨」欄 = その分野の数値を現実に釘付けする日本の公的データ。

## 4. 親の見立て(未リサーチ・議論の材料)

**律速は 3 つ**と見ている。

1. **検証の方法論(#21〜#24)**。第一目標が「世界そのものがプロダクト」である以上、売り物は世界の中身ではなく**「合っていると言える手続き」**になる。ハッカソンの 38 作を見ても、実データ照合・決定論の再生・母集団の較正を持つ作品は無かった。差別化はここにある。
2. **人間移動科学と交通工学(#2・#3)**。在圏の骨格が全部の上流にある。いま残っている最大の誤差(昼間 1.6 倍)もここ。
3. **認知科学の記憶(#12)**。個人の中の規則性が無いことが、個体の同質性の残りの原因。

**答申が無い 4 分野**を優先して埋めるべきだと考える。社会ネットワーク科学(#14)・物質フロー分析(#19)・不確実性の伝播(#22)・科学哲学(#26)。前 2 つは測れている弱点に直結し、後ろ 2 つは主張の強さを決める。

**逆に、急がない分野**もある。歩行者動力学(#18)は設計も費用の実測も済んでいるが、いま測れている誤差を直さない。犯罪学(#32)は世界の被覆を広げる話で、忠実度の話ではない。

## 5. R-1(分野地図の答申)で本来やること

本書は骨組みで、次が残っている。

- 各分野について「**検証済みの定量モデルが存在するか**」を一次資料で確かめる(存在しない分野は自前設計になる=指紋が増える)。
- 各分野について「**日本の公的データに錨があるか**」を確かめる(無ければ海外値の移送になる=expedient 宣言が要る)。
- 「この repo が既に採用した形」と「その分野の標準的な形」のずれを列挙する。
- 第2陣の決定アジェンダに写す(どの分野を、どの順で、どこまで入れるか)。
