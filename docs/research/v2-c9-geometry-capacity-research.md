> **問い**: G8 の 3 定数(歩行可能面積 = 街路点 × 6.25 m² / 店舗床 既定 80 m² / 1 席 2・4 m²)とホーム滞留容量を、**公的一次資料と手元データで測った値**に置き換える手順は何か。
>
> **答え(要旨)**: 4 つのうち **3 つは置換値が出た**。
> (1) **歩行可能面積**: 手元 PLATEAU tran(2025)に **歩道部ポリゴン 3,505 面**があり、束ねると現行式は「歩行可能面積」ではなく **「道路面(車道込み)」相当**で、歩行可能面積としては **≈2.6 倍の過大**、しかも順位が合わない(r = 0.34)ことが分かった。ただし TrafficArea は LOD2/LOD3 整備範囲にしか無く(GL 453 セル中 **161**)、全セルには **OSM klass × 道路構造令の既定幅員**を併用するしかない。
> (2) **店舗床面積**: 経済センサス(令和3年)の**売場面積の分布**が取れた——特別区部 小売業の **中央値 80.6 m²**(現行の既定 80 m² とほぼ一致)・p25 37.4・p75 193.4、渋谷区の平均 174.3 m²。
> (3) **1 席面積**: 現行の **4.0 m² は消防法施行規則 第一条の三(四)項ロ「床面積を四平方メートルで除して得た数」と逐語一致**。飲食の 2.0 m² は法定値(消防 3 m² / 建告1441 の飲食室 0.7 人/m² = 1.43 m²/人)の**間**にあり、出所は repo に無い。
> (4) **ホーム滞留容量**は「法令には無い」が **実測はある**——運輸政策研究 2012 が **3.30 人/m²(歩行停止・銀座線渋谷駅を含む 3 駅)**、整列乗車列 **4.00〜4.50 人/m²**。同論文で **R-7 の空欄「運輸政策研究 表―1 の単位」も解けた(人/m・分)**。

## §2 実測化の手順(入力 → 計算 → 出力列・工数の目安・残る expedient)

### 2-1 歩行可能面積 `walkable_m2`(セル × band)

**方針**: 2 系統のハイブリッド。PLATEAU の**面**が取れるところは面を使い、取れないところは **OSM klass × 道路構造令の既定幅員**で線から面を作る。**「どちらで作ったか」を列に残す**(expedient のカバー率を台帳に出せる形にする)。

| 段 | 入力 | 計算 | 出力列 |
|---|---|---|---|
| S1 | `udx/tran/*.gml`(30 メッシュ・188 MB) | `tran:TrafficArea` を走査し `tran:function ∈ {2000 歩道部, 2010 自転車歩行者道, 2020 歩道}` を抽出。幾何は **LOD3 → LOD2 → LOD1 の順で最初に在るもの**を採る(1 地物 1 LOD = 二重計上しない)。`gml:posList` は (緯度 経度 高さ) 順 → 局所 m へ(`world_crs.json` の `m_per_deg_lat 111132.9 / m_per_deg_lon 90447.033`)。`gml:exterior` は加算・`gml:interior` は減算の shoelace | `plateau_sidewalk_m2` |
| S2 | 同 | `function ∈ {1000 車道部, 1020 車道交差部}` も同様に面積化(**歩道の無い道路の判定と、現行式の正体の検算に要る**) | `plateau_roadway_m2` |
| S3 | S1/S2 の各ポリゴン | セル割当は**重心 1 点ではなくセル境界でのクリップ**にする。歩道部の中央値は 1.4 m²・p90 17.9 m² と小さいので重心法の誤差は小さいが、車道交差部(p90 33.7 m²)では効く。**本答申の再計算は重心法 = 近似** | `cell_id` |
| S4 | `w1_edges.parquet`(`klass`・`length_m`・`geom`)+ 道路構造令 | **TrafficArea の無いセル**は線 × 既定幅員で作る。既定幅員(すべて出典つき): `footway / pedestrian / path / corridor` = **2.0 m**(第11条3項「その他の道路」)、歩行者交通量が多い区間 = **3.5 m**(同項)、`cycleway` 併設 = **3.0 m**(第10条の2 2項)、`residential / service / unclassified`(歩道なし = 歩車共存)= **車道全幅 4.0 m**(第5条5項)、`tertiary / secondary / primary`(歩道あり)= **両側 2 × 2.0 m**(第11条3項)。`steps` は 1.5 m・`elevator` は 0 | `osm_walkable_m2`, `width_rule` |
| S5 | S3 + S4 | `walkable_m2 = plateau_sidewalk_m2`(被覆セル)または `osm_walkable_m2`(非被覆セル)。**重なる区間の二重計上を避ける**ため、PLATEAU 被覆セルでは OSM 側を `footway / pedestrian / steps`(PLATEAU tran に無い歩行者専用路)だけに限る | `walkable_m2`, `source ∈ {plateau, osm, mixed}` |
| S6 | `w4_buildings.parquet`(LOD1 足跡 `area_m2`) | **建物の差し引きは原則不要**(PLATEAU tran の歩道部も OSM の道路線も建物の外にある)。DECK/UG は別扱い = DECK は `w1_edges` の `band=DECK` の線のみ、UG は駅構内 W11 と地下街 `ubld`(**未使用**)に依存 | `band` |
| S7 | 検算 | (i) 被覆セルで `plateau_sidewalk_m2 + plateau_roadway_m2` と現行式の比が 1.0 付近(本答申の再計算では中央値 **1.125**)。(ii) `walkable_m2 / 10000` が 0.05〜0.45 に収まる。(iii) セル合計が区の歩道部総面積 **897,556 m²** を超えない | ゲート |

- **工数の目安 [推測]**: 実装 4〜6 h(GML 走査は全 30 メッシュ 188 MB を 1 パスで約 3 分 = 本答申の再計算で実測)+ 親検収 1 h。
- **残る expedient**: (1) 歩道の有無の判定(OSM に `sidewalk` タグが無いので `klass` で代理)。(2)「歩行者の交通量が多い道路」の判定(2.0 か 3.5 か)。(3) DECK/UG の面(PLATEAU `ubld` 未使用・デッキ床の資産が無い)。(4) セル境界クリップをしない場合の重心法の誤差。(5) 有効幅員と幅員の差(植樹帯・路上施設)。
- **バイト・性能**: セル 520 行 × 数列 = 数十 KB。**実行時ではなく W 段階(前計算)**なので P2 / P4 に触れない。

### 2-2 店舗の床面積 `floor_area_m2`(POI)

| 段 | 入力 | 計算 | 出力列 |
|---|---|---|---|
| T1 | e-Stat 表 **0004003261**(特別区部・売場面積規模 12 階級 × 中分類) | 階級の度数から**経験分布**を作る(階級内一様 = 線形補間)。中分類 → `w6_poi.cat` の写像表を作る | `floor_area_dist[cat]` |
| T2 | e-Stat 表 **0004003263**(渋谷区・中分類別 事業所数と総売場面積) | 渋谷区の**平均**で T1 の分布をスケールする(市区町村表には規模別区分が無いので平均のみ) | `scale[cat]` |
| T3 | `w6_poi.parquet` | POI ごとに `hash(seed, "floor", poi_id)` で分布から抽出(決定論・W 段階で凍結)。**既定の 1 値をやめて個体差を持たせる**のが要点 | `floor_area_m2` |
| T4 | `w4_buildings.parquet` | 上限の検算: POI が束縛された建物の `area_m2 × levels` を超えないようクリップ(建物束縛率 0.688 なので残り 31% はクリップ無し) | ゲート |

- **工数 [推測]**: 2〜3 h + 親検収 0.5 h。API 取得は済(本答申で 2 表を取得・再計算済)。
- **残る expedient**: (1) 飲食・サービス・宿泊・事務所は**統計が無い**(売場面積は小売業のみ)ので、現行のカテゴリ別既定値か §2-3 の法定密度から逆算するしかない。(2) 中分類 → `cat` 写像。(3)「売場面積」と「客が立てる床面積」の差。

### 2-3 1 席あたりの面積 `seat_area_m2`

- **置換は「1 席面積」ではなく「占有密度 人/m²」に持ち替えるのが筋**。法定値はすべて 人/m²(建告1441)か「床面積 ÷ X m²」(消防法施行規則)の形で与えられており、**席という単位を経由しない**。`seats = floor(床面積 / X)` の X をそのまま法定値に差し替えれば**式の形を変えずに**置換できる。
- 手順: `SEAT_AREA_M2` を「用途 → X[m²/人]」表に置き換え、**出典を行ごとに持たせる**(建告1441 か 消防規則か)。感度腕は「建告側(密)/ 消防側(疎)」の 2 本で足りる(飲食 1.43 vs 3.0 = **2.1 倍**)。
- **工数 [推測]**: 1 h(定数表の差し替えとテスト)+ 感度腕 1 本のラン。
- **残る expedient**: 用途 → 法定区分の写像(`nightlife` は「飲食室」か「遊技場」か)。回転率 `DWELL_MAX_TICKS = 30` は**本答申の範囲外**(法定値が無い)。

### 2-4 ホーム・コンコースの滞留容量

- 値は §3 のとおり**実測がある**ので、手順は「W11 の駅構内グラフのノードに面積を持たせ、`容量 = 面積 × 密度上限`」にするだけ。
- 必要な入力で**手元に無いもの**: 渋谷駅の**ホーム面積**(有効長 × 幅)。W11 は駅内グラフ(ノード 60 / 辺 57)とフロアガイド接続 22 しか持たない。PLATEAU の `ubld`(地下街 1 メッシュ)・`bldg` の `station` 5 棟は未使用。**面積は空欄**。
- 暫定手順: ホーム有効長(列車編成長 = 運用設計書の車両長 × 両数)× ホーム幅(**空欄**)。幅が取れるまでは「ホームは容量制約なし・改札とエスカレーターだけで律速」とし、**律速が改札側にあることを計測で示す**(d4 の 56.1 人/分・台 と d5 の 95.3 / 107.8 人/分 を使えば、ホーム面積に触らずに E10 の降車セル round-robin を置換できる)。

## §4 空欄(読めなかった・見つからなかったもの)

1. **鉄道の「解釈基準」(通達)の所在**。省令は性能規定で数値を持たない(d1)。ホーム幅の数値(島式 中央部 3 m 等として引用されることが多い)の**公的サイト上の原文にたどり着けなかった**。本セッションでは WebSearch / WebFetch が使えず、検索の代替(DuckDuckGo の HTML / lite 版)も結果を返さなかった。
2. **渋谷駅のホーム面積**(有効長 × 幅)。W11 は駅内グラフしか持たない。PLATEAU `ubld`(地下街 1 メッシュ)・`bldg` の `station` 5 棟は未使用。
3. **コンコースの滞留密度の数値**(土木学会論文集D3 67(5) I_705・図中)。
4. **飲食店の客席面積・坪数の分布**。e-Stat に「客席」を含む表は 0 件。日本政策金融公庫の生活衛生関係営業の調査は本調査では当たれていない。
5. **OSM の `width` / `lanes` / `sidewalk` タグの渋谷での被覆率**。手元の OSM 抽出はこれらのタグを**保持していない**ので、被覆率の判定には Overpass 再取得(公的ドメイン外 = ユーザー判断)が要る。
6. **建築設計資料集成**(日本建築学会)の飲食店の客席 1 席あたり面積。有料書籍で Web に本文が無い。
7. **令和2年国土交通省告示第510号**(現行の階避難安全検証法)の**本文からの逐語**。官報 PDF(`https://www.mlit.go.jp/common/001339931.pdf`・取得済)はテキスト層が疎で表を抽出できなかった。本答申の在館者密度は**旧告示(平12建告1441号)の国交省掲載 PDF** から採った。国住指第4658号(令和2年4月1日)が「算出方法は基本的に平成12年建設省告示第1441号と同様」としているとの二次記述はあるが、**その通知本文は未読**。
8. **セル境界でのクリップ**をしていない(重心法)。歩道部は小さい(中央値 1.4 m²)ので影響は小さいはずだが、車道交差部(p90 33.7 m²)では効く可能性がある。
9. **DECK / UG の歩行可能面積**。PLATEAU tran は地上の道路のみ。
10. 表―3・表―4(捌け時間と許容流動量の表)の**数値そのもの**は PDF のテキスト層から取れず、本文中に引用された値(65.7 / 56.1 / 3.30 / 1.48 / 63.5% / 53.9%)だけを採った。
11. **経済センサスの階級内分布**。中央値・四分位は「階級内一様」を仮定した線形補間であって、原表には分位点が無い。
