## 結論(5 行)

1. **渋谷の建物の中の形は、公開データでは今も 0 棟。駅の中は「作られたが非公開」が 2 つある。** 国交省は令和元年度に渋谷駅の屋内電子地図(B2・B1・2F・3F)を作ったが、ゼンリンと JR 東日本コンサルタンツの地図を元に NTT データが民間の契約で作ったもので、実証の一般公開も中止した(#1 p.4〜5・13〜15。時点 2020-03)。uc24-13(2024 年度)も非公開のまま(R-90)。都の 3D デジタルマップは PLATEAU 2025 年度版と同じもので、屋内は地下街 LOD4.1 だけ(#3 p.6・#5)。関東地方整備局の地下歩道と東急建設の UiM は施工用のモデルで、公開の記述は見つからない(#10〜#12)。
2. **PLATEAU の段の定義(第 5.1 版・2026-03-19)では、席(家具 = `bldg:BuildingFurniture`)は LOD4.2 の任意の地物で、4.1 は「階段・スロープ・輸送設備・柱・デッキ」まで**(#2)。MR14 の「駅と大型商業施設は 4.1 + 座席」は、4.1 に 4.2 の家具のうち席だけを足す組み合わせになる。部屋(Room)の取得基準は「建築確認申請書に部屋として記載されている区画」で、出どころは BIM か屋内測量に限られる(#2)。
3. **商業施設の平面図のドメインは 23 件を表にした(§空欄 A・承認待ち・取得していない)**。robots.txt で AI のクローラを止めているのはマークシティの地図の配信元 platinumaps.jp だけ(`ai-train=no`・GPTBot・ClaudeBot などを `Disallow: /`)。西武は GPTBot を `Allow`。利用条件で「自動収集」や「AI」を名指しで禁じる施設は 0 だった。ただし西武は「営利を目的とする行為」を禁止事項に挙げる。どの施設も、私的利用の範囲を超える複製や利用には許諾が要る型で、利用条件の頁が見つからない施設は 7 件。
4. **現地の計測は、手持ちの SLAM スキャナなら屋内で約 5 mm の精度が報告され、iPhone や iPad の LiDAR は 10 m 規模で 10 cm より良くならない**(#25・#28)。歩道の上では「交通の妨害となる測量」だけが道路交通法 77 条の許可の対象(都の手順書は MMS などの移動測量は申請不要とし、人の多い地区は警察署に問い合わせるよう勧める・#20・#21)。駅・地下街・商業施設の通路は管理者の承諾が要る。人を記録しない方法は、カメラを使わない LiDAR か、国の手引きの「人物領域のアイコン化・速やかな破棄・通知」の型(#24 適用ケース (5))。
5. **持ち運ぶ物の影響の実測は「速さより占める場所」**: 傘(直径 1 m)を差すと一方向の流量が 7.7〜24.7% 落ち(Guo ほか 2016 表 2 から再計算)、ベビーカーを押す人の前では対向の歩行者が 53% 長く、大型キャリーバッグでは 36% 長く避けた(東京の通勤時の準実験・大野ほか 2015)。地下鉄の通路の観察では、大きな荷物で速さは 10〜14% 落ち、占める場所は 300〜650% 増えた(Ye ほか 2012・抄録)。看板と店頭の文の現実のデータは、OSM の店名(W1 で 2,813 件)のほかは、画像から読む経路(Mapillary は CC BY-SA だが規約に収集の制限・Google のストリートビューは規約で抽出を禁止)か現地撮影しかなく、看板の文そのものの公開データは見つからない。

### 1-2 PLATEAU の LOD4 の段(MR14 の物差し)の原文の要点(#2・第 5.1 版)

- 概要: 「建築物モデル（LOD4）は、BIMモデルからの変換又は屋内測量によって取得する。」「標準製品仕様書では原則としてLOD4.0を採用する。ただし、ユースケースの必要に応じてLOD4.1又はLOD4.2を採用できる。」
- 表 4-22 の地物: **4.0** = 建物の外形・部屋(Room)・天井・内壁・床・閉鎖面・窓・扉・階(CityObjectGroup)。**4.1** = 4.0 + 屋内付属物(`bldg:IntBuildingInstallation`)の「階段・スロープ・輸送設備・柱・デッキ・ステージ」(必須)。**4.2** = 4.1 + 梁・パネル・手すり(任意)・**家具(`bldg:BuildingFurniture`)(任意)**・任意設定空間(例: 防火区画)。
- 表 4-23 の 4.2 の説明: 「机やいすなどの移動可能な家具（bldg:BuildingFurniture）が追加される。」
- 部屋の取得基準(表 4-24〜4-26): 「建築確認申請書に部屋として記載されている区画を対象とする。」閉鎖面は「内壁面や天井面、床面はないが、建築確認申請では部屋となっている空間を区切る場合」。
- 地下街(`uro:UndergroundBuilding`)の LOD4 の区分は建物と同じ(検索の要約・#2 の地下街の節は本書では開いていない)。都の資料は、都の旧定義の地下通路を「内部空間の表現：LOD4.0以上、4.1からは付属物により区分」「階段・スロープ・柱：LOD4.1」「てすり：LOD4.2」と移した(#4 p.19)。

### 3-2 許可の取り方

- **道路(歩道)**: 道路交通法 77 条 1 項は、所轄警察署長の許可が要る行為として「道路において工事若しくは作業をしようとする者」(1 号)、「道路に人が集まり一般交通に著しい影響を及ぼすような行為で、公安委員会が…定めたもの」(4 号)などを挙げる(#21)。都の手順書は「道路上で交通の妨害となる測量を行う場合は、道路使用許可申請書の提出を行う。MMS などの移動測量機器の申請は不要であるが、同一箇所にて測量を行い申請対象かわからない場合、人流が多い地区では、管轄する警察署に問い合わせを行い、判断を仰ぐのが望ましい。」とする(#20)。手数料は工事・作業で 2,700 円(#22 △)。**渋谷の歩道で手持ちの機材を持って歩くだけなら申請不要の側、三脚を立てて止まるなら警察署に聞く側**(サブの読み・法的助言ではない)。
- **管理者**: 同じ手順書は「測量対象の道路、通路等の管理者を特定し、事業の目的、作業概要、作業期間、作業範囲、安全管理、緊急連絡先等を記載した作業計画書をもとに測量概要について説明を行う。…商店街などは道路管理者の他に商店街の組合などに連絡することもある」「占用（利用）申請、立入申請などの提出など、測量前の提出書類の確認を管理者とおこなっておく。測量開始時、測量終了時には関係者にその旨、連絡を行う。」とする(#20)。渋谷で当てはまる管理者の例(推測): 国道 246 の地下歩道とデッキ = 東京国道事務所・区道 = 渋谷区・都道 = 東京都・しぶちか = 地下街の管理会社・駅のコンコース = 各鉄道事業者・商業施設の通路 = 各施設。
- **国の屋内地図の手引き(#19 p.15・19)**: 「一般の方の通行が多い施設などは、営業時間内での現地作業が認められないことも多い。現地調査で収集すべき情報をあらかじめ整理した上で、調査可能な時期、時間帯、人数などを確認し、効率的な作業計画を作成する。」現地確認には「地権者・管理者への事前説明及び承諾が必要」。原典の図面を借りる場合は「情報非公開エリア」「歩行禁止エリア」の確認と、図面の権利者からの許諾(p.15)。
- **費用**: 外注の単価(1 m² あたり・1 日あたり)は見つからず**空欄**。機材の桁は 3-1 の表。

### 3-3 人を記録しない方法

- **カメラを使わない**: LiDAR の点群だけなら顔は写らない。ただし点群の色(RGB)は写真から付くので、色を付けない設定にする(推測)。歩く人の点は動く物として除く処理が要る(手法と精度は**空欄**)。
- **営業時間の外に測る**: 国の手引き(#19)の書きぶりから、施設の側も営業時間の外を求めることが多い。
- **写真を撮る場合の型(#24 適用ケース (5) は街中の看板・交通標識の抽出の例)**: 「人物領域のアイコン化を実施し、特定の個人の識別には至らない処理」・「取得時に、個人が特定できないレベルまで解像度を落として撮影」・「画像はしかるべき提供の後、破棄する」・事前告知と現場の掲示(目的・提供先・保存期間・問い合わせ先)。配慮事項 ⑬〜㊱ の表の対応例として書かれている(PDF p.84〜87)。
- **法の位置づけ**: 個人情報保護法の条文の当てはめは本書ではしていない(**空欄**・法的助言ではない)。

### 4-2 建築確認の BIM(#31 p.12)

- 「BIM図面審査」は **2026-04-01 開始**・2027 年度から「IFCデータを活用した審査対象を順次拡大」。BIM データから出力した IFC と PDF の図書を提出する。
- 「BIMデータ審査」は **2029 年春**。「IFCデータを審査に活用し、審査に必要な情報が自動表示される」。審査の対象は「IFC※データ ３D＋属性情報」。
- **公開との関係**: 確認申請の図書は審査のために出すもので、閲覧できるのは建築基準法 93 条の 2 と施行規則 11 条の 3 の書類(建築計画概要書・処分等概要書など)だけ(#32)。概要書の中身は「付近見取図、配置図」までで「平面図などの詳しい内容は記載されていません」(長野市の案内・#33 △)。練馬区と世田谷区は「建築物を特定しない閲覧」「一度に大量の閲覧」を断る(#33 △)。**BIM での確認が進んでも、IFC が公開される制度は見つからない**(空欄)。入手の道は持ち主との連携(MR14 の ①)。
- **見通し(推測)**: 2029 年春以降に確認を受けた建物は、持ち主が審査に出せる品質の IFC を持っている可能性が高い。渋谷の大型の建物の多くは 2029 年より前に建ったので、既存の建物の IFC の有無は持ち主ごとに聞くしかない。

### 当てはめ 5: 看板(指示書 10-12 §1-5 の 6)

- 「作り物」の印を 2 段に分ける案: (a) 店名・営業時間は OSM と公式サイトで今すぐ置き換えられる。(b) 店頭の文・看板の文は画像からしか取れず、現地撮影か Mapillary(一覧の外・規約の確認)を待つ。PLATEAU の「看板(自立式)」26 の形と「案内標識」27 の形は、文の無い看板の置き場所として使える。
