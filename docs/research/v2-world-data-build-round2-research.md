## A. 騒音・交通量レーン

### A1. ASJ RTN-Model 2018 音響パワーレベル式【実読・親再確認】
出典: S. Sakamoto, "Road traffic noise prediction model 'ASJ RTN-Model 2018'", Acoust. Sci. & Tech. 41(3) 529– (2020), DOI 10.1250/ast.41.529。PDF https://www.jstage.jst.go.jp/article/ast/41/3/41_E20301/_pdf/-char/en
- 式(2.1) "LWA = a + b lg V + C"(V=km/h・a,b=回帰係数・C=補正項)。式(2.2) C = ΔLgrad + ΔLdir + ΔLetc。排水性は式(2.3) "LWA = a + b lg V + c lg(1+y) + C"(y=舗装経過年)。
- 車種区分(Table 2.1/2.2): 3区分 Light(定員10人以下乗用車・排気量0.050L超かつ全長4.7m以下の小型)/Medium(全長4.7m超で大型を除く・11-29人バス)/Large(車両総重量8t超または最大積載5t超・30人以上バス・大型特殊)、2区分 Light/Heavy、Motorcycles追加可。HV/EVはLight。
- 区間定義(2.2.1): 定常交通流区間=高速または信号から十分離れた一般道・40≤V≤140。**非定常交通流区間=信号交差点を含む一般道・10≤V≤60**。加減速・停止を含む平均は非定常式。→渋谷の一般道(246号地平部・明治通り・道玄坂・宮益坂・公園通り・井の頭通り)は非定常、首都高3号のみ定常。
- Table 2.3(密粒舗装): 定常 Light 45.8/Medium 51.4/Large 54.4/Heavy(2区分) 53.2/Motorcycles 49.6・b=30。非定常 Light 82.3/Medium 87.1/Large 90.0/Heavy 88.8/Motorcycles 85.2・b=10。
- Table A4.1(排水性・一般道): 定常(40-80) Light 41.0(c 7.3)/Medium 47.6(3.6)/Large 50.5(3.6)/Heavy 49.3(3.6)/Moto 49.6・b=30。非定常(10-60) Light 76.6/Medium 83.2/Large 86.1/Heavy 84.9/Moto 85.2・b=10。適用限界: 高速の定常走行データ(舗装11年以内・15,000台/日以下)で決定。ΔLtraf=0。
- 伝搬: "LA,i = LWA,i − 8 − 20 lg ri + ΔLcor,i"。
