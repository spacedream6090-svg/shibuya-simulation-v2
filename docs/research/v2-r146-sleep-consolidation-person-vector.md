## §0 要旨

1. 文の記憶をベクトルへ写す先例の中心は文脈の蒸留である。文脈ありのモデルを教師にして、文脈なしのモデルが同じ分布を出すように学ぶ [S1][S2]。各層の前置きをこの形で学ぶ Cartridges は、100k〜484k トークンの文書を小さな前置きに写した [S5]。夜ごとの LoRA の論文は相補的学習系の説との対応を明記している [S7][S30]。人ごとのベクトルを夜ごとに学ぶ社会シミュの先例は見つからなかった。
2. 性格と事実で形の向き不向きが分かれる。操舵は性格では文のプロンプトと同じ程度の点を出す(90.8 対 87.9)が、知識が要る公人では下がる(51.4 対 89.1)[S15]。1 トークン 1 層の前置きに確実に入る事実は 1〜3 件で、全層にすると 20 件で正答 40% 程度まで保てる [S13]。理論にも上限の証明がある [S14][S38]。
3. 事実を重みやベクトルに高い率で残した先例は、読んだ範囲では合成の文を使っている。Dennis らは 1 事実に約 20 本の言い換えを作り、LoRA に 74.6〜94.3% を残した [S7]。Behrouz らでは合成(夢)を外すと 48.9% が 35.7% に下がる [S8]。合成の文は本人の経験ではないので、11-05 の「本人の部分は本人の経験だけ」との関係を決める必要がある。
4. 熟考を習慣へ写す形では、第 1 世代は判断モデル全体を逆伝播する。第 2 世代はベクトルをヘッドの側に置けば 8B の前向き 1 回で済み、8B に操舵で入れれば差す層より上だけの逆伝播で済む【見立て】。本人の手本は 1 日 6.94〜16 件で、読んだ先例の量より少ない。未見の人を 1〜100 件で当てる先例(正答 40%→58%)は、全員で共有する写像を先に学んでいる [S11]。
5. vLLM では、入口の埋め込みは本体の prompt embeds で差し込めるが、R-141 の不具合が残る。各層の前置きは本体に口が無く(`past_key_values` の引数なし・prompt adapter は v0.10.0 で削除)[S19][S46]、KV コネクタのプラグインで計算済みの KV を入れた先例が v0.19.1 にある [S21]。学習した KV を vLLM に入れた例は見つからず、Cartridges は別のサーバーを使う [S6]。元のトークンと一致しない KV は接頭辞のキャッシュを誤らせる恐れがある [S22]。
6. 誰をいつ更新するかの先例は、重要度の和(閾値 150・1 日 2〜3 回 [S28])、驚きや誤差の札 [S31][S49]、定期、文脈の満杯の 4 型に分かれる。人の睡眠の研究は感情・報酬・将来の関連を選別の札に挙げる [S27]。集団の一部を本人の状態で選ぶ先例は見つからなかった。状態の閾値で選ぶなら、割合は設定の値ではなく結果になる【見立て】。
7. 親の見積り「割合 10%・軽い学習で約 20 GPU 時間」を式で再現すると、2,000 トークンを前向きと逆伝播に 1 回だけ通した量(20.3 GPU 時間)になる。読んだ先例に 1 回で学んだものは無い。同じ条件で 10 回なら 203、100 回なら 2,026 GPU 時間【推測】。測られた重い学習は 1 人 1.5 時間(A100・Dennis ら)[S7]。前向きだけなら 3.4〜6.8 GPU 時間【推測】。
8. 親の置いた実効 40 TFLOPS は、A5000 のカタログの 27.8 TFLOPS [S54] より大きい。ただし手元の実測(bf16 で毎秒 3,257〜3,443 トークン)を同じ式で直すと 45〜48 TFLOPS 相当で、推論の速さとしては矛盾しない。学習の速さの手元の実測は無い。Dennis らの同じ学習は A100 と RTX 5090 で 5.5 倍違うので [S7]、5070 で測る必要がある。
9. シミュは実時間で動かないので、世界の夜に GPU が長く空くわけではない。00〜05 時の呼びは 1 日の 4.3% で、壁時計では約 25 分にあたる【見立て】。学習の時間は壁時計にそのまま足され、20.3 GPU 時間なら 7 枚で約 2.9 時間増える。これは題 6 の「固まりの上限 30 分」とぶつかる。vLLM の sleep mode は同じ GPU のメモリを学習に空ける手段になる [S25]。
10. 5070 の試験は 3 段の案にした。配線の確認、テープの再生、30 人 × 5 日の閉じた輪である。更新あり/なしを同じ種で対にし、TIPI-J の再回答に行動の計器と活性の読み出しを並べる(自己申告と行動はずれるという報告がある [S45])。夜の学習は 30 人で 100 回なら約 78 分、450 回なら約 5.9 時間の見込み【推測】。

### 2-2 相補的学習系の説との対応

説の要点(要旨の範囲)[S30] ○: 新しい記憶はまず海馬の系で符号化される。海馬が新皮質で再現し、新皮質のシナプスは再現ごとに少しだけ変わる。結び目の重みで学ぶモデルは、各項目を「少しずつ、他の項目と交互に」学ぶときだけ共通の構造を取り出せる。海馬は構造を乱さず素早く覚え、新しい記憶を古い記憶と交互に再現する。

| 説の要素 | 読んだ先例での対応 | 本プロジェクトの候補【見立て】 |
|---|---|---|
| 速い系(海馬) | Dennis「文脈の窓の注意が速い符号化」[S7]。Behrouz の文脈内の記憶と速い層の低ランクの専門家 [S8] | 文の記憶(出来事の行・寝たときの書き直し) |
| 遅い系(新皮質) | Dennis・Behrouz の重み。Lee の速い重みは間の層 [S10] | 本人のベクトル(と共有の土台) |
| 再現で少しずつ | 夜の学習の回数と歩幅 | 1 夜の P と学習率(§7) |
| 交互に学ぶ | Snell は元の課題を混ぜた [S2]。Dennis は「新しい固定は古い重みを上書きしうるが、1 事実は多くのパラメータに分散するので 1 回の影響は小さい」と書く(試験はしていない)[S7] | 今日の手本だけか、過去の手本を混ぜるか(2-3) |
| 遠い記憶は遅い系へ | Baranov は MEMIT の尺度を 1.0→0.5→0.1→0.0 と下げて LoRA へ移す [S32] ○ | 文の記憶が M1 で薄れた後に傾きが残るか |
| 説の外の注意 | Dennis は「手続き記憶は海馬から新皮質の道ではなく皮質下の系」と書き、手続きは自分の写しの範囲外の可能性を述べる [S7] | 熟考 → 習慣(§3)は、この説の写しに入らない可能性がある |

### 2-3 11-05 の「上書き」と説の間にある点【見立て】

説は「交互に学ぶことで上書きを防ぐ」と言い、11-05 §2 は「本人のベクトルは睡眠ごとの更新で古い傾きが上書きされる」と置く。どちらも取りうる。過去の手本を混ぜる割合と 1 夜の歩幅が、忘れる速さの値になる。先例は Snell の連続の蒸留(上書きを狙う)[S2] と、Dennis の 3 周期で 80〜82% を保つ結果(上書きが少ない)[S7] で、向きが逆である。文の記憶の忘れ方(M1)とベクトルの忘れ方を同じ速さにするかどうかも、同じ題になる(§13 の T1)。

### 2-4 社会シミュの先例

人ごとの LoRA やベクトルを夜ごとに学ぶ社会シミュは見つからなかった。調査論文は役割演技の分野で LoRA に複数の登場人物を入れる例を挙げるが、住民の経験で夜ごとに更新する形は読めていない [S55] △。R-145 §3-3 の「読めた先例なし」と同じ結果である。検索の範囲が狭いので、無いとは断定しない。

### 3-3 引き金との関係【見立て】

9-3b の引き金 ④不慣れは「本人の記憶と、睡眠で育つ習慣から分かる」とされている。更新で判断モデルの迷いが減れば、LLM へ上げる回数が減り、翌日の手本も減る。この輪が収まるのか、傾きを固めるのかは先例が読めていない。計器は 9-3b の「上げた回数を引き金の種類ごとに」をそのまま使える(錨は 11-05 の 10〜30%)。

### 6-3 割合と規則の関係【見立て】

- 11-04b の題 9-4 は「心は状態だけで決める」「費用を抑える手段は調停の規則で宣言して腕で比べる」と決めている。「毎晩 10% を更新する」を置くと、計算の都合で本人を選ぶ形になる。本人の状態の閾値で決めるなら、割合は日ごとに変わる結果になり、費用の上限はランの安全装置の側に残る。

### 6-4 いつ【見立て】

更新の入力は「寝た時点までの本人のテープ」、効くのは「起きた時点」と置ける。決めることが 4 つある。世界の時刻で起きる前に学習が終わらないとき(§7-6)、夜中に起こされたとき、昼寝のとき、圏の外で寝る人の扱いである。

| GPU 時間 | 3.4 | 6.8 | 10.1 | 20.3 | 101 | 203 | 1,013 | 2,026 |

## §10 本プロジェクトとの接点【見立て】

| 場所 | 接点 |
|---|---|
| 心の口(11-04b 題 9-2) | ベクトルは「保存・復元・更新」の塊の中に入る。文の日記を監査のために残す規則は変えない |
| テープ | R-126 §5-2 の `persona_vec_id` に、ベクトルの内容アドレスを入れる形が候補。再生は学習を回さず、保存した版を読む形なら学習の決定論に頼らずに済む |
| 学習の決定論 | 夜の学習が世界に効くので、学習の再現性(種・バッチの組み方)を B14 の形で確かめるか、ベクトルの値をテープの側に残して再生だけ保証するかを決める必要がある |
| 再計算(T1) | 活性の再計算の条件に「その呼で使ったベクトルの版」を足す必要がある |
| 艦隊 | `params_extra` で prompt embeds や `vllm_xargs` は渡せる(R-141 §6)。人ごとの値は `params_hash` に入らない(R-142 §6) |
| 保存の量 | 全員 8 KB なら 1 版 2.87 GB/35 万体。日ごとの版を全部残すかは別の題 |
| 均質化 | 共有の土台の更新と本人の更新を分けて計器にする(11-05 §2) |
| 人の行動データ | 手本は LLM の出力と本人の経験だけなので、「人の行動データによる較正なし」の条件(R-126 §5-5)の中に収まる。SPM や PeaPOD の形の先例は教師が人なので、値は根拠にならない |
