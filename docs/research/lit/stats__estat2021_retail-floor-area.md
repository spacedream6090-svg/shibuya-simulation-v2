## 主張(claim)

日本には**店舗の床面積の公的な分布**がある。ただし**小売業の「売場面積」だけ**で、飲食店・サービス業には無い。特別区部の小売業の売場面積は **中央値 80.6 m²・p25 37.4・p75 193.4・平均 190.6 m²** で、**分布は右に強く歪んでいる**(平均が中央値の 2.4 倍)。

## 機構(mechanism)

経済センサスは事業所を売場面積の **12 階級**(10 m² 未満 / 10-20 / 20-30 / 30-50 / 50-100 / 100-250 / 250-500 / 500-1000 / 1000-1500 / 1500-3000 / 3000-6000 / 6000 以上)に分けて数える。階級内一様を仮定して線形補間すれば分位点が出る。**「代表値 1 つ」ではなく分布が取れる**のが要点。

## 効く箇所(seam)

- **`crowd.py` の `DEFAULT_FLOOR_AREA_M2 = 80.0` の置換**。偶然にも中央値(80.6)とほぼ一致するが、**分布の幅(p25 37 / p75 193 = 5.2 倍)が失われている**のが問題。POI ごとに分布から引けば、席数 `c` に個体差が入り、`can_admit` の満席・待ち行列の形が変わる。
- `FLOOR_AREA_M2_BY_CAT`(food 60 / shop 100 / …)のうち**小売系のカテゴリだけ**が置換可能。
- D-52(廃棄が現実の帯の外)の分母にも効く。

## 「結論でなく機構として」の入れ方

「店は 80 m²」ではなく「**店の大きさは右に歪んだ分布で、上位 25% が面積の大半を持つ**」という機構を入れる。特別区部 小売業計で、面積階級が判明した 31,656 事業所の総売場面積は 6,952,044 m²。渋谷区では **7 事業所(各種商品)が区の売場面積の 25.3%(134,444 / 530,805)を占める**。

## コスト/スケール含意

W 段階で POI 2,337 件に 1 列(float32 = 9 KB)を足すだけ。実行時は既存の `seats_for_categories` がその列を読むだけで、計算量は変わらない。

## 批判・限界

- **飲食店には統計が無い**。e-Stat 横断検索で `searchWord=客席` は **0 件**。売場面積は小売業限定。飲食の床は法定占有密度(建告1441 / 消防法施行規則)から逆算するしかない。
- **売場面積 ≠ 延床面積**。バックヤード・事務室・階段を含まない。ただし v2 の用途(客が入れる面積)にはむしろ合う。
- 中央値・四分位は**階級内一様を仮定した補間**であって、原表に分位点は無い。
- 渋谷区は市区町村表に規模別区分が無いので**中央値が取れない**。特別区部の分布を渋谷区の平均でスケールする操作は expedient。
- 「不詳」が小売業計で 4,809 事業所(13.2%)ある。本計算では分母から外した。
