# Roberts & Dunbar 2015 — Managing Relationship Decay: Network, Gender, and Contextual Effects

- リンク: https://doi.org/10.1007/s12110-015-9242-7 (全文: https://pmc.ncbi.nlm.nih.gov/articles/PMC4626528/) | 分野: 社会ネットワーク科学 #14 / 人格心理学 #13 | 重要度: **P1**

## 主張(claim)

**親密さは放っておくと下がる。下げ止めるのは「会うこと」である。** ただし**家族は例外**で、接触が減っても親密さが下がらない(むしろ上がる)。すなわち**単一の半減期ではモデル化できない**。

## 機構(mechanism)

25 名の学生を高校→大学の移行期に 18 か月追跡し、3 時点(T1/T2/T3)で網の全員について **1〜10 の情動的親密さ**と**最終対面接触からの日数**、共同活動のスコアを取る。混合モデルで「親密さの変化」を「接触頻度の変化」に回帰する。

## 数値(出所つき・**読み取り器経由**)

- 尺度の妥当性: Subjective Closeness Index と 1–10 親密さ尺度の相関 **r = 0.90, p < 0.001**。
- **Model 8**: 接触頻度の変化(= 最終接触からの日数)→ 親密さの変化、**b = −0.71**(SE 0.17・95% CI −1.03〜−0.38・p < 0.001)。**性別交互作用 0.51(p<.05)**=女性で強く男性では有意でない。
- 友人との**平均「最終接触からの日数」28.41(T1)→ 69.31(T2)→ 128.78(T3)**。
- 時点ごとの親密さ変化: **家族 b = +0.27(t₅₄₂.₁₀ = 7.28, p<.001)** / **友人 b = −0.62(t₇₈₆.₅₇ = −15.23, p<.001)**。Model 3 では −0.52。
- **落ち方は前半が急**: T1→T2 が **−0.82**(Model 4)、T2→T3 が **−0.31**(Model 5)。外層へ落ちた友人は **−1.22**(p<.001)。
- 内層に留まった割合: **kin 102/145 = 70.3%** vs **friends 69/142 = 48.6%**。
- 共同活動スコア(友人): **2.00(T1)→ 1.25(T2)→ 0.97(T3)**。
- 逐語(読み取り器が返した短文): "even close friendships require active maintenance, whereas family relationships are more resistant to decay" / "To prevent this decay requires time-consuming maintenance behaviors, principally communication and joint activities" / "time is an inelastic resource"。

## 効く箇所(seam)

**C10 の着手条件②「半減期 30 日」と行動契約 §5「半減期 90 日」の両方**。この論文は**種別ごとに減衰が逆向き**であることを示すので、**1 個の半減期定数は実証に反する**。基底活性方式なら、世帯辺は同居によるエピソード供給で自動的に維持されるので、**種別ごとの定数を置かずに家族/友人の差が出る**。

## 「結論でなく機構として」の入れ方

借りるのは b=−0.71 でなく **「親密さは接触の関数で、接触が止まれば減る。ただし供給源は種別で違う」**。本 repo で言えば: 世帯辺は毎晩の在宅で、職場辺は毎日の在席で、友人辺は**会話の成立でしか**エピソードが供給されない。**会話率が上がらない限り友人辺は作れない**という C10 の制約を、実証側から裏づける。

## コスト/スケール含意

測定側: 辺ごとに「最終相互作用時刻」を持てば「最終接触からの日数」がそのまま出る(uint32 4 B/辺)。**28 / 69 / 129 日という帯は、本 repo の辺の年齢分布の照合値に使える**(ただし英国の学生の値であり、日本・都市の一般人口ではない)。

## 批判・限界

- **標本 25 名**・英国・高校→大学の移行期。**定常期でも日本でもない**。
- 親密さは**自己申告**。行動ではない。
- **本メモの数値は WebFetch の読み取り器が返したもの**で、リサーチサブが表を直接見ていない。b、SE、CI、t 値、内層保持の分数は**すべて親の再確認対象**。
- 移行期という激変を含むので、**減衰の速さは定常期より速い側に偏っている**はず。
