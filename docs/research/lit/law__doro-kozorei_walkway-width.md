# 道路構造令 1970(現行) — 歩道・自転車歩行者道・車線の幅員

- リンク: https://laws.e-gov.go.jp/law/345CO0000000320 (道路構造令・昭和四十五年政令第三百二十号。本文は e-Gov 法令検索 API `laws.e-gov.go.jp/api/1/articles;lawId=345CO0000000320;article=11` および `article=5` で取得)。国交省掲載の条文 PDF(平成15年7月改正版)= https://www.mlit.go.jp/road/sign/kouzourei/0.pdf | 分野: 交通工学 #2 / 地理情報科学 #9 | 重要度: **P1**
- **一次確認**: **実読(サブ Opus 5・2026-09-17)**。e-Gov 法令検索 API v1(**現行版**)と国交省 PDF(平成15年改正版)の**両方**を読み、差分を確認。**親未確認**。

## 主張(claim)

日本の道路の幅員には**政令で定まった下限**がある。歩道は 3.5 m(歩行者交通量が多い道路)/ 2 m(その他)、自転車歩行者道は 4 m / 3 m、市街地の車線は 2.75〜3.5 m、歩道の無い細街路の車道は 4 m。したがって **OSM の道路「線」しか無くても、klass さえ分かれば出典つきの「面」に変換できる**。

## 機構(mechanism)

道路構造令は道路を **第一種〜第四種 × 級**に区分する(第四種 = 市街地の道路)。幅員は区分ごとの表で決まる。歩道の設置義務も区分で決まる(第十一条第1項)。「幅員」と「有効幅員」は別で、後者はバリアフリー省令(平成18年国土交通省令第116号)第四条が「道路構造令第十一条第三項に規定する幅員の値以上」と定める。

## 効く箇所(seam)

- **R-8 ①(歩行可能面積)の非 PLATEAU セル**。PLATEAU tran の TrafficArea は LOD2/LOD3 整備範囲(渋谷区 2.57 km²)にしか無く、GL 453 セル中 161 しか賄えない。残りは `Σ 辺長 × 既定幅員` で作る。
- `renderer.py` の `STREET_POINT_AREA_M2 = 6.25`(= 2.5 m 格子の目の面積)と `8 m バッファ`(中心線から片側 4 m)を、**klass 別の法定幅員**へ置き換える。

## 数値(条・項まで)

|---|---|---|
| **第十一条第3項** | 「歩道の幅員は、歩行者の交通量が多い道路にあつては**三・五メートル以上**、その他の道路にあつては**二メートル以上**とするものとする。」 | 3.5 / 2.0 m |
| 第十一条第4項 | 「横断歩道橋等又は路上施設を設ける歩道の幅員については、前項に規定する幅員の値に横断歩道橋等を設ける場合にあつては**三メートル**、ベンチの上屋を設ける場合にあつては**二メートル**、並木を設ける場合にあつては**一・五メートル**、ベンチを設ける場合にあつては**一メートル**、その他の場合にあつては**〇・五メートル**を加えて」 | +0.5〜3 m |
| **第十条の二第2項** | 「自転車歩行者道の幅員は、歩行者の交通量が多い道路にあつては**四メートル以上**、その他の道路にあつては**三メートル以上**とするものとする。」 | 4.0 / 3.0 m |
| **第五条第4項**(車線の幅員の表・現行版) | 第一種第一級 三・五 / 第二種第一級 普通道路 三・五 / **第四種第一級 普通道路 三・二五**・小型道路 二・七五 / **第四種第二級及び第三級 普通道路 三**・小型道路 二・七五 / 第三種第四級 二・七五 | 2.75〜3.5 m |

## コスト/スケール含意

W 段階(前計算)の定数表。実行時の計算量・バイトに影響しない。

## 批判・限界

- **これは基準であって実測ではない**。実際の歩道は基準を下回ることも上回ることもある(既存道路は適用除外が多い)。
- **2011 年の法改正以降、都道府県道・市町村道は各自治体の条例が道路構造令と異なる規定を置ける**。渋谷区内の区道に東京都/渋谷区の条例が別値を置いているかは**未確認(空欄)**。
- 「歩行者の交通量が多い道路」の判定基準は政令に無い(3.5 か 2.0 かの分岐が expedient になる)。
- OSM の `klass` と道路構造令の「種・級」は**対応表が無い**。`residential / service / unclassified` を「歩道なしの細街路」と読むのは本調査の解釈 = expedient。
