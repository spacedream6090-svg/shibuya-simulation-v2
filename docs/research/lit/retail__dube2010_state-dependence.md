## 主張(claim)

「同じ商品を繰り返し買う」現象(**慣性 inertia**)は、**選好の個人差(heterogeneity)を極めて柔軟に入れても消えない**。したがって少なくとも一部は**構造的な状態依存(true state dependence)**であり、自己相関誤差・探索費用・学習では説明がつかない。

## 機構(mechanism)— **P3 と K-1 の二重計上を切り分ける正典の式**

本文 式(2.1):

```
u_jt = α_j + η·p_jt + γ·I{s_t = j} + ε_jt
```

- **`α_j` = 銘柄切片**「represent a persistent form of vertical product differentiation that captures a household's **intrinsic product (or brand) preferences**」= **選好ベクトル(不変・体ごと)**。
- **`γ·I{s_t = j}` = 状態依存**。`s_t` = 直前に買った銘柄。「If s_t = j, the household is said to be **'loyal' to brand j**」= **習慣(経歴で動く)**。
- **すべてのパラメータが世帯ごと**(`α`, `η`, `γ` の全部が家計固有)。
- 「It is well known that it is **difficult to distinguish between state dependence and heterogeneity**」→ **識別には長いパネルと、状態を外生的に動かす仕掛け(価格割引)が要る**。

**これが v2 の §4(二重計上)の答えの型**: 選好は**切片**(場所/カテゴリごとの定数)・習慣は**直前の選択に付く 1 項**。**同じ量を 2 度足さない。**

## 数値(表番号まで)

- **データ**: AC Nielsen 家計パネル・**米中西部の大都市・1993〜1995 年**・**2,100 世帯**。期間中 2 回以上購入した世帯に限定 → **冷蔵オレンジジュース 355 世帯 / 16 oz タブ マーガリン 429 世帯**(Table 1)。マーガリンは 1 世帯あたり **18.25 トリップ・9.90 購入**。無購入率 マーガリン 45.73% / OJ 23.75%。
- **再購入率**(Table 2): OJ **Minute Maid 購入頻度 .43 / 再購入 .78 / 割引起点の再購入 .74**、**Tropicana .57 / .86 / .83**。マーガリン ICBINB **.43 / .88 / .88**、Shedd's .23 / .81 / .80。本文「**nearly 60% of the purchases are for products offering a temporary price discount**」。
- **異質性を入れても状態依存は残る**(Table 3・対数周辺尤度・大きいほど良い):

| モデル | マーガリン | OJ |
|---|---|---|
| 同質・状態依存なし | −10755 | −7612 |
| **5 成分正規混合・状態依存なし** | **−5575** | **−4528** |
| 5 成分・ラグ価格あり・状態依存なし | −5517 | −4389 |
| 同質・状態依存あり | −8175 | −6297 |
| **5 成分・状態依存あり** | **−5501** | **−4434** |
| **5 成分・購入順序を無作為化** | **−5581** | **−4503** |

  → **「柔軟な異質性 + 状態依存」が最良**。そして**購入順序を無作為化すると当てはまりが落ちる**(−5501 → −5581)= **順序に情報がある**ことの証明。**これは v2 でそのまま使える負の対照(placebo)**。

- **状態依存の金銭換算**(Table 5・`γ/η` = 切替費用):

| 分位 | マーガリン | 平均価格比 | OJ | 平均価格比 |
|---|---|---|---|---|
| 10% | $0.07 | 0.04 | $0.12 | 0.04 |
| 25% | $0.17 | 0.11 | $0.27 | 0.10 |
| **50%** | **$0.44** | **0.28** | **$0.56** | **0.21** |
| 75% | $1.16 | 0.75 | $1.15 | 0.42 |
| 90% | $2.69 | 1.74 | $2.09 | 0.77 |

  → **中央値で平均価格の 21〜28%**、**上位 10% では価格と同等〜1.7 倍**。「慣性」は小さくない。そして**個人差が 1 桁以上ある**(0.07 → 2.69)。

- **学習では説明できない**(Table 4)・**探索費用でも説明できない**(店頭広告を外生変数に使った検定)。

## 効く箇所(seam)

- **§4 二重計上の整理の一次根拠**。v2 の P3(選好ベクトル)= `α_j`、K-1(訪問回数カウンタ)= `s_t` 由来の項。**この 2 つは別の項として先行研究で共存している**=両方持つこと自体は二重計上ではない。**二重計上になるのは、同じ「戻りやすさ」を性格(P2 開放性)と趣味(P1)にも入れたとき**。
- **「順序無作為化」= v2 の負の対照**。テープの訪問順を体ごとにシャッフルして同じ指標を測り、**指標が落ちなければ「経歴が効いていない」**。安い(ラン不要・集計だけ)。
- **金銭換算の分位表**は、v2 が「常連の強さ」を 1 定数で置かず**分布で持つ**べき根拠。

## 「結論でなく機構として」の入れ方

- **借りない**: 銘柄選択(v2 は店・場所の選択)・ベイズ混合正規の推定手続き。
- **借りる**: (1) **効用 = 切片(選好)+ 価格 + 直前選択ダミー(習慣)** という**項の分け方**。(2) **順序無作為化の対照**。(3) **切替費用は中央値でも価格の 2 割**という桁感。

## 批判・限界

1. **米国・食品スーパーの 2 カテゴリ・1993-95 年**。日本の外食・小売にそのまま移せない(日本側は [[retail__hotpepper2018_repeat-rate]])。
2. **`s_t` は直前 1 回だけ**(著者も「by no means the only possible specification」と断る。Seetharaman 2004 の分布ラグを挙げている)。v2 の K-1(訪問回数カウンタ)は**より長い記憶**なので、この論文の γ とは量が違う。
3. 初期条件バイアス: 同著者らの後続(Simonov ほか 2020)が「状態依存パラメータのバイアスは **2〜2.5 倍**に達しうる」と報告(**本メモ未読=二次**)。
4. **買い物トリップの発生は外生と仮定**(いつ店に行くかはモデル外)。v2 は来店自体を内生に持つので、同じ識別は成り立たない。
5. Table 3 と Table 4 で「5-comp, SD」の値が **−5501 と −5551** で食い違う(WP 版の誤植の疑い)=**親の一次確認項**。
