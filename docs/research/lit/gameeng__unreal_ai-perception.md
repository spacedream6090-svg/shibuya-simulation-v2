## 主張(claim)

ゲーム AI に「見える・聞こえる」を持たせるための **業界標準の部品構成**。感覚(Sense)ごとに設定を持ち、**刺激(Stimuli)を集めて対象(Target)を選ぶ**コンポーネントとして実装する。

## 機構(mechanism)— 5 つの部品が v2 に無い

- 「AI Perception Component which acts as a **stimuli listener** and gathers registered Stimuli Sources.」
- 「When a stimuli source is registered, the event **On Perception Updated** (or **On Target Perception Updated** for target selection) is called」= **対象選択が明示的なイベント**。
- **① 取得半径と喪失半径が別**(AI Sight):
  - 「**Sight Radius**: The max distance over which this sense can start perceiving.」
  - 「**Lose Sight Radius**: The max distance in which a seen target is no longer perceived by the sight sense.」
- **② 視野角**: 「**Peripheral Vision Half Angle Degrees**: How far to the side the AI can see in degrees. The value represents the angle measured to the forward vector, not the whole range.」
- **③ 刺激の寿命**(全センス共通): 「**Max Age**: Determines the duration in which the stimuli generated by this sense becomes forgotten (0 means never forgotten).」
- **④ 感覚の優先順位**: 「**Dominant Sense** property can be used to assign a Sense that should take precedence over other senses when determining a sensed Actor's location.」
- **⑤ 対象の粘り**: 「**Auto Success Range from Last Seen Location**: When greater than zero, the AI will always be able to see the target that has already been seen as long as they are within the range specified here.」
- ほかに AI Hearing(`Report Noise Event` で鳴った音を拾う)・AI Team(同じチームが近くに来たことを通知)・AI Prediction(対象の PredictionTime 秒後の予測位置)。

## 「結論でなく機構として」の入れ方

1. **★ 借りる(G7)**: **成立距離と離脱距離を分ける**(Sight Radius / Lose Sight Radius)。d_talk を成立・離脱とも 2 m にすると、**境界上の二人が毎 tick 会話を作っては壊す**。D-49 が「近接入替は最大の暴発源」と名指しした形と同じ。
2. **★ 借りる(G4)**: **注意の焦点に寿命を持たせる**(Max Age)。焦点が永遠に残ると `TARGET_GONE` を出す機会が無い。
3. **借りる(将来)**: **Dominant Sense**。v2 は視覚・聴覚・傍受を別チャネルで持つが、**同じ相手を別の感覚で捉えたときどちらの位置を採るか**は未定義。
4. **借りない**: `Auto Success Range` のような「見えていないのに見えたことにする」近道。v2 は W8 の前計算で遮蔽を扱うので、近道を入れると二重基準になる。
5. **v2 に無いものの確認**: W8 は **視野角なし(全方位)・眼高 1.5 m・最大視程 150 m**([C9 材料](../../design/v2-c9-geometry-brief.md) §1.5)。**① ② ③ ④ ⑤ のどれも持っていない**。

## コスト/スケール含意

① と ③ はどちらも **体あたり数バイトと分岐 1 本**。毎 tick 全体走査には**しない**(焦点を持つ体だけ)ので P4 の逐次ループ宣言にはならない見込み(親判断)。

## 批判・限界
