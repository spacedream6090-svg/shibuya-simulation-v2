# 総務省統計局 2021(令和3年社会生活基本調査 時間帯編 第15-4表) — 勤務形態別・時刻区分別行動者率

- リンク: https://www.e-stat.go.jp/stat-search/file-download?statInfId=000032224355&fileKind=0 | 分野: 時間利用研究 #4 / 人口学 #1 | 重要度: P0
- **一次確認**: **実読(サブ・2026-09-17・xlsx を取得し openpyxl で再計算)・親未確認**
- 主張(claim): 日本の公的統計に**「始業時刻の分布表」は存在しない**。本表は勤務形態(交替制を含む)× 時刻区分(15 分・96 区分)の行動者率を持つ**唯一の代理**であり、交替制勤務の時刻像を初めて数値で与える。
- 機構(mechanism): 「仕事」の時刻区分別行動者率 v(t) の**正の階差** Δv(t)=max(0, v(t)−v(t−1)) が、その時刻に仕事を始めた人の割合に対応する。朝の窓(04:00–12:00)に限ればほぼ始業、13:00 の巨大な山は昼休み明けの復帰。
- 効く箇所(seam): D-68 の **M3(開始分のエントロピー / `:00+:30` 率)の判定側アンカー**を 1 本増やす。第2陣の記憶・習慣で交替制の体を扱うときの**深夜例外の根拠**。
- 「結論でなく機構として」の入れ方: 「交替制は時刻がばらつく」ではなく「**朝の山が低く、深夜に別の山を持つ**」という**形**として入れる。分散を広げる操作ではなく別の型を持たせる操作になる。
- 数値(出所のシート・行キーまで): シート `a015_4`・ヘッダ 7 行目(index 6)に `01_0:00 - 0:15` 〜 `96_23:45 - 24:00`、値は index 7 以降。行キー = 曜日 / 地域区分 / 男女 / 従業上の地位 / 勤務形態 / 行動の種類。
  - 勤務形態 7 区分: `0_総数` / `1_フルタイム` / `11_始業時間が固定されている` / `12_始業時間が固定されていない` / `121_始業時間などを選択できる(裁量労働・フレックスタイムなど)` / `122_始業時間などが会社の都合で決められている(交替制勤務など)` / `2_短時間勤務`
