# 建設省告示第1441号 2000 — 避難安全検証法の「在館者密度」と「必要滞留面積」

## 主張(claim)

日本の建築基準法は、**用途ごとに「1 m² あたり何人いるとみなすか」を法定している**。避難計算はこの密度を使って出口通過時間を出す。したがって「店に何人入れるか」は設計者の裁量ではなく、**出典のある数値**で書ける。

## 機構(mechanism)

避難完了時間 `tqueue = Σ p·Aarea / Σ Neff·Beff`。`p` = **在館者密度(人/m²)**、`Aarea` = 床面積、`Neff` = 有効流動係数、`Beff` = 有効出口幅。避難経路側には別に **「必要滞留面積」an(m²/人)** があり、廊下は 0.3 m²/人。つまり法は「**居室の占有密度**」と「**通路の滞留密度**」を別々の数として持っている。

## 効く箇所(seam)

- **`crowd.py` の `SEAT_AREA_M2`(飲食 2.0 / その他 4.0)の置換**。法定値は「床面積 ÷ X」ではなく「密度 p」の形なので、`seats = floor(床面積 × p)` に書き換えれば式の形が変わらない。
- **`DENSITY_STAGE_EDGES` と LOS の上側**。通路 0.3 m²/人 = **3.33 人/m²** は、建築基準法が想定する通路の実質的な上限密度。Fruin LOS F(> 2.0 人/m²)の上に置く目盛りになる。
- U15-4 の LOD 閾値(LOS C 相当 0.43〜0.72 人/m²)との距離が測れる。

## 「結論でなく機構として」の入れ方

「飲食店は 1.43 m²/人」と定数で入れるのではなく、**「用途によって占有密度が数倍違う」という機構**を入れる(事務室 0.125 / 飲食室 0.7 = **5.6 倍**)。感度腕は法定値の 2 系統(建告 vs 消防法)で作る。

## コスト/スケール含意

定数表の差し替えだけ。計算量・バイトとも増えない。

## 批判・限界

- **避難計算のための密度**であって、平常時の実在密度ではない。「満員になったときの上限」に近い読み方が要る(平常時はこれより疎)。
- **本メモの逐語は平成12年建設省告示第1441号**(2017 年に国交省が掲載した PDF)から採った。**現行は令和2年国土交通省告示第510号**で、国住指第4658号が「算出方法は基本的に同様」としているとの二次記述はあるが、**その通知本文も告示 510 号本文も未読**。親の一次確認が要る。
- 用途の区分(`nightlife` が「飲食室」か「遊技場」か)は写像の判断が要る = expedient が残る。
- 「売場に附属する通路 0.25」と「廊下その他の通路 0.3 m²/人」は**単位が逆**(前者は 人/m²、後者は m²/人)。取り違えると 13 倍ずれる。
