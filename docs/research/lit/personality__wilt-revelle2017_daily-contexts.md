# Wilt & Revelle 2017 — The Big Five, Everyday Contexts and Activities, and Affective Experience

- リンク: https://pmc.ncbi.nlm.nih.gov/articles/PMC6168084/ | 分野: 人格心理学 #13 / 時間利用研究 #4 | 重要度: **P1**(**「性格は単一場面でなく集計を予測する」の根拠**)
- **一次確認**: **実読**(2026-09-17・サブが PMC 本文を取得し標本・手続き・結果節を読取)。**親未確認**。*Personality and Individual Differences*。

## 主張(claim)

経験サンプリングで測った**日常の同伴者(company)と活動(activity)**を Big Five から予測する。同じデータを 2 通りに解析した:
- **瞬間(マルチレベル・ロジスティック回帰)** → 予測はまばら。
- **週で集計(ポアソン回帰)** → 係数が出る。

## 数値

**標本・手続き**: 大学の有償被験者プールから 101 名が完了、**うち 5 件以上応答した 78 名**(女 63・平均 26.6 歳 SD 7.9)を分析。白人 52・アジア系米国人 15。オンラインで Big Five(各特性 28 項目・感情/行動/認知/欲求のバランス)に回答した後、**1 週間・1 日 4 回(10 時・14 時・18 時・22 時)**の SMS。回答は直前 30 分の同伴者(1 人・家族・友人・恋人・群衆)、活動(17 択のうち頻出 6: 仕事・食事・TV・勉強・ネット・社交)、感情 3 次元。**応答率 84%(2,184 中 1,827)**。

**瞬間(マルチレベル・ロジスティック回帰・特性 1 点上昇あたりのオッズ比)**

| 文脈 | 有意だった特性 |
|---|---|
| 1 人でいる | 協調性 **OR = .50** |
| 友人といる | **外向性 OR = 1.98** ・協調性 1.77 ・開放性 .46 |
| TV を見る | 開放性 1.72 |
| ネットを見る | 開放性 1.92 |
| 社交する | 協調性 1.63 ・開放性 .63 |

**誠実性と情緒安定性は瞬間では何も予測しなかった**。

**週で集計(ポアソン回帰・b・df=71)**

| 特性 | 有意だった集計 |
|---|---|
| 外向性 | 友人 b=.52 / 家族 −.37 / 勉強 .85 / ネット −.72 |
| 協調性 | 友人 .62 / 家族 .65 / 1 人 −.51 / ネット −.39 |
| **誠実性** | **勉強 .60**(同伴者への効果なし) |
| 情緒安定性 | 1 人 .13 / 友人 −.16 / 仕事 .29 / 勉強 .34 / TV −.49 |
| 開放性 | 1 人 .21 / 友人 −.80 / TV .57 / ネット .66 / 勉強 −.96 |

**著者の総括**: 性格は「集計された同伴者・活動文脈」はよく予測したが、「それらの単一の事例」の予測はうまくいかなかった。解釈は **Epstein / Fleeson の集約原理**。関連は「かなり微妙(subtle)」なので、時間をまたいで集計したデータでこそ検出できる、と述べる。

## 機構(mechanism)

**集約原理**。1 回の測定には状況要因のノイズが乗る。同じ人の測定を n 回足すと、状況ノイズは 1/√n で縮み、特性由来の成分が残る。だから**特性の効果は「頻度」や「割合」の水準で現れる**。

## 効く箇所(seam)★

本 repo の設計に 2 つの拘束を与える:
1. **効かせる先**: 性格は「この tick で話しかけるか」を動かしてはいけない。**「1 日あたり何回話しかけたか」の個体間分布**を動かす。
2. **測る先**: 感度試験・照合も**同じ集約水準**で行う。瞬間の意思決定で差を探すと、**現実でも差が出ない水準**を見に行くことになり、何も検出できない。

親案の「会話の起点**率**」「計画一致**率**」「新規 POI 探索**率**」が率であるのは、この原理と整合している(良い)。欠けているのは**測る側の集約水準の宣言**。

## 「結論でなく機構として」の入れ方

OR や b の値を輸入しない(N=78・米国の大学院年齢・自己報告の文脈分類)。**入れるのは「集約水準を合わせる」という手続き**。

## コスト/スケール含意

集計は既存テープから。追加ランなし。

## 批判・限界

1. **N=78**。係数の推定は粗い。
2. **米国の若年成人**(平均 26.6 歳・女性 81%)。
3. 文脈は**強制選択の自己報告**。著者自身が「客観的な手がかりと主観的な解釈が混ざる」と注意している。
4. 「自宅にいる」文脈は測っていない。交際状況・就業状況も収集していない。
5. 瞬間と集計で**符号が食い違う組がある**(開放性 × 友人: 瞬間 OR=.46 / 集計 b=−.80 は同じ向きだが、社交は瞬間 .63・集計は非掲載)。解析水準で像が変わることそのものが本論文の主題。
