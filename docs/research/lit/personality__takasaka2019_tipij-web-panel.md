# 鷹阪・山田 2019 — 公募型 Web 調査における TIPI-J の利用可能性の検討

- リンク: https://www.jstage.jst.go.jp/article/jssp/35/1/35_1807/_pdf | 分野: 人格心理学 #13 | 重要度: **P2**
- **一次確認**: **実読**(2026-09-17・サブが J-STAGE PDF を WebFetch 取得 → pymupdf 抽出 → Table 1 / Table 3 と本文の該当段落を照合)。**親未確認**。*社会心理学研究* 35(1), 19–27(資料論文)。

## 主張(claim)

大学生標本で作られた TIPI-J を、**公募型 Web 調査の成人標本**に当てて、記述統計・因子間相関・併存/弁別妥当性・再検査信頼性が保たれるかを見た。結論はおおむね利用可能。ただし**協調性の項目表現には問題が残る**。

## 数値(出所の表番号まで)

**標本**: n=480(20〜60 代・男 239・女 241)。PC 以外のデバイス回答者と回答時間・SL(satisficing 指標)で除外。パネル調査(再検査)は別途。

## 機構(mechanism)

同じ尺度・別の標本抽出法(公募型 Web パネル)・別の年齢層でも、**年齢と性別の向きが川本 2015 と一致する**(年齢↑で協調性・勤勉性↑、神経症傾向↓。女性が外向性↑・開放性↓)。**2 標本の独立再現**なので、抽選の設計はこの向きに従ってよい。

## 効く箇所(seam)

- 川本 2015 の**外部妥当性チェック**。20 代の値が川本(男 81・女 95)より厚い(n=76)ので、若年側の推定を幅で見るときに使う。
- 「Web パネルで測った値」という点で、本 repo が将来 Web 調査をする場合の期待値になる。

## 「結論でなく機構として」の入れ方

この表の平均を直接使わない(標本が 480 と小さい)。**向きの一致を確認するためだけに引く**。

## コスト/スケール含意

なし(規準表の追認)。

## 批判・限界

1. **n=480**。年代別は各 76〜120。SD の推定が不安定。
2. 公募型 Web パネル特有の選択バイアス(satisficing で除外した後の値)。
3. **協調性の項目表現の問題が大学生でも Web でも出る**——協調性の値を係数に使うのは他因子より危ない。
