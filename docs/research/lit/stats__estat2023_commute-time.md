# 総務省統計局 2023(令和5年住宅・土地統計調査 表58-2-1) — 片道通勤時間の分布(市区町村別)

- リンク: https://www.e-stat.go.jp/dbview?sid=0004021722 | 分野: 人口学 #1 / 交通工学 #2 | 重要度: P0
- **一次確認**: **実読(サブ・2026-09-17・e-Stat API getStatsData で取得し再計算)・親未確認**
- 主張(claim): 片道通勤時間の**分布**を持つ現行の公的統計は住宅・土地統計調査であり、**渋谷区まで降りられる**。社会生活基本調査の分類事項「ふだんの片道の通勤時間」は**平成23年で終了**しており令和3年には存在しない。
- 機構(mechanism): 出勤時刻(家を出た時刻)+ 片道通勤時間 = 始業時刻。オフセットを一律にせず**分布から個体ごとに引く**ことで、始業時刻の広がりが出勤時刻の広がりより広くなる。
- 効く箇所(seam): W17 の勤務窓投入(下見設計書 §2-3 の `arrival_lead_min` 候補 (a))の妥当性検査。第2陣の記憶・習慣で「毎日同じ経路を同じ所要時間で」を作るときの所要時間の母数。
- 「結論でなく機構として」の入れ方: 平均値(東京都 44.6 分)を定数として入れない。**8 区分の構成比から逆関数法で体ごとに引き、区分内は一様に散らす**(既存の出勤時刻投入と同じ手順)。
- 数値(統計表 ID・分類まで): statsDataId **`0004021722`**(表番号 58-2-1)。cat01=家計を主に支える者の男女、cat02=住宅の所有の関係、**cat03=家計を主に支える者の通勤時間(自宅・住み込み / 15 分未満 / 15〜30 / 30〜45 / 45〜60 / 60〜90 / 90〜120 / 120 分以上 / 不詳)**、area=1,283 件(渋谷区 = `13113`)。時間軸 2023 年。表章項目 = 主世帯数。
  - 総数(cat01=0, cat02=0): 全国 **21,957,400** / 東京都 **2,386,200** / 渋谷区 **32,530**
