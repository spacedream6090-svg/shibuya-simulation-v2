# 小塩・阿部・カトローニ 2012 — 日本語版 Ten Item Personality Inventory(TIPI-J)作成の試み

- リンク: https://doi.org/10.2132/personality.21.40 (本文 PDF: https://www.jstage.jst.go.jp/article/personality/21/1/21_40/_pdf) | 分野: 人格心理学 #13 | 重要度: **P2**
- **一次確認**: **実読**(2026-09-17・サブが J-STAGE PDF を WebFetch で取得 → システム python の pymupdf で本文抽出 → Table 1 / Table 3 / 性差・再検査の段落を逐語照合)。**親未確認**。*パーソナリティ研究* 21(1), 40–52。

## 主張(claim)

Gosling, Rentfrow & Swann (2003) の 10 項目版 Big Five 尺度を日本語化し、信頼性・妥当性を検討した。**各因子 2 項目・合計 2–14 点・中間点 8 点**。以後の日本の Big Five 研究のほとんどがこの尺度を使う。

## 数値(出所の表番号まで)

**標本**: 愛知・大阪・兵庫・長崎の大学生 **902 名**(男 376・女 526)、**平均年齢 19.2 歳(SD 1.5)**、2010 年 9–12 月(Sample 1)。Sample 2(再検査 n=149)〜Sample 7(同性友人ペア 31 組)は下位標本。

**Table 3 — 代表値・散布度・下位尺度間相関**

| 因子 | M | SE | 95%CI | SD | 歪度 | 尖度 |
|---|---|---|---|---|---|---|
| 外向性 | 7.83 | 0.10 | [7.63, 8.02] | 2.97 | 0.07 | −0.83 |
| 協調性 | 9.48 | 0.07 | [9.34, 9.62] | 2.16 | −0.57 | 0.43 |
| 勤勉性 | 6.14 | 0.08 | [5.98, 6.30] | 2.41 | 0.38 | −0.07 |
| 神経症傾向 | 9.21 | 0.08 | [9.05, 9.37] | 2.48 | −0.36 | −0.10 |

因子間相関(同 Table 3): 外向性—協調性 .04 / —勤勉性 .12*** / —神経症傾向 −.19*** / —開放性 .24***。協調性—勤勉性 .20*** / —神経症傾向 −.25*** / —開放性 .01。勤勉性—神経症傾向 **−.32***** / —開放性 .07*。神経症傾向—開放性 −.15***。本文: 「r＝−.32(勤勉性と神経症傾向)から.24(外向性と開放性)の範囲」。

**性差**(逐語 ≤125 字):
- 「外向性では男性よりも女性の得点が高く(女性:M＝8.07, SD＝2.96; 男性:M＝7.49, SD＝2.95; t＝2.91, df＝900, p＜.001)」
- 「開放性では女性よりも男性の得点が高かった」(女性 M=7.79 SD=2.32・男性 M=8.36 SD=2.64・t=3.44, df=900, p<.001)
- 「その他の下位尺度では,男女の有意な得点差はみられなかった」
→ d 換算: 外向性 ≈0.20・開放性 ≈0.23。

**再検査信頼性(2 週間・n=149)**: 外向性 .86 / 協調性 .79 / **勤勉性 .64** / 神経症傾向 .73 / 開放性 .84(すべて p<.001)。

**項目間相関(Table 2・対応する 2 項目間)**: 外向性 r=−.59 / 協調性 **r=−.22** / 勤勉性 −.38 / 神経症傾向 −.28 / 開放性 −.39。著者自身が「協調性と神経症傾向の項目のペアの相関係数は高いとは言えず」英語版(協調性 −.36・神経症傾向 −.61)より低いと書いている。

**得点化**: 外向性=項目1+(8−項目6) / 協調性=(8−項目2)+項目7 / 誠実性=項目3+(8−項目8) / 神経症傾向=項目4+(8−項目9) / 開放性=項目5+(8−項目10)。

## 機構(mechanism)

Big Five を「2 項目 × 5 因子」で測るという設計そのものが、**測定誤差を許容する代わりに調査コストを 1 桁下げる**という取引。日本の大規模社会調査に載せられたのはこの取引のおかげで、その結果として **N=4,588 の年代別規準表**(川本 2015)が存在する。

## 効く箇所(seam)

- 母集団合成での **traits の抽選分布**(L0 不変核)。ただし**大学生標本**なので、渋谷の全年齢母集団には**川本 2015 を使う**べき。本メモは「尺度の定義と限界」を引くために持つ。
- **歪度・尖度がいずれも絶対値 1 未満** = 正規近似の許容の根拠。

## 「結論でなく機構として」の入れ方

平均値を「日本人はこういう性格だ」と読み込まない。**入れるのは (μ, SD, 相関行列) という分布の形**であって、平均の高低ではない。

5 float32 × 40 万体 = 8 MB。プロンプトには 1 バイトも載せない設計なら、トークン予算への影響ゼロ。

## 批判・限界

1. **2 項目尺度**。再検査 .64(勤勉性)〜.86。**観測できる相関の上限を下げる**——性格 × 行動の r を「小さい」と読むとき、尺度側の減衰が入っていることを忘れない。
2. **大学生・平均 19.2 歳**。年齢分布が渋谷の母集団と全く違う。
3. 協調性の項目表現に問題があることは、著者と追試(鷹阪 2019)の両方が指摘。
4. 使用マニュアル(日本パーソナリティ心理学会)は**項目の改変・順序変更を認めない**と明記。本 repo は尺度を実施しないので該当しないが、規準値を引くときは「TIPI-J の得点」であることを明示する。
