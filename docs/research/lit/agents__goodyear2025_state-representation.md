## 主張(claim)

LLM は状態を持たないので、履歴を自然言語に直して渡す。その**直し方が独立変数**であり、先行研究はそこを場当たりに決めてきたので比較ができない。3 軸で整理し、**どの書き方が均衡に近づくか**を測る。

## 機構(mechanism)— 3 軸 × 2 水準 = 8 通り

| 軸 | 水準(逐語 ≤125 字) |
|---|---|
| 行動情報量 | 「**O if only an agent's own action history is included; E if all agents' action history is included**」 |
| 報酬情報量 | 「**P for payoff-based feedback; R for regret-based feedback**」 |
| 表現様式(自然言語圧縮) | 「**F for full-chat, S for summarized**」 |

命名は S-RO のように連結。**S-RO =「要約 × 後悔 × 自分の行動だけ」**。

## 数値(出所つき)— Table 1(経路あたりの平均人数・括弧は試行間の標準誤差)

均衡: Game A = 9/9、Game B = 全 18 体が橋経路 O-L-R-D。

| 表現 | Game A(O-L-D / O-R-D・SE) | Game B(O-L-D / O-R-D / **O-L-R-D**) |

- **均衡に最も近いのは S-RO**(§5.4 で「the representation that resulted in LLM behavior closest to equilibrium」)。Game B では **17.71 で人間 14.82・EXP3 13.81・MWU 13.87 を上回る**。
- **Game A では平均はどれも 9/9 付近だが標準誤差が桁で違う**: 要約系 2.11〜3.52 に対し full-chat 系 **6.71〜7.99**。平均だけ見ると差が消える=**分散で見ないと書き方の効果は見えない**。
- 軸ごとの効き(逐語 ≤125 字):
  - 要約 vs 全文が最強。「**is approximately 40% for summarized representations, and closer to 15% for full-chat representations**」(Game A の焦点経路シェア・均衡は 50%)。「**regrets are 4-5x lower using summarized representations in Game A**」。
  - 後悔 vs 素の利得(Game B 橋経路): F-PO 8.25 → F-RO 17.52 / S-PO 15.90 → S-RO 17.71 / F-PE 4.74 → F-RE 9.90 / S-PE 10.88 → S-RE 17.36。
  - 自分だけ vs 全員(Game B): F-PE 4.74 → F-PO 8.25 / S-PE 10.88 → S-PO 15.90 / F-RE 9.90 → F-RO 17.52 / S-RE 17.36 → S-RO 17.71。**他者の行動を見せるほど均衡から遠のく**。

## 効く箇所(seam)

`v2-perception-contract.md` の知覚 3 層(B0-B4 共有静的/セル・B5 個体・B6 直前の結果)。**この repo の現行設計は既に本論文の「良い側」に寄っている**:
- **要約**: 「観測は有界な完全現在形」(§1-3)=全文履歴を渡さない ✔
- **後悔情報**: B6「直前の結果 50 tok(失敗理由+観測値+いま可能な行動 3 語)」= 後悔に近い ✔
- **自分だけ / 全員**: B5 の「知人/近接上位 3-4」「被注視」は**他者の行動を見せる側**。本論文はここを**均衡から遠ざける方向**と測っている ✖

## 「結論でなく機構として」の入れ方

- **借りない**: ルーティングゲームの均衡・S-RO という名前。
- **借りる**: (1) **3 軸の分類そのもの**を知覚テンプレの ablation 軸に写す(要約度 / 結果の与え方 / 他者情報の量)。(2) **平均でなく試行間分散で判定する**。(3) **他者情報は少ない方が安定**という仮説 = `v2-perception-contract.md` §3 の「近接 k の密度逓減(疎3/中2/密1)」の ablation に、**k=0 の腕**を足す根拠。
- **注意**: 均衡の存在するゲームでの「均衡への近さ」が物差し。この repo に均衡は無い(前向きに 1 回進むだけ)ので、**物差しは holdout の H1〜H5 と分散**に読み替える必要がある。

## コスト/スケール含意

18 体 × 40 ラウンド × 8 表現 = 小さい。**知覚テンプレの 3 軸 ablation は 40 万体でなく数千体の下見で回せる**(この repo の mock 5,000 と同じ規模感)。

## 批判・限界

- **モデル 1 種**(gpt-4o)。8B 級で同じ順序かは未検証。
- HTML 版の Fig. 2a の O/E 列ラベルが本文の記法と食い違う(サブ確認)。親の一次確認ではそこを見ること。
- 試行本数が本文に無い=Table 1 の標準誤差の分母が分からない。
- 「均衡に近い = 良い」は**このゲームだから**言える。人間(14.82)より均衡に近い(17.71)ことを「良い」と呼ぶなら、**人間の再現という目的とは逆向き**。この repo の第一目標は現実整合なので、**S-RO は「人間より均衡的すぎる」側**として読むべき。
