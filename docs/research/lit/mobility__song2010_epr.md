## 主張(claim)

個人の移動は Lévy flight / CTRW では説明できない。**探索(exploration)と優先的回帰(preferential return)の 2 機構だけ**で、訪問地点数の増加則・訪問頻度の Zipf 則・超低速拡散の 3 つの「異常」が同時に説明でき、指数も解析的に予測できる。

## 機構(mechanism)— これがこの論文の本体

1. 待ち時間 Δt を `P(Δt) ~ Δt^{-1-β}` から引く。
2. **確率 `P_new = ρ S^{-γ}` で未訪問の新地点へ**(S = それまでに訪れた相異なる地点数。移動のたび S → S+1)。跳躍距離は `P(Δr) ~ Δr^{-1-α}`・方向は一様。
3. **補確率 `1 - ρ S^{-γ}` で既訪問地点へ戻る**。戻り先 i の選択確率は **`Π_i = f_i`**(その地点の過去訪問頻度そのもの=優先的選択/累積優位)。

→ **「常連か探索か」は個体の性格ではなく、`ρ`(個体パラメータ)と `S`(経歴)の関数**。S が増えるほど探索は自動的に減る。

## 効く箇所(seam)

- **P3(選好ベクトルと常連/探索)の骨格そのもの**。「戻る/探す」の比を**エンジンの 1 本の式**に落とせる: `P_new = ρ_i S_i^{-γ}`。個体差は **ρ_i 1 個**(平均 0.6 の正規分布)で足りる=**設計者の指紋が最小**。
- **D-81 K-1(習慣=訪問履歴カウンタ)と直結**: 回帰先の選択 `Π_i = f_i` は「訪問回数カウンタに比例」そのもの。K-1 (a) の土台が先行研究の機構と一致する。
- **M5(体ごとの行動エントロピー)の下限側**: δ = 1+γ なので、γ を入れれば Zipf 指数は自動的に決まる。**δ を別に較正してはいけない**(二重計上)。

## 「結論でなく機構として」の入れ方

- **借りない**: 跳躍距離 `P(Δr)` の Lévy 則(v2 は渋谷 bbox 内なのでカットオフが支配的・C9 の速度/経路が別に決める)。
- **借りる**: (1) **探索確率が訪問地点数の冪で逓減する**という形。(2) **戻り先は頻度に比例**(別の重みを足さない)。(3) **個体差は ρ の 1 スカラー**に集約する、という倹約。
- **そのまま合わせない**: γ=0.21 は「1 移動 = 1 回の決定」の粒度。v2 の 1 日 5〜6 活動という粒度と単位が違うので、**同じ粒度で測り直す**か、粒度を宣言して使う。

## コスト/スケール含意

呼数ゼロ(エンジン側の 1 行)。`S_i` は体ごとの int と訪問回数の疎な表で足りる(K-1 と同じ実体)。

## 批判・限界

1. **γ・ρ の標本が 1,000 人・2 週間**。地点の定義は「基地局/位置ログの点」であって POI ではない。
2. **地点に意味がない**(店か公園かを区別しない)。v2 の「どの店に行くか」には**そのままでは答えない**。
3. **地点間の結合がない**(各体が独立に動く)。人気の店ができない → [[mobility__schlapfer2021_visitation-law]] が PEPR で修正している。
4. **returners/explorers の二分は再現できない**([[mobility__pappalardo2015_returners-explorers]]: EPR は k=60 でようやく均衡・実測は k=4)。
5. ρ が正規分布という記述はあるが**分散が本文に無い**=個体差の幅は空欄。
