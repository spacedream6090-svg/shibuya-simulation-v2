# 鈴木ほか 2012 — 都市開発による鉄道駅の混雑と施設容量に関する研究(運輸政策研究 15(3))

## 主張(claim)

鉄道事業者の「設計容量」は事業者ごとにばらつき、しかも実測の「許容量」と系統的にずれている。**13 事業者(A〜M)のうち設計基準を持つのは 3 社だけ**で、ホームの設計容量は 78 / 86.4 / 107.4(人/m・分)と 1.4 倍の開きがある。実測すると、階段・エスカレーターは設計容量より**高い**流動量を出せるのに対し、**改札は設計容量を下回る**。

## 機構(mechanism)

- 「待ち行列が発生してから解消するまでの時間」= **捌け時間**、その間に通過した人数 = **許容流動量**。両者を線形回帰(`y = ax`・R² 0.96〜0.99)して施設ごとの許容量 a を出す。
- **ホームだけは流量ではなく密度で定義する**: 「ホームでの歩行停止状態の密度を計測し、その数値を『ホームの許容容量』として定義する」。
- 旅客は施設が直列に連なったネットワークを流れるので、**律速は最小容量の施設**。改札で捌けないと滞留がホーム階段まで戻る。

## 効く箇所(seam)

- **R-8 ④(ホーム滞留容量)の空欄がこれで埋まる**。U15-5 段階3 の施設容量レイヤに、ホームの密度上限を入れられる。
- **U15-5 段階3 の既存値(改札 56 人/台/分・エスカレーター 95.3 / 107.8 人/分)の一次出所がこの論文**であることが確認できた(これまで出典が repo に無かった)。
- **R-7 の空欄「運輸政策研究 表―1 の単位は混在」が解ける** → 単位は **人/m・分**(エスカレーター・改札は 人/台・分)。`v2-crowd-physics.md` U15-5 の「単位混在のため採用保留」を解除できる。
- E10(降車セル = 45 出口 → 25 セルへ round-robin)の昇格: ホーム面積が無くても、**改札 56.1 人/分・台**と**ES 95.3 / 107.8 人/分**だけで出口ごとの吐き出し上限を作れる。

## 「結論でなく機構として」の入れ方

「ホームは 3.30 人/m² まで」と定数を置くのではなく、**「歩行停止状態の密度には上限があり、それを超えると転落・接触のリスクになる」という機構**を入れる。値は expedient ではなく実測だが、**地下鉄のホームの実測**なので、渋谷の地上・高架ホームへの外挿は宣言つきにする。

## コスト/スケール含意

値はすべて定数表に入るだけで、計算量は増えない。ホームの密度上限は `占有 = 面積 × 3.30` の 1 行。**面積(ホーム幅 × 有効長)の入力が手元に無い**ことだけがコスト。

## 批判・限界

- **地下鉄(東京メトロ)のホーム**の実測。渋谷駅の JR・私鉄の地上/高架ホームは風・雨・ホームドア有無が違う。
- ホームの密度は **3 駅のみ**の平均(丸ノ内線池袋・銀座線渋谷・東西線東陽町)。分散は本文に無い。
- 表―1 の事業者記号(A〜M)は匿名化されており、どの事業者がどの値かは分からない。
- 2012 年の調査。ホームドア整備と可動柵の普及で滞留の形は変わっている可能性がある。
- 図―6〜10 の回帰係数(0.89 / 0.90 / 0.63 / 0.55 / 1.07)は図中にあり、本文の許容量(65.7 等)との対応は本調査では追えていない。
