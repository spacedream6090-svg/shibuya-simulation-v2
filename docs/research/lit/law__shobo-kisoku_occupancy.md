# 消防法施行規則 第一条の三 — 収容人員の算定方法(飲食 3 m²/人・物販 4 m²/人)

- リンク: https://laws.e-gov.go.jp/law/336M50000008006 (消防法施行規則・昭和三十六年自治省令第六号。本文は e-Gov 法令検索 API `laws.e-gov.go.jp/api/1/articles;lawId=336M50000008006;article=1_3` で取得) | 分野: 法学(業法・条例) #11 | 重要度: **P0**
- **一次確認**: **実読(サブ Opus 5・2026-09-17)**。e-Gov 法令検索 API v1(現行版)から条文 XML を取得し逐語採取。**親未確認**。

## 主張(claim)

消防法は防火対象物の**収容人員**を「床面積 ÷ X 平方メートル」で算定させる。X は用途別に法定されており、**物販店舗の一般部分は 4 m²/人、飲食・休憩の部分は 3 m²/人**。これは建築基準法の在館者密度(建告1441)とは**別系統の数値**で、同じ用途でも値が違う。

## 機構(mechanism)

`収容人員 = 従業者数 + Σ(客席部分の算定値)`。客席部分は「固定式のいす席があるならその数」「無いなら床面積 ÷ X」。**固定席があれば席数が優先**という構造は、v2 の `seats = floor(床面積 / 1席面積)` と同じ形。

## 効く箇所(seam)

- **`crowd.py` の `DEFAULT_SEAT_AREA_M2 = 4.0` は本条(四)項ロと逐語一致**。repo には出所の記載が無い(コメントは expedient とだけ言う)ので、**由来か偶然かは判定できない**が、**4.0 を mechanism へ昇格させる根拠にはなる**。
- `SEAT_AREA_M2 = {"food": 2.0, "nightlife": 2.0}` は本条(三)項ロの **3 m²** とも建告1441 の飲食室 **1.43 m²** とも一致しない = **帯の中にあるが出所が無い**。既定を 3.0 にすれば法定値になる。
- 劇場・イベントの「立見 0.2 m²/人」は、催事セルの上限密度として使える。

## 批判・限界

- **収容人員は消防用設備等の設置基準を決めるための行政上の数**であって、実在人数の平均でも上限でもない。「この人数までは想定されている」という**法の想定値**。
- 建築基準法(建告1441)の在館者密度と**同じ用途で違う値**を持つ(飲食: 消防 3 m²/人 vs 建告 1.43 m²/人 = **2.1 倍**)。どちらを採るかは設計判断 = **感度腕 2 本で扱うのが正しい**。
- 令別表第一の項番号 → `w6_poi.cat` の写像は本メモには無い(`nightlife` が(二)項か(三)項かで長いす式の除数が 0.4 / 0.5 と変わる)。
