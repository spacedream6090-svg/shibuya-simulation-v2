# Roberts, Kuncel, Shiner, Caspi & Goldberg 2007 — The Power of Personality

- リンク: https://doi.org/10.1111/j.1745-6916.2007.00047.x (全文: https://pmc.ncbi.nlm.nih.gov/articles/PMC4499872/) | 分野: 人格心理学 #13 | 重要度: **P2**
- **一次確認**: **実読**(2026-09-17・サブが PMC 本文を取得し Figure 1–3 の数値と General Discussion を読取)。**親未確認**。*Perspectives on Psychological Science* 2(4), 313–345。

## 主張(claim)

「性格の効果は小さいから重要でない」という批判を、**同じ土俵で比べる**ことで反証した。前向き縦断研究に限り、背景要因を統制した上で、**死亡・離婚・職業達成**に対する性格の予測力を、社会経済的地位(SES)と認知能力(IQ)と並べる。結論: **性格の効果は SES・IQ の効果と区別がつかない大きさ**。

## 数値(Figure 1–3・相関メトリック)

**死亡(Fig.1)**

| 予測子 | r | CI |
|---|---|---|
| 低 SES | .02 | [.017, .026] |
| 低 IQ | .06 | [.03, .09] |
| **勤勉性(低いほど死亡)** | **−.09** | [−.12, −.05] |
| 外向性・陽性感情 | −.07 | [−.11, −.03] |
| 神経症傾向 | .05 | [.02, .08] |
| 敵意・低協調性 | .04 | [.02, .06] |

→ **性格は SES より強く、IQ と同程度**。

**離婚(Fig.2)**

| 予測子 | r | CI |
|---|---|---|
| SES | −.05 | [−.08, −.02] |
| **神経症傾向** | **.17** | [.12, .22] |
| **協調性** | **−.18** | [−.27, −.09] |
| **勤勉性** | **−.13** | [−.17, −.09] |
| IQ | 集約せず(2 研究・結果が矛盾) | — |

**職業達成(Fig.3・標準化 β)**: 親の SES/学歴 β=.09 / 親の収入 .14 / IQ .27 / **性格(加重平均)β=.23** [.14, .32]。

**General Discussion の要旨**: SES・認知能力・性格の効果量は「一様に小〜中程度」であり、「ほとんどの心理学的構成概念の効果量は相関尺度で .10〜.40 の範囲にある」というレビューと整合する、と述べる。

Table 2 は死亡に関する 34 研究を列挙(多くで SES・認知能力・性別・疾患重症度を統制)。ハザード比・相対危険を相関メトリックに変換して掲載。

## 機構(mechanism)

**比較のベンチマークを置く**という方法そのものが機構。「小さい」は絶対値でなく比較で決まる。r=.09 は単体では小さいが、**同じ結果に対する SES の効果 .02 の 4.5 倍**である。

## 効く箇所(seam)

- 性格 → 行動の係数を置く/置かない判断の**根拠の型**。「r=.17 は小さいから入れない」は誤った推論であることの外部根拠。
- ただし本 repo が扱うのは**日常行動**(会話・移動)であって、死亡・離婚・職業達成のような**人生の帰結**ではない。**この表の値をそのまま日常行動に移してはいけない**(帰結の時間尺度が違う)。

## 「結論でなく機構として」の入れ方

数値を輸入しない。**「効果量は比較の中で読む」という規約**だけを輸入する。

## コスト/スケール含意

なし。

## 批判・限界

1. **帰結が長期**(死亡・離婚・職業)。本 repo の照合先(1 日の会話数・訪問地点数)とは時間尺度が 3 桁違う。
2. 前向き縦断に限ったとはいえ、**メタ分析ではなく研究の平均**。CI は研究間ばらつきを含む。
3. 2007 年の値。[[personality__soto2019_loopr]] が示すとおり、**公刊値は追試で 23% 縮む**——この表も同じ圧力を受けているはず。
