## §0 要旨

1. 文の側(Generative Agents・MemGPT・Mem0・Evo-Memory)は、文をモデルの外に書き、検索して読み直す流れで、重みは変わらない。測っているのは事実の想起(MemGPT の DMR 93.4%・Mem0 の LOCOMO 66.88)と課題の成績(Evo-Memory の ReMem 0.78)が大半で、本人の性格や感情の一貫性を指標にした論文はこの 4 本に無い [S1][S2][S5]。
2. 一貫性を測った研究は別の流れにある。指示は 8 往復以内で流れ [S12]、会話の履歴を足すと性格の測定のばらつきが増えることがあり [S14]、出来事の後の性格の動きの人ごとの広がりは人の 3〜4 分の 1 に縮む [S15]。
3. 重みを変えずに一貫性が上がった例もある。人格に沿う選択は、記憶なしの偶然の水準(25% 前後)から記憶つきの最良 64.9% まで上がった(同じ 150 問で人は 80.8%、最良の模型は 64.0%)[S10]。事実・推測・感情を分けて書かせる形では、決定が覆る率が新しい模型で 82% 減った [S17]。外に持った感情の数を戻す形は、25 往復の試験で状態なしより回復が安定した [S16]。
4. 重みの側で Qwen3-8B の行があるのは睡眠の論文(2606.03979)で、AIME-24 が 73.8 から 79.2 へ上がった。これは数学の成績で、人格は測っていない。全体で 1 つのモデルの話で、人ごとの更新は書かれていない [S26]。
5. Titans と TTT-E2E は文脈を重みに畳む形で、報告はどちらも自前で学習した模型(170M〜3B)である。素の模型に試験時学習をかける形は、玩具の試験で基準をわずかに上回っただけだった。畳むと細部は落ち、S-NIAH は 128K で 0.06 まで下がる(全注意は 0.99)[S21][S23]。
6. 状態を持つ模型で 7〜9B の公開の重みがあるのは RWKV7-7.2B・Qwen3.5-9B・Granite-4.0-H-Tiny(いずれも Apache-2.0)と PLaMo 2.1-8B(コミュニティライセンス)である。構成から数えると 1 人の状態は 34 MB・50 MB・29〜58 MB で(PLaMo は構成の値が読めず空欄)、35 万人では 10〜20 TB になる【見立て・算術】。R-141 のベクトル 1 本(8 KB)の 3,500 倍以上にあたる。
7. 日本語の値を同じ表で比べられるのは Qwen3-8B(Swallow の日本語平均 0.491)と Qwen3.5-9B(0.534)である [S50]。PLaMo 2.1-8B は開発元の表で pfgen 0.893(同じ表の Qwen3-8B は 0.634)[S47]。RWKV-7 は 0.1B の札に ja とあるだけ、Granite は札に日本語を挙げるが、どちらも日本語だけの値は見つからなかった [S35][S44]。
8. 保存と再開の口は RWKV にある(`forward(token, state)`・初期状態を学ぶ state tuning)が、RWKV は vLLM の対応表に無い。vLLM の Mamba と GDN の状態はブロックの境目の接頭辞キャッシュで、利用者が保存して戻す口は文書に書かれていない [S36][S39][S56][S58]。
9. 決定論の前提が変わる。`VLLM_BATCH_INVARIANT=1` は GDN を持つ模型で起動時に止まり(#42960・open・0.28.0 でも確認)、直す PR #45819 は未合流である。Mamba 混成と RWKV は試験済みの一覧に無い。RWKV-7 の論文は状態の更新が数値の精度に敏感と書く [S61][S62][S57][S32]。
10. Qwen3-8B のままでできるのは、文の記憶の全部・夜の文の書き直し・操舵・型ごとの LoRA・夜の微調整までである。替えないとできないのは、模型の中に状態を持ち越す形(RWKV・Mamba・GDN)と Titans・TTT-E2E の形である。文で持つ人格と状態で持つ人格を同じ物差しで比べた研究は、検索の範囲では見つからなかった(§5・§8)。
