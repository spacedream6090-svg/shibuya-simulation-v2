# 渋谷駅周辺「5エリア」定義の一次確認

調査日: 2026-09-04 / 調査範囲: Web公開資料のみ（読むだけ・リポ書き込みなし）

## ① 結論（定義が取れたか・粒度）

**取れた。ただし粒度は「主要幹線+鉄道による分割を示した縮尺付き地図（図）」まで。町丁目リスト・境界道路の条文・GeoJSON は存在しない（公開範囲内では未確認）。**

3行でまとめると:

1. **シブヤ クリエイティブ・ジャンクション（SCJ）本体には境界情報が無い。** 同サイト `/about_areas` は5エリアの**名称・キャッチコピー・説明文のみ**。API `space_areas` も `{id, name, name_en}` だけでジオメトリを返さない。地図ページ `/spaces` の JS チャンクにもポリゴン/GeoJSON は含まれない（全チャンクを grep 済み・後述）。エリアは**スペース1件ごとに付与された属性**として運用されている。
2. **原典は渋谷区『渋谷駅中心地区まちづくり指針2010』（平成23年3月）** の **p.11-12【エリア】** と **p.17-18 指針1「エリアごとの特性を活かした高次な機能の集積・導入」**。SCJの5エリア名・説明文はこの文書のエリア①〜⑤のほぼ逐語的な引き写し（番号の振り方だけ違う）。
3. **境界の粒度**: p.18 の図「■渋谷らしさを構成する駅周辺地域」に、**実地図の上にオレンジ破線で5分割線**が引かれている（縮尺・方位付き、1:約1万）。分割線の実体は **(a) JR線（山手線・埼京線の線路敷）= 南北軸、(b) 国道246号(玉川通り)＝駅の西側／六本木通り＝駅の東側 = 東西軸、(c) 駅直近を囲む多角形（エリア⑤）**。外周は **都市再生緊急整備地域「渋谷駅周辺地域」約139ha** の区域線。

→ ポリゴンを厳密に再現したいなら「JR線 + 国道246号/六本木通り + 139ha区域線」の3レイヤから合成するのが最短。**エリア⑤の外形だけは図から手でトレースするしかない**（法定境界ではないため公的な線形が存在しない）。

→ 「その他」エリアは笹塚・幡ヶ谷・本町・恵比寿・代官山・原宿など、意図的に bbox 外を含む受け皿。

### 3-2. 区域図からの幾何推定 [推測]

公式区域図の縮尺バー（1000m≈520px）と渋谷駅表示位置から読み取った 139ha 区域の外周（=5エリアの外縁）の概略:

- 南端 ≈ lat 35.652（±0.001）… 鶯谷町/代官山寄り
- 西端 ≈ lon 139.690（±0.001 ≈ ±90m）… 南平台町/鉢山町・旧山手通り付近
- 東端 ≈ lon 139.708（±0.001）… 東2丁目/青山寄り

### 3-3. エリア別の所見 [推測]

- **01 中心 / 03 北東 / 04 南東**: 完全に bbox 内。余裕も大きい。地形的にも駅から600m以内。
- **02 北西**: 東側〜中央は完全に内側。ただし指針図の外縁は **松濤・観世能楽堂・Bunkamura の西側（≈139.692）** まで及ぶので、bbox 西縁 139.6905 のすぐ内側。**神泉/松濤の縁が数十m単位で切れる可能性**。SCJの実データでは最西が円山町の 139.69516 で余裕あり。
- **05 南西**: 桜丘町中心で bbox 内。ただし指針図の外縁は**旧山手通り（南平台町・鉢山町）**まで及び、ここが**5エリア中で最も bbox 西縁をはみ出しやすい部分**。実データ最西 139.69399（桜丘町）はまだ内側。
- **境界線そのもの**（JR線・国道246号・六本木通り）は全て bbox 内を通るので、**5エリアの内部分割は bbox 内で完結する**。欠けるとすれば外縁の西側の縁だけ。
- 全体として: **v2 bbox（3.8km²）は 139ha 区域（1.39km²）の約2.7倍**なので、5エリアは bbox の中央部にすっぽり収まり、bbox の外周部（代々木公園・原宿・恵比寿・神泉奥・鶯谷町の外側等）は5エリアの「外」＝SCJで言う「その他」に相当する。

## ④ 未確認の正直な列挙

1. **GeoJSON / シェープファイルは見つからなかった。** SCJ の公開JSチャンク全21本（`/spaces` と `/about_areas` の全ロード対象）を grep したが `geojson` / `MultiPolygon` / `coordinates` / ポリゴン座標列はゼロ。API も `space_areas` はジオメトリを返さない。**「存在しない」ことは証明できていない**（認証付きAPI・都市OS(FIWARE)側・区の内部GISに存在する可能性は未確認）。
2. **町丁目リストによる定義は未発見。** 指針2010 にも都の景観指針にも、5エリアを町丁目で列挙した表は無い（読んだ範囲では）。都市再生緊急整備地域の**政令上の区域告示**（町丁目・地番レベルの文言があるはず）は未確認 — 地域整備方針PDF `assets_kankyo_000059086.pdf` は未読。
3. **指針2010 のPDFはテキストレイヤ無し**（全25ページ・抽出文字数0）。②に転記した指針2010の本文は**私が画像を目視で書き起こしたもの**で、機械抽出ではない。細部の助詞・読点に転記誤りが残りうる。正典化するなら原本PDFを再確認すること。
4. **図からのトレースは目測。** ③3-2の緯度経度はランドマーク照合と縮尺バー読みによる概算で、誤差 ±100〜200m。**エリア⑤（中心）の多角形の頂点座標は取っていない**。
5. **KDDI Location Analyzer 側のポリゴンとの一致は未検証。** Power BIダッシュボードのポリゴンが指針2010の図と同一線形かは確認していない（ダッシュボード自体にアクセスしていない）。SCJが「点への属性付与」で運用しているのに対し、KDDI側は面のメッシュ集計なので、**両者の線引きが微妙に違う可能性は高い**。
6. **渋谷区オープンデータカタログ・東京都オープンデータカタログでの5エリアポリゴン公開の有無は未確認。**
7. **『渋谷駅中心地区基盤整備方針』(2012) と『渋谷駅周辺まちづくりビジョン』(2016) は本件エリア区分の記載を未確認**（前者はテキストレイヤ無しで未目視、後者はテキスト抽出で「エリア」ヒット0）。
8. SCJ の各スペースの `space_area_id` は**運営者の手入力**とみられ（新宿高島屋が北東エリアに入っている）、**エリア割当を境界の代理指標に使う場合はノイズが混じる**。
9. 「渋谷駅周辺地域」139ha の指定区域は **R3.8.11 に変更**されている。指針2010(H23) の図の外周は変更前の線の可能性があり、現行の区域図と完全一致するかは未照合。
