1. **テープの本体は手元にあり、案 (a′) は作れます。** c7-day-4 の seed 1・2・3 の `calls.parquet` が残っています。案 (a) へ戻す条件には当たりません。

### 3-3 公開の前に決めること

ODbL の 4.4(c) により、図や動画を公に使うと派生データベースも公に使ったことになり、4.6 の提供義務がかかります(台帳 9 行)。W1・W7・W11 は OSM とそれ以外が混ざり、セルと歩ける面もその上にあります。提供方法の第一候補は構築の道具の公開で、決める時期は「ODPT の作品の壁打ち」とされています([10-13b](../design/v2-answers-2026-10-13b.md) の 1-6)。**PLATEAU の提出はそれより先に来ます。** 公開は止まる地点 S2 なので、ユーザーの判断が要ります。
