## 決定規則の要約(この表で使う記号)

- **A** 人や組織の判断で決まるべき量を、規則で決めない。口がまだ無いものは「無い」と宣言する。集計の量で世界を動かさない。
- **B** 代打を例外として認める条件は 5 つ。①主体が体として世界に居る ②規則が書くのは「その人がやるはずの行為」で、集計の率ではない ③conf と外す段を宣言する ④代打の回数を計器に出す ⑤代打の出力が、その過程を検証する錨の系に入らない。
- **C** 行き先は 5 つ。L1 残す/L1.5 判断モデル/L2 LLM/初期の予定/無いと宣言(5 条件を満たせば代打として残す)。
- **D** 集計の率を式で入れている 5 件は外す。価格の改定確率・出勤率・宅配・倒れる率・催しの 200 人注入。
- **E** 循環 3 件(宅配と W2・倒れる率と W3・価格の β と E7)は、錨を検証に残す側で解く。
- **F** 最低賃金と労働時間は machine→human。検知と反応の口ができるまで、machine をつなぎに残す。
- **G** 入力は 5 つ。訪日の母集団・景気と物価・区の政策の決定・運行の乱れ・催しの情報。

表の「いまの決め手」の頭の記号は棚卸しのままです。L2=LLM(既定は mock の一様抽選)/L1=体と System 1/E=エンジンの規則/D=構築時のデータ/—=口が無い。

## §6 要判断の行

### 6-1 §4-2 の体と知覚の過程の置き場(#18・34・60・77・82・86)

- 理由: C は「裏付けの無いもの(§4-2)は L1 に残さない」と決めた。でも、これらは本人の判断でもない(疲れる・暑く感じる・着信に気づく・段を越える・避ける・看板が目に入る)。なので L1.5・L2 には行けず、行き先が規則に無い。
- 選択肢:
  - (a) **L1 に置き、値だけを conf 宣言のつなぎと研究の題にする。** C の基準を「仕組みに裏付けがあれば L1、値は研究の題」と読み替える。#77 疲れ・#82 暑さ・#86 段の区切りがこれに合う。
  - (b) **外して「無い」と宣言する。** 例:「疲れは世界に無い」。#60 着信の気づきは既定 off なので、これでも影響は小さい。
  - (c) **#82 は WBGT→熱中症の体の式(#83 の置き換え先)にまとめる。**
- #34 だけは別の問題がある。注視(どこを見るか)は本人の向き(判断)にも関わる。錨 0.70 は率なので、A により駆動には使えず、検証に回す。
- #18 は答申 R-93 を読んでから決めるのがよい。

### 6-2 起床の門(#66・67・68)

- 理由: 「ずれを検出する」部分は §4-1 で L1 です。でも、不応期・就寝と域外の抑止・活動層の抑止は「暴発の上限の装置」で、人の研究の裏付けが無い。置き換え先の DM8(変化と時刻の入口)と驚きの点数が L1.5 なのか L2 なのかも、C から決まらない(C は「終えるか」を L1.5、「驚いた後に考え直す」を L2 に置いている)。
- 選択肢:
  - (a) 行を分ける。検出は L1 残す、「考え直すか」は L1.5(DM8)、考え直した中身は L2。
  - (b) 不応期と抑止は、DM8 ができるまで呼の予算の装置として conf で残す。「人の行為ではない・予算の都合」と宣言する。
  - (c) #67 のうち域外の人は、範囲外の層ができるまで「域外の人の思考は無い」と宣言する。寝ている間は、体の睡眠の研究の題にする。

### 6-3 記憶の書き込み(#91・93)

- 理由: §4-1 にあるのは「活性と忘却」(#92・58)だけ。覚える(書き込む)・口コミを受けることは名指しされていない。

### 6-4 気づきと驚きと向き(#57・89・90)

### 6-7 組織の主体と入力の境(#35・73・107・108・111・112)

- **#35 看板の文**: (a) 入力(現実の看板データ)(b) 店主の L2(店主の体ができたら)(c) 作り物を代打で残す(① 店主の体が無いので ×)。(c) は B を満たさない。

### 6-9 規則の側の空欄
