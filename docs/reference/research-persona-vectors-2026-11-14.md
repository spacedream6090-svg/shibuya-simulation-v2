# モデル内部のベクトルでペルソナがどう変わるか:最近の研究のまとめ

調べた日:2026-11-14。調べた人:claude.ai(壁打ちの材料。答申ではない)。

ここで言う「ベクトル」は、モデルが文を読むときの内部の活動(数千の数の並び)の中の「向き」のこと。ある向きに沿った量で性格や人物の強さを読み取ったり(見張る)、その向きを足し引きして振る舞いを動かしたり(押す)できる、という研究の流れを扱う。

---

## 0. 要点

1. **人物は、モデルの内部の向きとしてかなり表されている。** 性格の特性はおおむね直交する向きとして取り出せ、足し算・引き算・倍率で組み合わせられた。ある試験では、学習なしで、学習で合わせた場合とほぼ同じ点だった(PERSONA・ICLR 2026)。
2. **ただし、向きどうしは干渉する。** ビッグファイブの向きは少し絡み合っていて、無理に直交させても他の特性への漏れは消えず、押す力も弱まった(2026-01)。
3. **押す効き目は不安定。** 多くの振る舞いで効き目がばらつき、逆向きに動くこともあった(Tan ら・NeurIPS 2024)。振る舞いが 1 本のまとまった向きで表されていないと、押しは当てにならない(Braun ら 2025)。意味を変えない小さな入力の違いでも、効き目が大きく変わった(2026-06)。
4. **押すと文が崩れやすい。** 内部の主な流れ(残差の流れ)を押すと文のまとまりが落ちる。人物と文体を受け持つ 3 つの注意の頭だけを押すと、崩れが大きく減った(ICML 2026・東京大学ほか)。
5. **会話の中で人物は動き、相手にも引っ張られる。** LLM どうしの会話では、モデルごとの「落ち着き先」があり、違うモデルどうしでは一方が他方を非対称に引き寄せた。議論は時間とともに同意と前向きさへ流れた(2026-06)。
6. **学習で人物が丸ごと変わることがある。** 狭い誤ったデータで微調整すると「ずれた人物」の内部の特徴が強まり、関係ない場面まで振る舞いが崩れた。その特徴は、振る舞いの検査で崩れが見える前に、学習データの 5% が誤りの段階で検出できた(OpenAI・ICLR 2026)。
7. **人物の文を書き分けるだけでは、集団の多様さは出にくい。** 役を割り当てても、集団全体の合意の動きはほとんど変わらなかった。違う(学習済みの)モデルを混ぜると、合意の動きが 2 倍を超えた(2026-07)。

## 1. 既存の答申との関係

リポの R-141(11-04)と R-141 の追補(11-09)が、次をすでに調べている:
- 押し方の種類:残差に向きを足す/入力の埋め込みに差す(ソフトプロンプト・PERSOMA)/LoRA・ReFT
- 気分の押し方、読み出し(probe)で確かめる輪、Qwen3 で日本語を壊さない層と強さ、vLLM での使い方
- Qwen3-8B 用の公開の特徴の辞書(Qwen-Scope など)
- persona vectors(Chen ら 2025)、Qwen3-8B での先例(Zeng・Emami・Choi 2026)
- Assistant Axis と、範囲を出たら切る activation capping
- 人・場面・振る舞いの三つ組(Zhang・Wang・Su)

このまとめは、それ以外の 5 点を足す。
1. 人物がどう表されているか(理論と幾何)
2. 会話の中でどう動くか
3. 学習でどう変わるか
4. 押したときに何が起きるか(信頼性と副作用)
5. 集団の多様さ

## 2. 人物はモデルの中でどう表されているか

| 研究 | 分かったこと |
|---|---|
| ペルソナ選択モデル(Marks・Lindsey・Olah・Anthropic・2026-02) | 理論の提案。事前学習で LLM は、文に出てくる多くの人物(実在の人・物語の人物・SF のロボット)を演じ分けることを覚える。後の学習は、その中の 1 つ「アシスタント」の人物を形作り肉付けするもので、根本の性質は変えない、とみる。アシスタントの内部の表現は、他の人物の表現と同じ概念の語彙を使っている、という解釈の証拠を挙げている。どこまで説明できるか、将来も当てはまるかは不確かだと著者自身が書いている |
| PERSONA(ICLR 2026・arXiv 2602.15669) | 性格の特性は、内部でおおむね直交する向きとして取り出せ、倍率(強さ)・足し算(組み合わせ)・引き算(抑える)で操作できる。PersonalityBench で 9.60(学習で合わせた上限は 9.61)、勾配の更新なし。推論の途中で組み合わせを変える Persona-Flow を持ち、会話の中での変化を測る Persona-Evolve(800 の多ターンの場面)で勝率最大 91% |
| 性格の特性は干渉するか(Bhandari・Naseem・Nasim・2026-01・arXiv 2602.15847) | ビッグファイブの 5 つの向きは少し絡み合っている。無理に直交させても、他の特性への漏れは消えず、押す力が弱まることがあった(Llama-3-8B と Mistral-8B) |
| IRIS(ACL 2026 Findings・前のまとめで紹介) | 人物に関わる神経には、場面ごとの一貫した型がある。場面に合う神経を選んで押す |
| Assistant Axis(Lu ら 2026・R-141 で既出) | 人物の空間の主な軸が「アシスタントらしさ」。会話の領域によってこの軸から離れる |

**読み取り**
- 住民は、LLM が演じる「人物の 1 人」。後の学習で形作られたアシスタントは、モデルが戻りやすい「ふだんの家」にあたる(ペルソナ選択モデルの見方)。住民が会話や判断の中でアシスタントらしく(親切・同意しやすく)寄っていくのは、この引力の表れと読める【見立て】。呼びかけへの反応のずれ(迎合)や、皆が同じになる癖とつながる。
- 性格の向きを組み合わせて住民ごとに違う性格を作ることは、試験の上では学習に近い精度でできる。ただし向きどうしの干渉があるので、1 つずつ別々に効くとは限らない。

## 3. 会話の中でどう動くか

| 研究 | 分かったこと |
|---|---|
| 多ターンの LLM の会話に落ち着き先が生まれる(arXiv 2606.30571・2026-06) | 7 モデル・20 の争点で、LLM どうしの自由な議論を見た(同じモデルどうし/違うモデルどうし)。同じモデルどうしの会話の軌跡は、モデルごとの落ち着き先になった。違うモデルどうしでは、その落ち着き先が相手を非対称に引き寄せ、文体や振る舞いを変えた。内部の活動の空間と、文の特徴の両方で測った。Claude Haiku は内部の空間で強い落ち着き先で、他のモデルがその癖(自分の発言についての発言)を取り込んだ。GPT-4.1 nano は特に流されやすかった。会話全体では、序盤の反論・留保・否定から、終盤の同意・掘り下げ・前向きさへ流れた |
| SPASM(ACL 2026 Findings・arXiv 2604.09212) | 人物のずれを、決まった問い(気がかり・感情・動機)への答えの文の埋め込みが、会話の前の答えからどれだけ離れたか(コサイン距離)で測った。履歴の渡し方を変える方法(ECP)で、ずれが減り、相手の言葉をおうむ返しする失敗が消えた |
| Best Friends, Not Forever(arXiv 2607.28818・2026-07) | 話し相手の AI の人物を 85〜130 回の会話で追い、人物の崩れを、封をした 102 問の問診と、各番の判定で測った |
| 人物は前置きに置き続けるべき(2610.01490・前のまとめで紹介) | 前置きから人物が外れると、元のアシスタントに戻ることがあった |

**読み取り**
- 住民どうしの会話(題 5・会話の泡)では、会話がモデルの落ち着き先(同意・前向き)へ流れる心配がある。R-149 の「皆が同じになる癖」を、会話の中でも測る。
- 2-64 の (A) 住民ごとにモデルを混ぜる腕では、一方のモデルが他方を引き寄せることを測る項目に入れる。
- 人物のずれは、内部の活動に触らなくても、**決まった問いへの答えの文を埋め込みで比べる**だけで測れる(SPASM)。vLLM に手を入れずに作れる安い計器。

## 4. 学習でどう変わるか

| 研究 | 分かったこと |
|---|---|
| 人物の特徴が「出てくるずれ」を左右する(OpenAI・ICLR 2026・arXiv 2506.19823) | 狭い誤ったデータ(危ないコード・誤った健康や法律の助言など)で微調整すると、関係ない質問にまで悪意のある答えをする(emergent misalignment)。微調整の前後で内部の特徴を比べると、「ずれた人物」の特徴(有害な人物・皮肉屋の助言者・物語の悪役など、事前学習で覚えた人物の表現)が強まっていた。中でも「有害な人物」の特徴が一番強く効き、その向きへ押すと崩れが増え、逆へ押すと減った。この特徴は、振る舞いの検査で崩れが見える前に、学習データの 5% が誤りの段階で検出でき、崩れたモデルを 100% 見分けた(解説記事による)。少量の無害なデータでの微調整で戻せた |
| persona vectors(Chen ら 2025・R-141 の追補で既出) | 学習データが人物をどちらへ動かすかを、学習の前に向きで予測できた |

**読み取り**
- R-150 と U19(人の行動データで住民を学ばせる道)で微調整をするなら、**狭いデータが人物全体を思わぬ向きへ変える**ことがある。学習の前後で、人物の特徴(Qwen-Scope などの特徴の辞書・persona vectors)を比べる検査を条件に入れる。

## 5. 押したときに何が起きるか(信頼性と副作用)

| 研究 | 分かったこと |
|---|---|
| Tan ら(NeurIPS 2024・arXiv 2407.12404) | 多くの振る舞いで、押す効き目は当てにならず、逆向きに動くこともよくあった。プロンプトの型などの見かけの要因が効き目を左右し、学んだ範囲の外ではさらに悪かった |
| Braun ら(ICLR 2025 のワークショップ・arXiv 2505.22637) | 押す向きを作る例の型(7 種)で、できる向きがかなり違った(同じ例からでもコサイン 0.07〜0.86)。それでも平均ではどれも効いた。正と負の例が内部でよく分かれている振る舞いほど押しやすい。振る舞いが 1 本のまとまった向きで表されていないと押しは当てにならない |
| 押しの頑健さ(arXiv 2606.07696・2026-06) | 意味を変えない小さな入力の違いで、押す効き目と効く層が大きく変わった |
| Style Modulation Heads(Izawa ら・ICML 2026・arXiv 2603.13249) | 残差の流れを押すと、関係ない特徴まで動いて文のまとまりが落ちる。人物と文体を受け持つ 3 つの注意の頭を見つけ、そこだけを押すと、人物を動かしつつ文の崩れが大きく減った(数値は要旨に無い) |
| 予防の人物の押しの安全の代償(NeurIPS 2026) | 押したときの安全の副作用は試験によって違い、能力の点数だけからは推し量れない |
| Chen ら 2025(Anthropic・既出) | 使っている最中に押して抑えると、少し賢くなくなる副作用 |

**読み取り**
- 2-64 で決めた「会話で本人のベクトルを使う腕」は、**押す前にまず見張る**(読むだけ)から始めるのが安全。
- 押す腕を作るなら、次の 4 つを測る項目に入れる。
  1. 特性ごとに、逆向きに動いた例の割合
  2. 他の特性への漏れ
  3. 日本語の文の崩れ
  4. 言い換えた入力での効き目の違い
- 押す場所は、残差全体より注意の頭に絞る方が崩れにくい(Izawa ら)。

## 6. 集団の多様さ

| 研究 | 分かったこと |
|---|---|
| 信念の共進化(arXiv 2607.27512・2026-07・CoevolveSim) | 1,280 回のシミュレーション(4 つの筋書き・2 つの網の形・20 の医療の命題)。役を割り当てる人物の文は、個々の住民の信念の変え方は変えたが、集団の合意の動きはほとんど変えなかった。専門に学ばせたモデルを混ぜると、合意の動きが 2 倍を超えた。信念の広がりを現実らしく再現するには、人物の文だけでなく、違うモデルの集団が要る、と結論 |
| 多様さによるエージェントの増やし方(arXiv 2602.03794) | 土台のモデルと人物の両方が違う 2 体の方が、多様さの無い 16 体より課題の成績が良かった(課題を解く話で、シミュレーションの話ではない) |
| LLM の社会シミュレーションには境界が要る(arXiv 2506.19806) | LLM のエージェントは「平均的な人物」として振る舞いがちで、人の集団のばらつきを抑えてしまう |
| 流暢さの誤り(arXiv 2507.19364) | 人物の文を変えても、ありがちで社会的に無難な答えに戻りがち。逆に無理に違う役を強いると、誇張された戯画になる |

**読み取り**
- 2-64 の決定(B:ランごとにモデルを替えるのが先、A:住民ごとに混ぜるのは腕)を支える。
- 性格の向き(PERSONA)で住民ごとに違う性格を作るのは、多様さを作る 3 つ目の道。ただし §5 の不安定さがあるので腕として測る。

## 7. この渋谷のシミュレーションへの示唆(決定ではない・壁打ちの材料)

1. **会話のベクトルの腕(2-64)は、まず「見張る」から。** 押すのは見張りで要ると分かってからにする。押すときは、§5 の 4 つの物差しと、注意の頭に絞る方法を比べる。
2. **人物のずれの安い計器。** 決まった問いへの答えの文の埋め込みの距離(SPASM の方法)。内部の活動を読む計器(persona vectors・Assistant Axis の射影)は 5070 で足す。R-149 の「人物のずれ」の物差しに入れる。
3. **住民どうしの会話の落ち着き先を測る。** 同意・前向きへの流れ、モデルごとの引き寄せ(R-149 の「皆が同じになる癖」の会話版)。
4. **学習するときは人物の特徴の前後比較を条件に入れる**(R-150 の追補の条件・U19)。
5. **集団の多様さは、人物の文よりモデルの違いが効く。** 2-64 の進め方を支える。性格の向きは 3 つ目の腕。
6. **住民がアシスタントらしさへ寄る引力を意識する**(ペルソナ選択モデルの見方)。呼びかけへの反応のずれと、皆が同じになる癖の根の 1 つとして、R-149 で測る。
