### 6-1. PS2 の属性の表と PS4〜PS7 の中身(壁打ちで示し、ユーザーが承認したもの)

**PS2 何を持たせるか**

| 属性 | データの候補 | 状況 |
|---|---|---|
| 年齢・性別・世帯(誰と住むか・続柄) | 国勢調査・合成人口 | 作り直す |
| 住まい | 国勢調査の小地域 | 作り直す |
| 仕事(職業・産業・雇用形態・勤め先) | 経済センサス・法人番号 | 作り直す。勤め先は開始時点の組織データ(CP6) |
| 学校 | 学校基本調査・公式の時程 | 作り直す |
| 収入と資産 | 賃金構造基本統計調査・全国家計構造調査 | 経済の段で(EC2) |
| 使える言語と程度・国籍 | 在留外国人統計・訪日外客の統計 | 追加(§4-8) |
| 持ち物(自転車・車・スマホ・アプリ) | 保有率の統計 | CT で決定済み |
| 体(身長・体重)と感覚(視力・聴力) | 国民健康・栄養調査・年齢別の感覚のデータ | 体は済み。感覚はデータを探す |
| 移動の助け(車いす・杖・ベビーカーなど) | 統計を探す | 新しく足す |
| 関係(家族・同僚・友人) | 家族と同僚はデータから。友人は慣らしの期間で本人たちが作る | 決定済み |
| 好みと習慣 | 割り当てない。開始前の経験と慣らしで出てくる | 決定済み(DM-0・MR) |
| 声の大きさの人の差 | R-95(SD 3〜4 dB・男女 56.3/51.7 dB) | ペルソナの材料 |

**PS4 開始前の経験**
- データで分かる事実(家・勤め先・世帯・同僚・通勤の道・住んでいる年数)を入れる。
- その上に、**開始前の習慣の初期化を TimeGeo 型を核に 1 つ**で行う(指示書 §4-10。PS4 の当初案「粗い前段のシミュレーション」は、この決定で**比べる腕**に変わった)。手順の骨組みは次のとおり。
  1. なじみの場所の数を、約 25 か所の分布から一人ずつ引く(Alessandretti 2018)。
  2. 順位ごとの行く頻度を、k の −1.2 乗の法則で決める(Song 2010)。
  3. 実在の店と場所を、家と職場からの距離と、その人の生活(年齢・職業・世帯)に合う業種から当てはめる。当てはめの規則は設計者の指紋になるので、感度試験で効きを確かめる。
  4. 住んでいる年数(国勢調査の居住期間)が長い人ほど、行ったことのある場所が多い(時間の 0.6 乗)。
  5. あとは慣らしの期間で、住人自身の行動で育つ。
- 較正に使った法則と集計は、検証に使わない(パターン台帳 §10 の 5-3)。ランの結果で同じ法則が保たれているかを見るのは、診断としてかまわない。
- 近所や店の顔なじみは、なじみの場所が同じ人どうしが慣らしの期間に出会って育つ。
- 作り物の経験の文(LLM に経験を書かせる)は使わない。

**PS5 開始時点の組織**

| 項目 | 中身 |
|---|---|
| 会社と店 | 法人番号と経済センサスから |
| 役割 | 店長・正社員・パートなどの割合を、雇用形態の統計から |
| 部署 | SR2 の決定どおり(大きさは「1+部下の数」) |
| 権利台帳 | 雇用契約・店の持ち主・賃貸を、開始時点の値として入れる(CP4) |
| 働く人のエージェント | ②群(開店・補充・配送・運転など)を受け持つ人を、ここで割り当てる |

**PS6 人口とペルソナの検証**

| 見るもの | 比べる相手 |
|---|---|
| 年齢・性別・世帯・職業の分布 | 国勢調査・経済センサス(マクロで合うか) |
| 言語と国籍の分布 | 在留外国人統計・訪日外客の統計 |
| 住人の似通い(D-68 の画一性) | 行動のばらつきが人のデータのばらつきに近いか(DM6 のばらつきの比) |

注: 人口の作り直しに使った統計を、そのまま「合っている」の証拠にはしない(構築に使ったものは検証にならない)。上の表は「作った結果が統計と食い違っていないか」の点検として扱う。

**PS7 人物を LLM と判断モデルにどう見せるか**

| 項目 | 案 |
|---|---|
| 中身 | PS2 の属性を言葉で。Big Five は腕のときだけ |
| 言語 | その人の第一言語 |
| 長さ | 計算の都合では決めない。中身に必要な長さにし、実際の長さを測る |
| 作り方 | 同じ仕組みで、判断モデルには短い版、LLM には長い版を作る(DM4) |
| 改変との関係 | 改変した物を名指ししていないかを機械で調べる(CP5-3) |

## 2. 計画への注文

手順(段 0〜10 は GPU 不要・段 11 だけ GPU の後):

| 段 | やること |

### 2-0b. LLM が書いた人物と書いていない人物の比較(ユーザーの希望・今後の検証)

- 既定は §2-0 のとおり、人物の中身を LLM に書かせません(PS3 (b))。
- ただし今後の検証の一つとして、**「LLM が書いた人物像」の腕**を作り、書いていない人物(既定)と比べます。根拠は Li ら(NeurIPS 2025・arXiv 2503.16527)で、LLM が書き足す量が増えるほど模擬の結果が一方向にずれ、人物像が前向きで苦労の少ない方へ偏ったという報告です。原典の一次確認をしてください(リサーチ F 群に追加)。
- 腕の作り方: 同じ合成人口(同じ属性)の上に、LLM が書いた生い立ち・人柄の文を足す。書き足す量を段階で変える(属性だけ/属性+LLM が埋めた項目/自由な文章)。書かせた LLM と版は manifest に記録する。
- 比べるもの: マクロの結果(行動の分布・店や場所の選び方・お金の使い方など)の現実からの離れ方と、住人の似通い(D-68 の画一性・DM6 のばらつきの比)。比べる相手の現実データは検証専用の一覧から、事前登録の手順で。
- 時期: GPU の後(段 11 の後)。器(人物の文を差し替えられる口)は §2-0 の段 9 で用意しておいてください。
