### 2-1 重い問い

#### MR1 想起の式の形と係数(関係・エピソード・店の記憶に共通の形)

- 何を決めるか: C6 の「基底の活性+文脈の関連度」を式にする形。係数の値(と宣言の仕方)。関係・エピソード・店の記憶で何を共通にし、何を種類ごとに分けるか。「最後に会ってからの時間」を式に入れるか。
- 背景: 今の 3 つの表は同じ近似式 A = ln(n/(1−d)) − d·ln(L+1)(d=0.5)を使っています。L は「最初に書かれてから」の時間です(`relations.py`・`store_memory.py`・記憶 第 1 段 §1-6)。このため、ユーザー案の「最後に会ってからの時間」は今の式に入っていません(R-87 §1-3)。読み方は表ごとに違います。エピソードは score = w_r·A + w_i·importance(w_r=1.0・w_i=0.5・関連度の重み w_v=0)、店は A+0.5×min(4, 精度)、関係は P = 1/(1+exp(−(A−τ_rel)/s))(s=0.25)です。
- 選択肢(式の形)
  - (a) ACT-R 型(加算)。想起の強さ = B + w_ctx·cos(印象の埋め込み, 問いの埋め込み)。B は今の近似式のまま。単位が log-odds なので、τ と同じ尺度で「思い浮かばない」を切れます。w_ctx は錨が無いので expedient として宣言し、感度の腕を {0, 0.5, 1, 2} に置く案です(R-87 §4-1・推測)。
  - (b) (a) の B を ACT-R の折衷形にする。直近 k 回の本当の時刻を持ち、古い分は近似で足します。最後に会ってからの時間が効くようになります。関係辺 50 本で k=3 なら 600 B/体、39 万体で約 234 MB の増分です(R-87 §1-3・推測)。
  - (c) GA 型。recency(最後に想起されてからのゲーム内の時間に 0.995/時の減衰)・importance・relevance を min-max で [0,1] に正規化し、α=1 で足します(R-87 §1-4・原典で確認)。正規化が候補の集合に依存するので、同じ記憶の点数が周りの記憶で変わり、閾値で「思い浮かばない」を表しにくい、という短所があります(R-87 §4-1)。
- 選択肢(共通にする範囲)
  - (d) 草案の案(未リサーチ)。共通にするのは「B の式・τ の尺度・w_ctx」の 3 つ。種類ごとに分けるのは d(MR12)と、B に足す項(エピソードは importance、店は精度、関係は無し)。
  - (e) 草案の案(未リサーチ)。3 つの表の読み方を 1 本の score にそろえ、importance と精度も同じ係数で足す。
- 材料
  - ACT-R の基底の活性は B = ln Σ t_j^−d、近似は B = ln(n/(1−d)) − d·ln(L)。マニュアルは :bll(d)の推奨値を 0.5 とし、「数少ない強い推奨値の 1 つ」と書く(R-87 §1-1)。
  - 活性の広がりは S_ji = S − ln(fan)。:mas(S)の既定は nil で、「S はおよそ 2」という値は原典で確かめられていない(R-87 §1-1・空欄 #12)。
  - d=0.5 は Anderson & Schooler 1991 の本文には無い。環境の指数は .73・.77・.83、当てはめの d₁ は .125・1.0・1.5(R-87 §1-2)。食い違い §3 の 3 番。
  - LLM エージェントで基底の活性と埋め込みの関連度を合わせた先行は SYNAPSE と Hou ほか 2024。どちらも抄録だけで式の細部は未読(R-87 §1-5)。
- 影響する段と文書: R1 / 記憶アジェンダ M5・M6・M16 / C10 の読み口 / 店の記憶 N5・N6 / テープ版 4 の同定(MR16)。
- 親推奨: 式は (b)(ACT-R の折衷形: 直近 k 回の本当の時刻+古い分は近似。最後に会ってからの時間が効く)。共通にする範囲は (d)(B の式・τ の尺度・w_ctx の 3 つを共通、種類ごとに d と足す項を分ける)。GA 型 (c) は min-max 正規化が集団の大きさで動くので採らない。
