## 7. 確かめていないこと・測っていないこと

- 試験は 1 本も回していません。回したのは `pytest --collect-only -q` を印ごとに 1 回ずつ(計 3 回)だけです。
- ディレクトリごと・試験ごとの時間は測っていません(§2-1)。slow の CI での分、data のある全体の試験の手元の分、5070 の試走の分も測っていません。
- CI で「data 以外の理由で飛んだ 32 件」がどの試験かは確かめていません(§1 の注 2)。
- golden が作者の機械で A/A だけになった原因(どの欄が変わったか)は確かめていません(§1-1)。
- PR #10 の組の分け方・ロックのファイル・byte-check の 20 構成・未 commit の試験 6 本は、親からの知らせです。組の表(`tools/ci/test_shards.json`)の中身は読みましたが、ほかは確かめていません。
- 封印の語の AST の検査がどの試験かは確かめていません(`tests/c7` は開かないため)。
- 「消した旧道を試験の中だけで回す」関数の数は、助けを直に読む関数だけの下限です。fixture を通した使い方は数えていません。
- 艦隊に送る要求の全体の指紋を固定する試験があるかは、確かめていません(§4-2)。
- 案 K のとおりに動かす場合の、ファイルごとの行き先と本数は数えていません(§6-1 は引き算の見積り)。
- 先例との比べ(他の研究のプロジェクトや、大きな Python のプロジェクトの試験の組み方)はしていません。Web は使っていません。足す形の候補は、どれも未リサーチ(expedient)です。
