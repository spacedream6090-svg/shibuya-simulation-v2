## 要約

この章は、住民 1 人の心をどう作るかを決めます。

心は 1 つのモジュールです。速い過程と遅い過程は直列ではなく、速い過程は常に並行して動き、遅い過程が入って上書きします。心の内側には本人、記憶、期待、目標と予定、感情、考えかけ、他人についての主観などを置きます。体、持ち物と金、位置、世界の事実は外側です。他人から読めるのは見た目だけです。心は世界を直接読まず、知覚として受け取ります。その守り方も 11-09 に決めました(MD-55)。LLM が事前学習で持つ知識のうち、その生い立ちの人なら普通に知っていることは使ってよく、それを超える事実は本人の記憶にあるときだけ使います(MD-05)。

世界から心への入口は、休みなく流れる知覚です(MD-29・11-09)。物理として届いたかと、見回したときの場面は世界が計算します。System 1 が受け持つのは、System 1.5(判断モデル=候補ごとの確率を返す小さなモデル)を呼ぶかどうかの振り分けと、体の状態の見張りだけで、意味の表は持ちません。強い音・急な動き・接触・目の前での話しかけはすぐ System 1.5 へ回し、それ以外は溜めずに数秒の名残だけを持ちます。ひと区切りでは今の場面を見回し、何に気づくかは System 1.5 が本人の目的に照らして決めます。区切りの置き方や閾値は腕にして、検証で選びます(MD-56)。

驚いたかとその大きさは System 1.5 が決めます(MD-53)。System 2(LLM)へ上げるかも常に System 1.5 が決め、例外は言葉の中身を作るときと、眠っている間の意識しない整理だけです(MD-54)。熟考へ上げる引き金は迷い、驚き、行き詰まり、不慣れの 4 つで、「よく考える」という候補は置きません。考えている間も、歩くなどのやり直しのきく行為は仮に始めてよく、払う、約束するといった行為は結論を待ちます。今すぐ反応すると決まったときは、途中までの考えに刺激を知覚として足して続きを考えます。名前に気づく率のような研究の値の使い道は、答え合わせの基準である錨だけです。不応期(再呼び出しの間隔)は世界の規則から外します。

習慣は、眠っている間の整理で本人の文として書く形を目標にし、それまでは「同じ場面で N 回」のコードの習慣をつなぎにします。初めの習慣は、世界を組むときにペルソナから書きます(MD-40)。相手への印象は文で持ち、温かさ・有能さ・親しさの数は計器としてだけ取り出します(MD-06)。

予定は「予定の棚」に置きます(題 4・11-09)。勤務や授業のような縛りのある予定は時刻の項、柔軟な予定は「〜になったら」の項です。本人の言葉にある中身だけを決め、活動の終わりの手がかりに外の合図と満たされた・飽きたを足し、見直しは前提が崩れたときと浮かんだときに行います(MD-57〜MD-62)。時刻ちょうどには起こさない方向で、細部は研究(R-149)の後に決めます。

考えかけは 1 人 1 本で、記憶と同じ式で薄れ、再開するかは本人が決めます。忘れ方は ACT-R の基本の活性を既定にする方向です。行為には「依頼から本人の言葉、差分、返った知覚まで」の鎖を付けます。

まだ決まっていないのは、心の口の細部(9-2)、心と体の接続、本人の状態ベクトルの形、感情の中身、第 2 世代の速い判断の担い手(A-07)です。この章に印を付けた食い違いは、A-07 のほかは 11-09 までに決着か仮決定になりました。
