- 理由の出どころは、11-01 までが各回答の理由の文、11-02 以降が[壁打ちの記録](../../reference/wallbounce-record-2026-11-02_05.md)です。記録に無い理由は「理由の記録なし」と書き、推測で埋めていません。
- 11-09 から書いた項目の理由の欄は、記録にある文献と研究の理由を先に書き、ユーザーの言葉は「ユーザーの提案の 1 つ」として添えます(CLAUDE.md §2-4 の 11-09 の追加・U18)。ユーザーの言葉だけが根拠の決定は、その旨を書きます。
- 後の決定が前の決定を直した所は新しい方だけを正にし、古い方は出どころとして並べました。直しが見つからない所は「食い違い」の印を付け、片方を選んでいません。11-09 からは見出しの印に、決着・仮決定・未決(どの段の題か)・11/14 に決める、のどれかを書いています。〔11-16 で直した=「11/14 に決める」は、11/14 の確認の壁打ちがまだ済んでいないので「壁打ちの後に決める」と書く(返事その 8 §8)。記録が「候補として登録」と書く決定(MD-74・MD-75)は、見出しの印も「候補として登録」と書く〕
