## 1. 種別ごとの状況の事実の文(A07)

### 1-1 記録が決めたこと(2-53)

「あなたは〇〇です」の一行を 9 種別すべてで外し、置かれた状況の事実を 1〜2 文で書く。ラベルの語(通勤者など)は使わない。よく来る人(定期来街者)には何も書かない(土地勘は記憶の側)。古い一行は腕 #7 として残す。

今の B1 は `[B1 種別] あなたは{kind}です。`(`foundation/text/templates.py:685`)。語の表は 5 語だけ(`:184`)なので、種別 5〜8 は `perception/renderer.py:1740` で「来街者」に落ちる。数える役 B の報告 §2-1 では、ランの 5,000 体のうち 2,163 体(43%)が「あなたは来街者です」と見ている。本当の来街者はそのうち 765 体。

### 1-2 共通の形【案】

- **見出しは `[B1 状況]`**。理由: 記録の「置かれた状況の事実」に合う。「種別」はラベルを指す語で、事実の行の見出しに合わない。ほかの候補は `[B1 自分]`・`[B1 事情]`。
- **文体はです・ます体**。今の凍結の文(B0・B1)にそろえた。記録の例は「〜がある」の常体なので、です・ます体に直して使う。
- **「このあたり」**は舞台の範囲を指す。記録の例「このあたりの土地勘はない」に合わせた。ほかの候補は「渋谷」(B0 の頭の文「渋谷の街にいる」と合う)。
- **「職場」「学校」「家」**を使う。応答の対象の語(`自宅 / 職場 / 学校`=`templates.py:546`)と同じ語にそろえると、住民が対象の欄にその語を書きやすい。日課の側が対象の語の行き先を解いているので(報告 §2-2)、場所の名を書かなくても行動は成り立つ。
- **人の名・番号・数は差さない**(今の型の範囲)。理由は §1-5。

## 3. 囲いの形(A72 の ①②)

記録 2-54・2-62・2-65 の土台: 世界の中の文は**中身を変えない**。機械にだけ効く (i) 区切りの記号・ブロックの見出し・出力の欄の語だけを、区切りとして効かないようにする。中身の濾しはどこにも置かない((ii) の機械に向けた言葉も消さない)。外すのは ①② を入れるのと同時。

### 3-1 今の渡し方(調べた結果)

- 判断の呼び出しは system と user の 2 つのメッセージで送る。描画の本文を B0 とそれ以外に割り(`llm/fleet.py:287-295` の `split_system_user`・`runtime/systems/decide.py:176`)、艦隊の `_payload` が OpenAI 互換の `messages` にして、`chat_template_kwargs={"enable_thinking": …}` を付ける(`llm/fleet.py:1082-1109`)。チャットの型を当ててトークンに直すのは vLLM のサーバーの側。

**順序**: ① 本文を NFKC で正規化(`canonical_whitespace` と同じ)→ ② 上の表の置き換え → ③ ①-a の崩し(本文には区切りの字面がもう無いが、描画の最後でまとめて掛ける)→ ④ チャネルの枠の切り詰め(本文の末尾から削る。今と同じ)→ ⑤ `〔出どころ〕「…」` で包む。包むのは切り詰めの後なので、閉じの「」は必ず残る。

命令の言葉(「と書け」)は残る(濾しを外したので)。形だけが本物と違う。
