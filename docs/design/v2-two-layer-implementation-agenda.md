## 1. 段 1 の決め(契約・パーサ・文面)

### 1-1 語彙 v3(`VOCAB_VERSIONS = ("v1", "v2", "v3")`・既定 `DEFAULT_VOCAB_VERSION` は **v1 のまま**=ライブラリの既定バイト不変。CLI の既定は段 3 で v3 に切り替える)

| 種別横断(11 語+なし) | 役割語(11 語) | 外す(v3 で受理しない) |
|---|---|---|
| 移動・乗車・購入・食事・会話・退去・通報・手伝い・断る・就寝・**並ぶ**(役割語から横断へ)・**なし**(安全弁・失敗しない) | 接客・補充・開閉店・価格改定・発車・停車・放送・遅延報告・計画改訂・指示・撮影 | **待機・休憩・降車** |

- **行動コードは動かさない**(テープ・checkpoint・`last_action` の実体): 移動 0・乗車 1・降車 2(**欠番**)・購入 3・待機 4(**欠番**)・会話 5・退去 6・通報 7・手伝い 8・断る 9・休憩 10(**欠番**)・就寝 11・役割語 12..23(並ぶ は既存コードのまま・種別だけ横断へ)・食事 24・**なし 25**(新設 `ACTION_WORD_NONE = "なし"`・`NONE_ACTION_CODE = 25`)。
- `resolve._APPLY_BY_VOCAB["v3"]`: なし=時間経過だけ(旧 待機 と同じ適用関数を流用・失敗しない)。待機・休憩・降車の分岐は v1/v2 のまま残す(v3 では語が来ない)。**未定義(`UNDEFINED_ACTION`)の落ち先は v3 では「なし」**(v1/v2 は 待機 のまま)。
- **休憩の効果の確認**: 内受容の回復が「休憩」の適用に依存していれば、v3 では「なし」+活動「休む」で同じ回復が起きるように `_apply_none` に**回復を持たせない**(回復は時間経過の規則へ寄せる)。依存があれば本書 §5 に書いて親に報告(挙動を黙って変えない)。
- `VOCAB_COMPAT["v3"]`: 待機/休憩 → なし(v3 の語彙で v1 のテープを読む向き)/ v3→v1 の向き: なし → 待機。降車は欠番(対応なし)。`compat_word` の向きを両方持つ(`to_version` 引数は既存)。
- 段0 辞書 v5(`SYNONYMS_V5`・語彙 v3 専用・v1〜v2 の表は不変): 行為側だけ。**待機・休憩・降車へ写していた行を全て「なし」へ**(待つ・様子を見る・観察・眺める・確認・調べる・休む・座る・横になる・降りる・下車 …)。散歩・ぶらつく・歩き回る・うろつく・見る → **なし**(活動は自由文なので写像しない=写像先が無い語は なし)。辞書版 `undefined-synonyms-v5`。
- 語彙数の上限 `VOCAB_LIMIT_PER_KIND` の assert は **v3 の表では掛けない**(D-92 (a): 門は「契約行+エンジン効果+台帳行+テスト」)。v1 の assert は残す。

### 1-2 出力形 v3(行動契約書 §1 の改版・2 行形を保つ)

```
理由: <40 字以内・1 文>
行動: <11 語+なし から 1 語> 対象: <店名 / 店のカテゴリ / 人ID / 自宅 / 職場 / 学校 / 駅名 / あたり / なし> 活動: <いま何をして過ごすか・10 字以内 / なし> まで: <到着 / 相手 / N分 / HH:MM / 次の予定>
```

- `CANONICAL_LABELS_V3 = ("理由", "行動", "対象", "活動", "まで")`。**「ひと言」は v3 の必須ラベルから外す**(受理はする=別名表に残す・会話プロトコル側で使う)。`format_ok`(v3)=5 ラベル揃い+行動語が取れた。`strict_format_ok`(v3)=5 ラベルを正準表層だけで(別名なし・位置引数なし)。v1/v2 の判定は **1 バイトも変えない**。
- 位置引数(ラベル省略)の順序も 理由→行動→対象→活動→まで。
- **「まで」の解釈**(`parse_until(text) -> Until`): `到着`→ARRIVAL / `相手`→PARTNER / `(\d+)\s*分`→MINUTES(n)(上限 480・超過は 480) / `(\d{1,2}):(\d{2})`→CLOCK(hh,mm)(24 時制・過去なら翌日) / `次の予定`→NEXT_SCHEDULE / 空・その他→**DEFAULT(60 分・expedient・指紋)**。`Until` は `kind`(IntEnum)+`value`(int)。
- **「対象: あたり」**: `parse_target` で `TargetKind.CELL` の派生でなく **新種別は増やさず** `Target.kind = ITEM_CATEGORY, category="あたり"` に `wander=True` の印(dataclass に 1 欄追加・既定 False=v1/v2 で不変)。エンジンは `wander` で分岐。
- 「対象: 自宅/職場/学校」は既存の対象ヒント(home/work/school)に写す(`TARGET_HINTS` を v3 で「表層→ヒント」に拡張・v1/v2 不変)。
- B0 v3(`b0_system(intent_mode, vocab_version="v3", role_words)`): 出力規約の行動断片を上の形に・**対象欄の説明語を例示から外す**(D-89 (i)(b)=「物のカテゴリ」「セルID」と書かせない)・活動と まで の 1 行説明を足す(「活動: は世界を変えない過ごし方。まで: は次に考え直す目安。途中で驚くことがあれば早く考え直す」)。共有静的の予算(B0+役割語行+B1+B3 ≤ 750 tok)を守る=超えるなら親に報告。役割語行は 11 語に(並ぶ を横断へ移した分)。`b0_sha256("v3")` を指紋として記録。
- テンプレの `template_sha256`(v1)は不変。
