## 3. 集計と、AB7 で実際に効いた行

| 分類 | 行数 | AB7 open seed 1 での通過行数(概数) |
|---|---|---|
| なし | 61 | 行く 20,508・買う 548・移動する 等 |
| 軽微 | 8 | — |
| 対象の損失 | 17 | 探す 212・探索 86・帰る 等 |
| **意味の損失** | **14**(食べる・飲む・様子を見る・知らせる・対応する+観察系 9) | **食べる 12,594・飲む 44・観察 80** |
| 合計 | 100 | 段0 通過 34,272 行(93.0%) |

- 段0 を通った 34,272 行のうち、**意味の損失を伴う行が約 12,700 行(37%)**。ホワイトリスト腕(vocab)ではこの損失は起きない(LLM が 24 語から選ぶ)ので、**vocab と open の分布差(JSD 0.052)の大半は辞書の写像方針の産物**であり、「入口を開けば分散が増える」の反証(第201)はこの意味で読む。
- **対象の損失 17 行**は数値には出ないが、探索・帰宅・通勤の**目的地の情報を LLM から受け取らずにエンジンが決めている**=分業の線(意思は LLM・帰結はエンジン)を辞書が越えている箇所。C9 の設計で `TARGET_HINTS` を持つかを決める。

## 4. 政策(本書で宣言するもの・数値不変)

1. `SYNONYMS` は **expedient ではなく語彙政策**として扱う。行の追加・変更は (i) 本書の表に分類と根拠を書く (ii) `SYNONYM_TABLE_VERSION` を上げる (iii) manifest に版が載ることをテストで固定する——の 3 点セット。
2. **★の行(意味の損失)は、段2 の裁定(D-71・オフライン案)と AB7-c(辞書改訂腕)の起草材料**とする。順序は 食事(食べる・飲む・未定義「食事」)→ 観察・注意(観察系 9 行・見る・近づく)→ 知らせる/対応する。
3. 「対象の損失」は C9(位置幾何)の設計ラウンドで `TARGET_HINTS` の要否と一緒に決める。
4. 本書は v0。AB7-b(ヒント腕)の結果が出たら、ヒント提示で★の行の通過数がどれだけ減るかを §3 に追記する。

「知らせる→通報」の D-57 への寄与は**計測済み・なし**(c7-day-4 生表層: 知らせる 0・通報 640)。「対応する→接客」の誤写像の実例は未確認(役割語率 0 のため出現していない)。分類は親の判断(expedient)で、ユーザーの再分類を妨げない。
