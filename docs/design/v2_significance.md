# 第1章 何がわかるのか(科学的知見)

## 1.1 探索型研究質問の発見候補と、それぞれの「既知と未知」

研究質問「現実を再現した空間上でLLM駆動のエージェントを動かすとき、どのような現象が生まれるのか」に対し、
先行研究の到達点と未達を対にして発見候補を挙げる。

| 発見候補 | 既に示されたこと[実証] | v2で初めて測れること |
|---|---|---|
| 語彙の専門化・新語 | 2択naming gameで規範収束・集団バイアス・ティッピング(Ashery+, Science Advances) | **開放的な言語環境**での自然な語彙分化(v1は1日で造語ゼロ=週月スケール+開放環境が必要という定量的根拠を既に持つ) |
| 社会構造・組織 | Project Sid(**解析は500体**)で役割分化。ただし著者自身が「de novoの社会的革新は不可」と明記・宗教はシード注入(**第210 訂正・出典 arXiv 2411.00114**: ①「the results below are analyzed using a single 500-agent simulation」=1000体超のランは計算制約で解析されていない ②§5.2「we establish an existing set of laws」・§8.3の3条件に法無しは無い=**足場なし条件はSidが走らせていない**=実証ではなく空白) | 足場なしで制度が**自己実行するかしないか**——先行が**走らせていない**条件そのもの(v2は失敗も観測対象として設計) |
| 集合的虚構 | ハルシネーションのクラスタ内共有(Takata+)が最接近例。無シードの虚構創発の査読研究は無し | 40万体・実世界文脈での共有信念の形成・分岐の全数記録 |
| 信念・デマの分岐 | OASISが分極・herdを再現/虚偽の優位拡散は実SNSで実証(Vosoughi+, Science) | **人づて/SNS/場所の三経路が同居する世界**での経路別寄与(v1の×125/×57はその第一号) |
| ペルソナドリフト | 2体・8ラウンドで有意ドリフト(Li+, COLM 2024)。多体長期はn=25の予備報告のみ | **40万体×週スケールの長期一貫性の分布**(全LLM入出力保存が直接可能にする) |
| Price of Anarchy | 交通実データでEmpirical PoA=1.11-1.22。**LLM集団での直接測定は未占有** | 渋谷の実ネットワーク上でLLM社会のPoAを初測定できる可能性 |
| world-changer仮説(k*) | v1で「世界改変ツールは開かれているが行使は極少」を定量化済み | 発火条件の系統的探索(アンサンブル+介入の一級化が前提装備) |

**[推測]と明記する部分**: 上の右列は「測定装置として可能になる」ことの主張であり、「面白い現象が実際に
生まれる」ことの保証ではない。v1の教訓(造語ゼロ・world-changer未出現)はむしろ**未発火の定量化こそが
成果になりうる**ことを示している。

## 1.2 二重検証軸(believability vs accuracy)で何が検証可能になるか

分野の系統レビュー(Larooij & Törnberg, Artificial Intelligence Review 2025)は、生成的ABM 35本の大半が
**表面的believabilityとLLM自己評価の循環**に依存すると批判した **[実証]**。また人間実験との同一プロトコル比較は
「マクロは再現するがミクロ(個人の行動分散・条件付き戦略)は乖離する」ことを示している(de Arruda+)**[実証]**。

v2の検証設計はこの批判に正面から応える構成を既に持つ **[構成]**:

- **accuracy軸(マクロ)**: 現実整合アンカー台帳(v1で37本・出典/holdout分割付き)との照合を北極星KPI化。
  信頼区間つきのマクロ統計照合。
- **accuracy軸(ミクロ)**: 行動分散・意思決定規則レベルの照合を分離して報告(de Arruda型の実務的手本に従う)。
  分散不足が出た場合は主張を集団レベル定性パターンに限定する(方法論に明文化済み)。
- **believability軸**: 主要根拠にはしない。物語的な妥当性はChronicle(実文遡及)で提示するが、検証の言語は
  常にaccuracy側に置く。
- **創発主張の防御**: 「訓練コーパスの記憶と観測上識別不能」批判(Barrie & Törnberg)と、PIMMUR監査
  (39研究の89.7%が妥当性原則違反・61%のプロンプトが結果を先決め)**[実証]** を先回りするablationを完了条件に
  している(方法論Phase 4)。**[推測]** 渋谷という実在舞台は訓練データ漏洩リスクを高める側面があり、
  訓練コーパスに存在しない条件下での予測を最低1本用意することが強い防御になる。

## 1.3 既存アプローチが原理的に到達できないもの

- **ルールベースABM**: 自然言語・常識の数式/ルール化が構造的課題(Wu+)であり、「無害に見える仮定の選択が
  モデルの含意を根本的に変える」(Flache+, JASSS)**[実証]**。意味内容が伝わる口コミ・説得・解釈の分岐は
  ルールでは書けない。
- **Generative Agents系(小規模)**: 25体2日で数千ドル(Park+自認)**[実証]**。稀少事象・分布の裾・規模依存の
  現象に統計的検定力が届かない。実際、OASISは**100体ではherd効果が発生せず10,000体で初めて出現**することを
  実測した **[実証]** — 規模は贅沢ではなく、現象の存在条件である。裾の統計にはClausetの経験則(裾サンプル
  n≥50・母集団はその数十〜数百倍)が定量的根拠を与える **[実証]**。
- **観測データのみの計算社会科学**: モデル化の価値はEpstein "Why Model?"の語彙で言う「トレードオフ・不確実性・
  感度を開示して政策対話を規律する」ことにあり **[実証]**、反実仮想(同一世界で条件だけ変える)は観測研究には
  原理的にできない。v1のA/B対照(世界側の出来事=救急6件が一致し、社会側だけが×125動いた)はその最小実例 **[構成]**。

# 第2章 何ができるようになるのか(獲得する能力)

## 2.1 アンサンブルによる未来可能性テスト

LLM社会シムはプロンプトの微細変更で結果が最大76ポイント動くことが実測されており(TRAILS)**[実証]**、
「1本のランは主張にならない」が分野の合意に向かっている。v2は**N本ラン比較(アンサンブル)を第一優先の
設計対象**として持つため、この規律を製品仕様として備える側に立つ **[構成]**。できるようになること:

- **what-if条件比較**: 同一世界・同一seed群で介入だけを変えたN本の分布比較(介入は記録される実験条件として
  一級化・provenance付き)。事前サンドボックス評価という枠組み自体はPolicySim(ACM Web Conf 2026)が
  論文化済み **[実証]** で、v2はそれを都市スケールの開放行動空間で実装する。
- **都市・制度デザイン比較**: 歩行者流だけでなく「情報がどう回るか」「制度が使われるか」を含む比較。

## 2.2 環境限定デジタルツインの反実仮想改変

買い手が実在することは実績で示せる **[実証]**: 歩行者シミュは商用市場として確立(MassMotion=NY地下鉄実案件・
PTV Vissim/Viswalk)。国内ではPLATEAU UC25-07(2027国際園芸博の人流シミュ・横浜市/相鉄協力)の実証評価で
「複数ケース検証の容易性」肯定が13%→100%に跳ねた — 買い手が払っているのは予測精度でなく**合意形成の道具**
としての価値である **[実証+構成]**。v2の反実仮想改変(建物・サイネージ・営業時間・規制)は、
既存製品が持たない「群衆流+情報伝播+経済行動の同居」で差別化する **[構成]**。

## 2.3 観測射影レイヤー(L-OBS/L-REC)による復元限界の測定

現実側では「観測データから内面・属性がどこまで復元されるか」の上限が個別に実証されている **[実証]**:
FacebookのLikesのみで性的指向88%/政党85%(PNAS 2013)・時空間4点で95%の個人特定(Sci Rep 2013)・
15属性で99.98%再識別(Nat Commun 2019)・LLMによる属性推論はtop-1 85%で人間の1/100のコスト(ICLR 2024)。
しかしこれらは全て「正解が部分的にしか分からない実データ」上の測定である。

**v2は全員の内面という完全なground truthを持つ**ため、「サイバー空間の観測者が取れるデータの射影(L-OBS)
から、内部状態がどこまで復元できるか(L-REC)」を**正解つきで**測定できる。この構成の先行例は本調査の範囲で
見つからなかった **[実証(未発見)]** — プライバシー保護技術・匿名化・データ最小化の効果を、実在個人を
一切傷つけずに定量評価するテストベッドになりうる **[構成]**。(デュアルユース面は第3章で正面から扱う。)

## 2.4 広告・情報伝播・群衆安全の検証能力

- **情報伝播**: プレバンキングの効果は540万人露出の実広告実験で+5%と実測済み(Science Advances 2022)**[実証]**。
  v2はその「どの経路で・誰に・どの順で」を全数記録の上で分解できる **[構成]**。
- **広告**: 広告業界はABMを買収する程度に本気である(WPP/GroupMによるSandtable買収・Kantar Link AI)**[実証]**。
  ただし合成調査には強い批判(silicon sampling原著者の否定・実務採用率8%)がある **[実証]** ため、
  v2は「個票を当てる」市場ではなく**相互作用の帰結・介入の相対比較**の市場に立つ **[構成]**。
- **群衆安全**: 明石歩道橋事故の判例は主催者・警備・警察に「事前に想定していたか」の立証責任を作った **[実証]**。
  渋谷区はハロウィン対策に年間数千万〜1億円規模を反復支出している(報道ベース)**[実証]**。
  雑踏の物理だけでなく「情報(SNSでの呼びかけ・デマ)が群衆をどう動かすか」まで含む事前検証は、
  既存の歩行者シミュ製品にはない **[構成]**。

## 2.5 事業として成立しうる提供形態(根拠の強い順)

| 顧客 | 形態 | 実在アンカー[実証] |
|---|---|---|
| イベント主催者・自治体・鉄道 | 案件型検証+リプレイ納品(「事前に想定した」の証跡) | 明石判例・渋谷区の反復支出・PLATEAU調達実績(UC25-07) |
| プラットフォーム・規制当局 | 介入サンドボックス(アルゴリズム・施策の事前評価) | PolicySim・EU AI Act 57条の規制サンドボックス義務 |
| 広告主・代理店 | メッセージ/施策の相対比較 | GroupM/Sandtable・Kantar Link AI(ただし合成調査批判が直撃する領域と認識) |
| 保険 | 群衆事故リスクの引受根拠 | **[推測]** 公表事例は見つからず=根拠最弱と明記 |

冷静な参照点として: 合成調査のトップ企業Aaruは$1B評価に対しARR $10M未満 **[実証]** — 期待先行の市場であり、
収益主張は保守的に置く。研究シム→事業化の実例はSandtable(広告)とImprobable(ゲーム基盤→防衛・UK MoD
£8.3M実績)**[実証]**。

# 第3章 世界にどんな影響を与えうるのか

## 3.1 学術への影響

- 計算社会科学は2009年の分野宣言以来「観測ビッグデータ」を主軸にしてきたが、生成的ABMのレビューは検証の
  未成熟(35本中22本が主観評価)を指摘する **[実証]**。v2は「検証設計で評価される時代」に、忠実度回帰検収・
  ablation完了条件・マクロ/ミクロ分離報告という**再現可能性の側の実装例**を提供する **[構成]**。
- 判例結晶化ループ(先行が**判例概念を持たない**領域・**第203 訂正・出典 arXiv 2510.24442 本文の親一次確認**)・LLM集団のPoA実測(未占有)・観測射影の復元限界測定(未発見)は、
  それぞれ単独で論文貢献になりうる **[構成]**。
- モデルの価値を予測に限定しない立場(Epsteinの16の非予測的目的)に立てば、v1で実証した「未発火の定量化」
  (造語ゼロ・world-changer未出現)も知見であり、v2はそれを設計仕様に転換した最初の例になる **[構成]**。

## 3.2 産業への影響

都市計画・交通(合意形成の道具としての人流+情報の統合シム)、広告・マーケティング(相対比較サンドボックス)、
政策(規制サンドボックスの計算機版)への影響経路は第2章の通り。加えて**ゲーム/メタバース産業への逆方向の
貢献**がありうる **[推測]**: v2はゲーム産業の技法(ECS/リプレイ/LOD/スマートオブジェクト)を輸入して
作られるが、「40万体が自分で考える世界」の運用知見(LLM NPCの予算配分・長期一貫性・記憶統合)は
ゲーム側にまだ存在せず、逆輸出になりうる。

## 3.3 メタ安全保障の枠組みで語れるか — 語れる、ただし正確に

- 日本の国家安全保障戦略(2022年閣議決定)は「認知領域における情報戦」への対応強化を明記し、
  情報流通プラットフォーム対処法(2025年施行)・AISIのレッドチーミング手法ガイド等の制度枠組みが動いている **[実証]**。
- 影響工作研究の標準枠組み(Goldstein+ 2023)は緩和策を「モデル構築→アクセス→配信→**信念形成**」の4段階に
  分解するが、最終段「信念形成」は実験が最も難しく手薄である **[実証]**。**v2は信念形成の段を、実在の人間を
  一切実験台にせずに実験室化する装置**と位置づけられる **[構成]** — v1のA/B対照(誤情報×57)はその最小実証。
- ただし誠実さのために: 影響工作の**実世界効果**は限定的という強い実証がある(ロシアIRA露出と態度・投票変化に
  有意な関係なし・露出の70%が上位1%ユーザーに集中/Eady+, Nat Commun 2023)**[実証]**。したがって
  **シム内の「拡散量の差」を現実の「被害量」として語ってはならない** — v2の主張は常に「脆弱性の構造と
  相対比較」であり「実害の予言」ではない。

## 3.4 負の影響とリスク — 正面から

1. **世論操作への転用可能性**: LLMの説得力は条件次第で人間を上回り(討論での合意獲得オッズ+81.2%/
   Nat Hum Behav 2025)、post-trainingで最大51%増幅され、**説得力が上がるほど主張は不正確になる**
   (Science 2025)**[実証]**。「influence-as-a-service」の実運用も検出済み(Anthropic)**[実証]**。
   v2が「どの介入がどの層に効くか」を精緻化するほど、その知見は攻撃側にも価値を持つ — これは希釈せずに
   認めるべきデュアルユースである。
2. **プライバシー・監視技術としての側面**: 都市データ収集はSidewalk Labs Torontoの中止が示す通り社会的反発の
   実績がある **[実証]**。v2の全LLM入出力恒久記録は説明責任の資産であると同時に、**それ自体が保護・管理対象の
   負債**である **[構成]**。L-OBS/L-RECは防御研究の装置だが、同じ装置は攻撃の練習台にもなる。
3. **結果の過信**: 最も現実的なリスクは悪用より**「良性の過信」** — 較正範囲外の数値が留保なしに政策語彙へ
   移ること **[構成]**。金融のGaussian copula・疫学モデルの政策論争という実害の先例がある **[実証]**。

**緩和の5点セット(設計・運用への内蔵を提案)** **[構成]**:
①生ログ非公開+統制済み集計出力のみ公開(Five Safes/TREの標準形)②生成物への来歴署名(C2PA型・実データとの
機械可読な分離)③ODD/TRACE準拠の文書公開+段階公開(GPT-2方式)④攻撃条件の再現手順は非公開・防御側指標のみ
公開(DURC型用途審査を内部に設置)⑤全ランの前提・不確実性・感度の開示(Saltelliの5規範)。
「世界そのものがプロダクト」という構想は、**この5点を内蔵している場合にのみ**学術・政策の既存規範と接続可能
である **[構成]**。

## 3.5 長期像 — 「世界そのものがプロダクト」の先

世界モデル中心のAI開発言説(LeCun・Genie 3・World Labs・NVIDIA Earth-2)と国家級デジタルツイン
(EU Destination Earth・Virtual Singapore・東京都2030年ロードマップ)は資本と政策の主流にある **[実証]**。
しかし**それらは全て物理・気象・都市形状のツイン**であり、社会的行動そのものを都市規模で再現する国家級
プロジェクトは本調査で確認できなかった **[実証(未発見)]**。

**[推測]**(根拠の弱い長期展望としてそう明記する): 物理のツインが「街の形」の合意形成を変えたように、
社会のツインは「制度と情報環境」の合意形成を変えうる — 条例・イベント計画・プラットフォーム施策が、
実装前に「考える住民のいる渋谷」で試される世界。その時に問われるのは精度そのものより、第1章の検証規律と
第3.4節の緩和セットを保ったまま運用できるか、である。市場規模の推計値(デジタルツイン市場2025年$35.8B等)は
ベンダー推計の幅が大きく、方向性の指標としてのみ扱う **[実証(推計の乖離)]**。
