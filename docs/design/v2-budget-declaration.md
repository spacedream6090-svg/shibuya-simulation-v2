# v2予算宣言表(R1・Phase 0ゲート要素)

> **状態: 承認済み(2026-09-01 ユーザー認可・全決定は仮の原則の下で)。これによりPhase 0ゲート完了。**
> W1(壁時計8h/シミュ日)は9/10艦隊ベンチで必ず改訂する仮値であることをユーザー了解済み。改訂はdelta方式(規則3)。
> 根拠資料: v2-methodology.md(性能予算をCIゲート化=散漫化pitfallの処方箋)・v2-redesign.md §0(v1実測)・§4(ORCA-GPUアンカー)・§10c(観測容量実証)・LLMサービング答申。
> 原則: 予算は**打ち切り(cap)ではない**。憲法1により計算制約は解像度(LOD)で吸収する——予算は「どの解像度で粗くするかを宣言する枠」であり、世界規則に漏れてはならない。

## 7. 運用規則

1. **機能追加の門前条件は二重**: パターン照合1行(台帳)+予算行(本書)。どちらか欠けたらマージ不可。
2. 予算は**忠実度プロファイルごと**に持つ(比較するラン同士は同一プロファイル=同一予算)。
3. 本書の改版はdelta方式(旧値を残し日付つきで新値追加)。**黙って数値を変えない**。
4. 予算超過が観測されたら: (a)解像度宣言で粗くする(憲法6) (b)予算を宣言改訂——のどちらか。**capの静かな挿入は禁止**(憲法1)。
