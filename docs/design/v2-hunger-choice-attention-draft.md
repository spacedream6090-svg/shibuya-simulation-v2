## §0 要約

- **D-118 空腹**: 体ごとの必要量は食事摂取基準 2025 の式(基礎代謝基準値 × 体重 × 身体活動レベル)✓で、体重は国民健康・栄養調査の性年齢別分布から抽選。**消費は EER を 1 日で使い切る形に固定し、活動の種別の METs は相対比にだけ効かせる(K1 (c))**。v0 の「基礎代謝 × METs」は日平均 1.36 METs で EER の 0.78 倍にしか届かない [計算]。空腹感は**食事で 0 に戻る変数**(食後の消費 kcal)で決め、日次の収支は別の変数で閉じる(K8)。摂取は第13表の朝/昼/夕の**比**(0.19/0.34/0.47)を EER に掛ける(K7=紙上で収支が閉じる唯一の形)。LLM には粗い語 4 段だけ。**照合量は社会生活基本調査の食事行動者率と欠食率だが、同じ統計を較正に使わない**(K6)。
- **D-119 System 1.5**: 「データで較正した古典的選択モデル(分布を返す)」に賛成。活動選択は社会生活基本調査の公表統計だけで作れる Tanimoto 型の事前分布に状態の乗数(宣言)、ただし**乗数を掛けた後に時間帯ごとの定数で周辺分布を事前分布に戻す**(L7・空腹の二重計上を避ける)。店選びは満足化+習慣でハフ型は入れないが、**願望水準を空腹の語で動かし走査順に決定論の揺らぎ**を入れて one-hot を避ける(L8)。層ごとの判断の割合を SOFAI 形式で毎 run 記録。「古典だけ」腕は mock 方策の置き換えだが**旧 mock v3 は凍結版として残す**(L5)。
- **D-117 活動→知覚**: 通勤 vs 散策で視認率を直接比べた一次は無い。乗数は**全部 1.0 を既定候補**にし(M2 (b))、Hyman の錨は「通話/スマホ操作中」(下向き 0.49)と「連れとの会話」(上向き 1.39)に付け替える。乗数は p_see にだけ掛け B2 の行数には掛けない(M4)。Gehl の 7 倍は環境(店先)の効果であって活動の種別の効果ではない。

### 1-2 案(v1)

1. **消費(K1 (c))**: 毎 tick の消費 = **EER/1440 × METs(活動の種別)/ 基準日の平均 METs**。EER = 基礎代謝基準値(性・年齢)× 体重(国民健康・栄養調査の性年齢別分布から W16 の性・年齢で抽選)× PAL ふつう 1.75(+個人差 SD)。基準日の平均 METs は宣言する 1 つの定数(座位中心の 1 日=**1.364** [計算・§1-2b])。こうすると**基準日の日総量は EER に一致**し、METs は「歩いた日は多く・座っていた日は少なく」の相対比にだけ効く。v0 の (a)「基礎代謝 × METs」は感度腕に降格(§1-2b の理由)。
2. **活動の種別 → METs**(二層の `activity_kind` と就寝から): 就寝 0.95・その場/在店 1.3・目的地つき移動(歩行) 3.5・あたり(散歩) 3.0 [サブ値の版差の中間・expedient・感度腕で 2012/2024 の両版]。(c) では**比だけが効く**ので版差の影響は v0 より小さい。
3. **2 つの変数(K8)**: `since_meal_kcal`(食後の消費 kcal・float32・**食事で 0 に戻る**・軽食/飲料はその kcal を差し引く)=**空腹の語の源**。`energy_balance`(日次の 摂取 − 消費・float32)=**日次センサスの源**(憲法4)。1 変数(累積欠損から語)だと夜間の欠損が朝食後も残り「空腹」が 1 日の 7 割になる [計算・§1-2b]。
4. **摂取(K7)**: 食事の大きさは **EER の比**で決める: 朝 0.19・昼 0.34・夕 0.47(第13表の比 [サブ値]→[計算])。飲食店の食事=時間帯の比(昼 0.34/夕 0.47)・軽食(コンビニ等)=0.12・飲料=0.03 [expedient]。**第13表の絶対値(男 30〜39 で計 2,007 kcal)を摂取に使うと消費(EER)との差 800 kcal/日が毎日積み上がり収支が閉じない** [計算]。在店の間に摂取(持続の終わりに)。
5. **LLM に見せる語(B5)**: `since_meal_kcal` を「1 食分」(= EER/3・体ごと)で割った比で 4 段: 満腹(< 0.25)/ ふつう(0.25〜0.75)/ 空腹(0.75〜1.5)/ とても空腹(≥ 1.5)。数値は見せない。閾値をまたいだときだけ注入(R3-2 の閾値注入・`INTERO_UP_EDGES` の 3 段と同じ形なので change_detect の入口はそのまま)。区切りは expedient(先行に「欠損→空腹感」の関数は無い=R-46 §7)。
6. **食べる時刻**: 習慣(社会生活基本調査の性年齢・就業状態別の食事の時間帯=System 1 の予定)・カレンダー(昼休み=「まで: 次の予定」)・周囲(B2 に飲食店・B4b に食事中の人)を **System 1.5 の特徴量**に。System 2(LLM)には粗い語しか届かない。**K6 (i) なら習慣の特徴量に社会生活基本調査を使わない**(§1-3)。
7. **収支の閉じ方**: 体ごとに日次で 摂取 − 消費 = Δ貯蔵 を日次センサスへ。基準日で 摂取 = EER = 消費 なので**3 食の日は紙上で閉じる**(差は当日の METs と基準日の差=歩いた日は負)。朝食を抜いた日は −0.19 EER が残る=翌日に持ち越す(貯蔵)。体重の変化は扱わない(Hall 2011 の時定数は日より桁で長い [サブ値])。
8. **切替口**: `--hunger-model {v1,energy}`(既定は energy に切り替える=checkpoint が動く・版の台帳)。v1(全員 +1/30 分・−4/購入)は感度腕として残す。energy の中でも `--energy-rate {eer,bmr}`(K1 (c)/(a))を腕にする。

### 2-2 案(v1)

1. **口**: `Chooser.probs(candidates, context) -> np.ndarray`(分布)。D-101 (ii) の入出力の契約はそのまま。(G) logprob は同じ口の別実装として GPU 後に比べる。
2. **活動の選択器(ActivityChooser)**: 事前分布 P(活動 | 時間帯 15 分・曜日・性・年齢階級・就業状態)を社会生活基本調査の行動者率から(Tanimoto 型)。**K6 (i) なら食事の行は事前分布に含めない**(食事は §1-2 6 の門で先に決める)。状態の乗数 m(場所の種別: 駅/店/街路)・m(予定: 次の予定まで N 分)・m(直前の活動)を掛けた**あと、時間帯ごとの定数 c_t で周辺分布を事前分布に戻す**(L7・A3): 乗数は「誰がその活動をするか」を動かし「何人がするか」は事前分布のまま。**乗数は指紋として宣言し感度腕**。行為の候補は二層の契約語、活動は固定の粗い活動類型(社会生活基本調査 20 種 → v2 の活動の種別への対応表)。
   - A3 の注: 時刻別の行動者率には空腹の効果が既に入っているので、空腹の乗数を掛けたまま正規化すると二重に数える。K6 (i) では食事が事前分布に無いので空腹の乗数は食事の門にだけ効き、c_t は食事以外に掛かる。K6 (ii) では c_t で周辺を戻すと較正集合の周辺は**構成上一致**する=照合はホールドアウトでしかできない(A1 と同じ帰結)。
3. **店の選択器(DestinationChooser)**: 候補=エンジンが絞った営業中・条件一致の POI(D-114)+**記憶にあって評価の良い店**([新草案](v2-memory-wom-internet-draft.md) D-120)。**(i) 記憶にある最近の店が候補にあれば確率 p_h で選ぶ**(習慣) **(ii) 残りは B2 の可視順(W8 の視点数の降順)の満足化**。距離減衰の項は持たない。p_h は expedient(Rhee & Bell の約 3/4 を上限の目安・再推定は Foursquare Tokyo が候補 [サブ値])。
   - **A4(L8)**: v0 の満足化は同じ景色を見た全員が同じ店に入る one-hot で `Chooser.probs` の分布としても退化する。2 つの直し: **(α) 願望水準を空腹の語で動かす**(Simon 1956 の可変願望水準): とても空腹=最初に見えた飲食店(条件なし)/ 空腹=営業中+予算内 / ふつう=さらにカテゴリ一致 or 記憶の評価 ≥ 0 / 満腹=食事の門を通らない。**(β) 走査順の揺らぎ**: 条件を満たす店 k に P(k) ∝ exp(−rank_k/τ)(rank は可視順・τ は宣言・τ→0 で one-hot・τ→∞ で一様)。抽選は run_salt の決定論(blake3)。τ は expedient(初期 1.0・感度 0.5/2.0)。**距離項は入れない**(rank は可視順であって距離ではない=ただし可視順は距離と相関する=宣言)。
4. **層の分担と記録**: System 1(予定・習慣の既定=呼ばない)→ System 1.5(選択器)→ System 2(LLM・驚きのときだけ)。manifest に **時間帯 × 層の判断数と割合**(SOFAI 形式)と起床入口別の内訳。
5. **「古典だけ」腕(A6)**: `--system2 off`(LLM 0 呼)= 新しい方策 `classical`。**旧 mock v3(`MockLLM(form="v3")`・golden 02bd0312)は凍結した 1 版として残す**=checkpoint の差分の切り分け用(mock v3 → classical の差が「選択器が足したもの」)。指標は受入表(在圏・行動分布)+LLMob の 4 指標(SD/SI/DARD/STVD の JSD)。LLM 腕との差が「LLM が足すもの」。
6. **決定論**: 抽選は run_salt の決定論(ActivitySim の乱数流と同型 [サブ値])。

### 2-3 較正データ

- 事前分布: 社会生活基本調査の公表統計(e-Stat・取得はライセンス台帳と一緒)。個票(二次利用申請)や PT 個票は**先に聞く**案件(R-47 §10-5)。
