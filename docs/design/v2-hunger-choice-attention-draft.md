## §0 要約

- **D-118 空腹**: 体ごとの必要量は食事摂取基準 2025 の式(基礎代謝基準値 × 体重 × 身体活動レベル)✓で、体重は国民健康・栄養調査の性年齢別分布から抽選、減り方は活動の種別に METs を写す。LLM には粗い語 4 段だけ。食べる時刻は習慣・カレンダー・周囲を System 1/1.5 の特徴量に。**照合量は社会生活基本調査の 15 分刻み「食事」行動者率と欠食率**、kcal は副次(錨が二重に食い違うため宣言つき)。
- **D-119 System 1.5**: 「データで較正した古典的選択モデル(分布を返す)」に賛成。活動選択は社会生活基本調査の公表統計だけで作れる Tanimoto 型(遷移+継続時間)を事前分布に、状態(空腹の語・場所の種別・予定)の乗数は expedient として宣言。店選びは**満足化(見えている順に最初に条件を満たす店)+習慣(最近の店)**でハフ型は入れない(反対証拠 CoPB は記録)。層ごとの判断の割合を SOFAI 形式で毎 run 記録。**「古典だけ」腕**(System 2 を 0 呼)は mock 方策の置き換えであり未踏の対照。
- **D-117 活動→知覚**: 通勤 vs 散策で視認率を直接比べた一次は無い。看板の注視ゲート p_see を活動の種別で条件づけ、乗数は expedient(Hyman の通話中 25.0/51.3% を下向き、Gehl の停止 7 倍を上向きの錨)として感度腕で測る。

### 1-2 案

1. **体の状態**: `energy_deficit`(kcal・float32・0 以上)を registry に 1 欄。毎 tick の消費 = 基礎代謝(kcal/分)× METs(活動の種別)。基礎代謝 = 基礎代謝基準値(性・年齢)× 体重(国民健康・栄養調査の性年齢別分布から W16 の性・年齢で抽選・個体差 SD を足す)。**PAL は使わない**(活動の種別ごとの METs が同じ役を担う。1 日平均の METs が PAL「ふつう」1.75 に近いことを mock で確認=整合検査)。
2. **活動の種別 → METs**(二層の `activity_kind` から): 就寝 0.95・その場/在店 1.3・目的地つき移動(歩行) 3.5・あたり(散歩) 3.0 [サブ値の版差の中間・expedient・感度腕で 2012/2024 の両版]。
3. **食べた量**: 購入/食事の対象カテゴリで 3 段: 飲料 100・軽食(コンビニ・おにぎり等) 350・食事(飲食店) 700 kcal [expedient・食品成分表の品目から親が代表値を作る=空欄]。在店の間に摂取(即時でなく持続の終わりに)。
4. **LLM に見せる語(B5)**: 欠損を「1 食分」(= EER/3・体ごと)で割った比で 4 段: 満腹(< 0.25)/ ふつう(0.25〜0.75)/ 空腹(0.75〜1.5)/ とても空腹(≥ 1.5)。数値は見せない。閾値をまたいだときだけ注入(R3-2 の閾値注入と同じ)。区切りは expedient(先行に「欠損→空腹感」の関数は無い=R-46 §7)。
5. **食べる時刻**: 習慣(社会生活基本調査の性年齢・就業状態別の食事の時間帯=System 1 の予定)・カレンダー(昼休み=「まで: 次の予定」)・周囲(B2 に飲食店・B4b に食事中の人)を **System 1.5 の特徴量**に。System 2(LLM)には粗い語しか届かない。
6. **収支の閉じ方**: 体ごとに日次で 摂取 − 消費 = Δ貯蔵 を日次センサスへ(憲法4)。体重の変化は扱わない(Hall 2011 の時定数は日より桁で長い [サブ値])。
7. **切替口**: `--hunger-model {v1,energy}`(既定は energy に切り替える=checkpoint が動く・版の台帳)。v1(全員 +1/30 分・−4/購入)は感度腕として残す。

## §2 D-119 System 1.5 = データで較正した古典的選択モデル

### 2-1 錨(R-47・親検収)

| 先行 | 事実 | v2 での使い方 |
|---|---|---|
| 東京都市圏ACT [サブ値] | MNL+生存時間(1 分単位)・東京 PT 2018 で推定・約 100 万標本 | 最も近い日本の先行(入手は目的限定) |
| Tanimoto 型(Yamaguchi & Shimoda 2014)[サブ値] | 社会生活基本調査の**公表統計**(時間帯別行動者率+継続時間の平均/SD)だけで遷移確率と継続時間分布を作る | **活動選択の事前分布はこれで作れる**(個票なし) |
| Simon 1955/1956 [サブ値] | 順に調べて最初の満足解を選ぶ・願望水準は見つけやすさで上下・空腹の閾値で探索を始め**見えた**食物へ | 店選びの骨格 |

| CoPB ✓ | 「integrating CoPB with gravity model can reduce the token cost by 97.7% and achieve better performance」 | **反対証拠**(重力=ハフ型が LLM の場所選びに勝つ)。ただし全 POI 既知が前提。ユーザー決定「ハフ型は入れない」は維持 |

### 2-2 案

1. **口**: `Chooser.probs(candidates, context) -> np.ndarray`(分布)。D-101 (ii) の入出力の契約はそのまま。(G) logprob は同じ口の別実装として GPU 後に比べる。
2. **活動の選択器(ActivityChooser)**: 事前分布 P(活動 | 時間帯 15 分・曜日・性・年齢階級・就業状態)を社会生活基本調査の行動者率から(Tanimoto 型)。状態の乗数 m(空腹の語)・m(場所の種別: 駅/店/街路)・m(予定: 次の予定まで N 分)・m(直前の活動) を掛けて正規化。**乗数は指紋として宣言し感度腕**(公表統計では識別できない=R-47 §1)。行為の候補は二層の契約語、活動は固定の粗い活動類型(社会生活基本調査 20 種 → v2 の活動の種別への対応表)。
3. **店の選択器(DestinationChooser)**: 候補=エンジンが絞った営業中・条件一致の POI(D-114)。**(i) 記憶にある最近の店が候補にあれば確率 p_h で選ぶ**(習慣) **(ii) 残りは B2 の可視順(W8 の視点数の降順)に最初に条件を満たす店に 1**(満足化)。距離減衰の項は持たない。p_h は expedient(Rhee & Bell の約 3/4 を上限の目安・再推定は Foursquare Tokyo が候補 [サブ値])。
4. **層の分担と記録**: System 1(予定・習慣の既定=呼ばない)→ System 1.5(選択器)→ System 2(LLM・驚きのときだけ)。manifest に **時間帯 × 層の判断数と割合**(SOFAI 形式)と起床入口別の内訳。
5. **「古典だけ」腕**: `--system2 off`(LLM 0 呼)= mock 方策の置き換え。指標は受入表(在圏・行動分布)+LLMob の 4 指標(SD/SI/DARD/STVD の JSD)。LLM 腕との差が「LLM が足すもの」。
6. **決定論**: 抽選は run_salt の決定論(ActivitySim の乱数流と同型 [サブ値])。

### 2-3 較正データ

- 事前分布: 社会生活基本調査の公表統計(e-Stat・取得はライセンス台帳と一緒)。個票(二次利用申請)や PT 個票は**先に聞く**案件(R-47 §10-5)。
- 状態の乗数: 識別できない=宣言+感度腕。GPU 後に LLM 腕との比較で調整する道もあるが、それは「LLM を教師にする」ことなので別途判断。

### 2-4 空欄・リスク

- 社会生活基本調査の 20 種と v2 の行為/活動の対応表(親が作る)。渋谷の来街者(非居住)の時間帯分布は全国の公表統計と違う=D-115 の来街時刻の錨(PT2018)と突き合わせる。
- 満足化の「見えている順」は W8 の可視順に依存=可視の欠陥がそのまま店の集中に出る(宣言)。

### 2-5 順序

(1) 口(`Chooser`)と「最寄り」既定=D-114 の回で入る (2) 社会生活基本調査の統計表の取得と対応表 (3) ActivityChooser(事前分布+乗数)と DestinationChooser(習慣+満足化)を mock 方策に接続=「古典だけ」腕 (4) 層の記録列 (5) 受入表で v1 mock・古典だけ・LLM 腕を並べる(GPU 後)。

## §3 D-117 活動の種類が知覚を変えるか

### 3-1 錨(R-47 §5・すべて [サブ値])

- 通勤 vs 散策で**広告の視認率を直接比べた一次は日本・海外とも無い**(空欄)。
- Hyman ら 2010: 歩行中に道化を見た率 通話 25.0%・単独 51.3%・音楽 60.7%・二人連れ 71.4%。Gehl 2006: 活発な店先で停止・活動が 7 倍。Hillnhütter 2022: 頭の動き +71%。東京メトロ 2025: 渋谷駅集中展開の自己申告注目率 78.9%(視線計測ではない・目的別なし)。

### 3-2 案

- 看板の注視ゲート p_see(第232・既定 1.0)に**活動の種別の乗数**を掛ける: 目的地つき移動 0.5 / あたり 1.0 / 在店 1.0 / その場 0.75 / 会話中 0.5(Hyman 比 ≈ 0.49 を下向き、Gehl を上向きの目安)。B2 の可視物の行数も同じ乗数で丸める。**乗数は expedient・指紋・感度腕**(0.25〜1.0)。
- LLM が「気にする:」(Concordia の mask)を書く形は、2 ラベル追加の書式率を測ってから(3 つ目のラベル)。
- 計測: 看板の注視数と AD 腕(AB6b/AB6c)の指標を活動の種別で層別。
