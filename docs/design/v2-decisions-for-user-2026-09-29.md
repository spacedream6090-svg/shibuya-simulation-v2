## 2. 設計に効く発見(第284〜309)

1. **node 幾何の重なり**(第309): 既定の node 幾何では歩く体が全員ノードの座標に重なるため、群れ歩き・同行の計器は「同じノードに重なった体」を数えていた(組の 95〜99.7% が距離 0・edge 幾何で 0.290 → 0.022)。→ D-122 の S 層(連続位置)を先に入れる根拠。群れの計器は edge 幾何で読むと宣言(Q153)。
2. **起床入口「体」の主因は疲労**(第291・Q37): 空腹の跨ぎ 9,209 に対し疲労の下げ跨ぎ 16,182。D-111 の予想(5〜8%)は空腹だけでは届かない。
3. **実 LLM は会話で店を語らない**(第297・Q57): 8B テープで会話の発話に店名 1%・評価語つきほぼ 0。語彙 v3 に発話本文が無いので口コミの伝播は自然には起きない。
4. **関係辺の容量 15 が初期網を削る**(第301・Q111): 会話の辺は初期辺より必ず強く、満杯の体が話すたびに職場の辺が永久に落ちる。
5. **H5(属性構成)は写像の定義で桁ごと動く**(第303・Q123): kind 0.35・area 2.52・KDDI 1.66・現実同士のフロア 6〜10 倍=「定義を宣言して読む」量。
6. **expedient の感度ゲートは既存の記録では 1 行も満たせない**(第306〜308・D-44): 105 行とも入力側の JSD が無い。66 行は再構築で測れる(見込み 25 分)・17 行は対照を定義できない。
7. **古典的選択モデルは食べ過ぎる**(第292・Q48): 門を起床ごとに引くので約 20 回/体/日=収支 +176 kcal。時間あたりのハザードに直す案。
8. **範囲内の自宅に食べる口が無い**(第291・Q35): 居住者・従業者 509 体の朝食欠食 83%。範囲外の食事の 81% は既定時刻由来(Q34)。
9. **W6 の subcat をエンジンは読まない**(第284): W6 再生成で checkpoint は動かなかった=D-96 の予想の訂正。
10. **5 エリアのピーク時刻は退出の歩きでは動かない**(第302): sim 9〜11 時 vs KDDI 18 時=主因は W17 の来街者の時刻形状(PT 2018 待ち)。
