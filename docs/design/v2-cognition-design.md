## §3 昇格条件(T0/T1/T2・決定)
```
S(e) = w1·surprise + w2·stake + w3·novelty + w4·recent_failures + w5·social_exposure   # 全項エンジン算出・LLM採点なし
T0 -> T1 : 習慣の前提条件(場所・時刻・所持)が崩れた(決定論)
T1 -> T2 : S(e) >= θ_imm(即時) OR Σ_日 S(e) >= θ_cum(累積=GAの150に相当)
T1 -> T0 : 同一(文脈, 行動)対が n 回連続一致(習慣化)
θ_imm, θ_cum := 予算方程式の解 s.t. 昇格率≈0.02回/体/日 かつ ablationで主要指標不変
```
- 先行: FrugalGPT(カスケード・最大98%コスト減)/RouteLLM(2倍超のコスト減)/較正済み不確実性(31%削減)/GA(重要度和150・2-3回/日)。閾値の値は移植不能。
- **w1..w5・θ・n は全てexpedient**(感度試験±50%で移動分布・経済フロー・情報伝播が動かないことを示す。動くなら閾値が世界を駆動=不採用)。

## §4 記憶U1ハイブリッドの細部(決定)
```
score(m|q) = w_r·A(m) + w_i·importance(m) + w_v·relevance(m|q)     # w=(1,1,1)初期=expedient
A(m)       = ln( Σ_j (Δt_j+1)^(−d) )                               # ACT-R base-level(べき法則)
d          = 0.5(生エピソード) / 0.25(T2統合済みgist=24hブースト)
importance = S(e)の離散化(LLM採点なし=呼数0)
relevance  = cos(Ruri-v3-30m埋め込み)   ※自由文由来の記憶のみ。エンジン生成事象はID一致で引く
```
- 根拠: GAの指数減衰0.995/時(24hで0.887)は忘却曲線の再現(節約率 20分0.547/1h 0.455/9h 0.380/**1日0.408**/2日0.418/6日0.344/31日0.041)と形が合わない=初期急落+緩やか=べき法則。**1日時点の上向きの跳び**(睡眠固定の示唆)を「就寝時内省で統合したgistのd=0.25」で表す(ブースト量はexpedient)。
- 埋め込み: **cl-nagoya/ruri-v3-30m**(256次元・37M・Apache-2.0・JMTEB 74.51・最大8,192tok)。プレフィックス「検索文書: 」「検索クエリ: 」固定。**GPUはLLM専用・埋め込みはCPU/ONNX int8の別プロセス**(スループット実測1本が採用条件=未計測)。
- **バイト予算: 6.1KB/体**(構造化3.0KB+12本×260B)・40万体で2.4GB(既決7.7KB/3.1GBから削減)。
- 日次内省(就寝同期・§6既決): 最大3 gist/晩・ヘッダ(ID群)+自由文1-2文・24hブースト付与・生イベントは構造化のまま保持し自由文だけ落とす。
