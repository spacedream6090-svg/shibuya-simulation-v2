## §0 存在の連続性の運用(10-12 追加)

> 〔改訂(第328・2026-10-12・ユーザー決定)〕新設。方針は [決定台帳 §3c 存在の連続性](v2-redesign.md)、出典は [指示書 10-12](v2-wallbounce-decisions-2026-10-12.md) §1-3・§2 の 1・§4-7・§3 の表。本書の 09-07 版の記述(§1〜§7)と食い違う所は、各節に印を付けて残す。

- **背骨の文(K2・CLAUDE.md §3)**: 世界の状態と集約と破れない法則はエンジン(コード)。知覚・記憶の強さ・変化の検出は System 1(コード)、日常の判断は判断モデル、会話とよく考える判断は LLM。行動を止めるのは物理と、現実でも物理的に止める仕組み(鍵・改札など)だけ。人の手続きはコードに書かず住人の知識から出し、足りない世界の部品は構築側が版ごとに足す。
- **System 1(コード)**: 文ではなく、数値と ID で「何か変わったか」だけを扱う(変化の検出)。環境の入力は体(物理)・知覚(System 1)・浅い記憶(親しみ)に常に流れ、考えていない間も影響を受け続ける。記憶の強さも System 1 のコードの数値で持つ(MR-0。LLM には数値を見せず、言葉と中身の粗さで見せる)。経過時間は System 1 が実感の長さに直し、丸めた言葉で本人に渡す(§4-1 の「経過時間の実感」)。
- **判断モデル**: 変化があったときに呼ぶ。「短い状況 + 問い + 候補」を渡し、分布を受け取る。LLM を呼ぶかは判断モデルが決める(候補の 1 つが「よく考える」=少し考える/じっくり考える)。入口は変化の検出 + カレンダーの時刻(DM8)。「次に見直すのはいつ頃か」を理由なく毎回聞かない。
- **LLM**: 必要なときだけ呼ぶ。「常に入力」は「常に LLM」ではない。**会話の返事は、返すかを判断モデルが決め、中身は LLM**(§4-7 の前提)。
- **心の連続性**: 本人の状態(記憶・予定・関心の的・今の活動・体の状態)に持つ。LLM は呼ばれるたびにそれを読む。計算は「何かあった人だけ」でも結果は同じにする(TM5。体の変化は次に段階の境目を越える時刻を予約し、「全員を毎回見る版」と一致することを受入の条件にする)。
- 注意(未決): 考えていない間の影響(気分など)は係数が増えやすいので、錨のあるものから入れ、曖昧なものは段階の言葉にする。気分・感情の状態を持つかは、まだ決めていない(指示書 10-12 §9-1)。

## §3 昇格条件(T0/T1/T2・決定)
```
S(e) = w1·surprise + w2·stake + w3·novelty + w4·recent_failures + w5·social_exposure   # 全項エンジン算出・LLM採点なし
T0 -> T1 : 習慣の前提条件(場所・時刻・所持)が崩れた(決定論)
```

## §4 記憶U1ハイブリッドの細部(決定)
```
score(m|q) = w_r·A(m) + w_i·importance(m) + w_v·relevance(m|q)     # w=(1,1,1)初期=expedient
A(m)       = ln( Σ_j (Δt_j+1)^(−d) )                               # ACT-R base-level(べき法則)
d          = 0.5(生エピソード) / 0.25(T2統合済みgist=24hブースト)
importance = S(e)の離散化(LLM採点なし=呼数0)

```
- 〔改訂(第328・2026-10-12・ユーザー決定)〕上の式の +1 はやめる(→ 10-12 で上書き)。**時刻は秒で持ち**、t が 0 にならないよう最短の符号化時間を置く。ACT-R の折衷形(直近の数回は本当の時刻・古い分は近似)。d=0.5 は ACT-R マニュアルの推奨値。境目 τ は現実のデータで較正する(expedient)。忘れる速さだけ約 15% のばらつきで人ごとに変える(Sense 2018)。手がかりはその場の手がかり(ID の一致)が既定で、Ruri-v3-30m と 130m は腕。人も記憶の一つとして同じ器・同じ式で扱う([指示書 10-12](v2-wallbounce-decisions-2026-10-12.md) §4-6 MR-0・MR1・MR2・MR5・MR8。仮決定・B 群と E7 の後に見直し)。重みの w=(1,1,1) と importance の扱いは 10-12 の指示書に記述が無い=要確認(親)。
