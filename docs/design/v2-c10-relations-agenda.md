## 0. 材料が変えた前提

1. **関係は「枠を作る」話ではなく「枠を使う」話**: 予算行 M5「関係(疎表現)≤6 KB/体」は 09-02 に宣言済みで実装ゼロ。k=15 辺×6 B=90 B/体(39 万体で 35 MB)は M5 の 1.5%。
2. **会話は c7-day-4 で 4,040 呼(0.149%)・成立 410 セッション/日**(サブ再計算・親未確認。D-33/D-68 の「0.04%・0.02%」は前のラン)。会話クラスの呼は 30 万あるのに「会話」と答えたのは 0.56%=**起点が無い**(知人ゼロ・招待の相手は「セル内最小 id」=D-31)。
3. **「待ち合わせ」は未定義行動として一度も出ていない**(c7-day-4 上位 29 語・AB7 36 語とも)→ D-71 の自成長では出てこない=**人が通す(決定台帳 09-17 の affordance 行)**。v1 には `with`/`meetup` があったが配線されず「各自が独立に目印を選ぶので集まらない」失敗の記録。
4. **関係の種はデータにある**: 世帯 27,404(世帯内ペア 16,207=人口の 4.2%・続柄なし)・組織 9,872(全ペア 2,789 万・76% が 15 人以下)・学校 53 セル。**同行者データは W17 にも PT にも無い**。

## 4. 決定(第210・ユーザー 2026-09-17)

- **R1〜R14 = 親推奨どおり**(C9 の後に実装)。
- **R9′(ユーザー案)= 関係を「会話・感情・状態から取り出す抽出エンジン」で作る**: 関係辺の更新を、出来事の回数(R9)だけでなく**会話の中身**から行う。親の整理(自己修正 3 原則と両立する形): (i) **ラン内**=会話の LLM 応答に構造化 1 行「関係: +1/0/−1・気分: 語」を持たせ、parser が読んで辺の強さを更新(**呼数 0 増**・決定論=応答が同じなら同じ更新・指紋=尺度の定義)(ii) **ラン後**=日次のオフライン抽出(T2・温度 0)が会話記録から要約と感情の印を付け、辺の「種別」(友人/同僚/常連)の昇格候補を出す=D-71 の裁定バッチと同じ位置(中間の輪)(iii) 「感情」の状態欄は現状の内受容 3 変数(空腹・疲労・温冷)に無い=**新しい状態の種類**なので、C10 では辺に付く印(会話の気分)に留め、個体の感情欄は C11(記憶・習慣)で決める。**内受容と関係の橋**: 会話の成立に気分を効かせるかは C11。
- 追加の判断: R9′ (i) の尺度(3 値か 5 値か)と (ii) の抽出プロンプト版は指紋として宣言。
