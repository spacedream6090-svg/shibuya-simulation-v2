## 1. 決定の記録(仮決定)

### 題 9-1 の追加
1. **他人から見えるもの**:世界の側に置くのは本人の属性の写しではなく「見た目の欄」(年格好・服装・制服や名札・連れの有無・話す言葉など)。他人が読んでよいのは見た目だけで、本人の内側の事実(本当の年齢・職業・性格)は読めない。棚卸し A07 はこの線の上の問題として仕分ける。性別や民族の見え方をどこまで欄に入れるかは倫理の方針(F2)で決める(未決)。
2. **本人の知識の線**:本人の知識=本人の記憶と生い立ちから来るもの。LLM が事前学習で持つ知識は本人の知識ではない。漏洩の検査(A1-6)は「本人が知らないはずのことを言った率」として心の計器にも数える。
3. **主観の関係を 3 つに分ける**(すべて心の内側):
   - 個人への印象:短い文+温かさ・有能さ・親しさの数+確信度。会うたびに更新し、寝たときに書き直す(今の `memory_impression.py` の器)。
   - 相手の今の内面の推測:気分・意図の短い推測+確信度+「相手はこう返すだろう」の予測。予測と実際の食い違いで直し、数分で消える(先例:ToM-agent 2025)。
   - 一般化した印象:属性の概念ごとに温かさ・有能さの数+確信度+出会った数。初期値は本人の生い立ちから作り、出会いで少しずつ動く。関わりが増えた相手は個人への印象へ移る(連続体の模型 Fiske と Neuberg 1990)。個人として見直すかは心の調停(題 9-3)で決める。
   - **BIAS map(Fiske ら 2002 の 4 象限と感情・行動の対応)はコードの規則にしない**。住民の振る舞いが同じ向きになるかを確かめる錨(知識の検査)にだけ使う。
   - **偏りは消さずに測る**:その集団にだけ多く出る語・文から集団を当てられる率・応答の多様さ・人の回答の分布との距離(先例:The Prompt Makes the Person(a) 2025)。C5(不平等の軸の計器)へ。ペルソナの書き方(「あなたは〇〇です」の直接形/インタビュー形式)は比べる腕の候補。

### 題 9-4 L4 の予算
**(b) 世界の規則から外す+(d) ランの安全装置としてだけ持つ**。
- 心は状態だけで「考えたい」を決め、runtime は全部実行する。計算が追いつかなければ透かしで世界が待つ(EVE の Time Dilation と同じ)。
- 1 ランの呼数か費用の上限を超えたら、ランを止めて状態を保存する。住民の判断は変えない。
- 費用を抑える手段は、心の調停の規則(何を判断モデルで受け、何を熟考へ上げるか)で、宣言して腕で比べる。
- (c) 本人の認知の容量(熟考に限りがある)は、題 9-3 の答申の後に検討。
- arbiter の残りの役目の行き先:不応期 → 心の「考え中」と集中の度合い(9-3)/昇格と縮退 → 心の調停(9-3・題 4)/同時刻の順 → 題 2 の鍵。v3 では arbiter は心の調停と runtime の推論の口に分かれて消える。
- 費用の見込み:按分を外すと呼数は 1 人 1 日 6.94 → 12〜16 前後(E 系列の幅)。E 系列の費用の表に、この前提を明記する。

### 題 9-2 の方針(口の形の前提)
心の口は「保存・復元・更新ができる、中身の見えない状態の塊」として作る。口は、刺激を入れる/考えを依頼する/状態を保存する・戻す/アイドルの一歩を進める/読み出す(気分や印象の数を外へ)、の形。中身が文の記録(今)でも、本人のベクトル・睡眠での更新・状態を持つ系列模型・本人の重みでも、runtime を作り替えずに差し替えられるようにする。文の日記はどの段でも監査のために残す。口の細部(読むもの・取り出すもの・出力の方式)は壁打ちで決める(未決)。

## 2. 研究(答申・Opus 5.5・番号は親が振る・比較の表まで・推薦は書かない)

その 4 §5 の 2 本(持続する状態ベクトルと操舵/活性をテープに残す道)に加えて 3 本。

1. **睡眠での固定と本人のベクトル**:
   - 文の記憶 → 本人のベクトル:文脈の蒸留(その日の出来事を毎回プロンプトに入れなくても同じ答え方になるようにベクトルを学ぶ)の先例(Askell ら 2021・Snell ら 2022 など)。相補的学習系の説(McClelland ら 1995)との対応。
   - 熟考 → 判断モデルの習慣:その日に LLM で決めたことを判断モデルの側の本人のベクトルへ写す形。第 1 世代(判断モデルの入口に本人用のベクトル)と第 2 世代(Qwen の活性+ヘッド・ベクトルは 1 本)の比較。
   - ベクトルの形の比較:入口だけ(prompt tuning・Lester ら 2021)/各層(P-tuning v2・Liu ら 2022)/操舵(学習なし)/LoRA。性格・好み・判断の癖の保持と、事実の容量。
   - vLLM で人ごとに違う学習済みのベクトル(入口の埋め込み・各層の前置き)を差し込んで推論できるか。版と機能の名を一次で。
   - 誰をいつ更新するか:本人の状態(その日の驚き・感情の動き)から決める形の先例。
   - 費用の見積り:1 人あたりの学習の計算量(前向きだけ/軽い学習/重い学習)と、更新する人の割合ごとの GPU 時間。親の粗い見積り(A5000 実効 40 TFLOPS・1 人 1,000〜2,000 トークン)では、割合 10%・軽い学習で 1 シミュ日 約 20 GPU 時間(昼の推論 約 63 GPU 時間の約 3 割)。世界の夜の空いた GPU で回せるか。
   - 5070 で小さく試す計画:数十人を数日回し、更新あり/なしで人格と感情の一貫性を比べる(計器はその 4 §5 の活性の列・TIPI の再回答など)。
2. **継続学習と持続する内部状態**:文の側で学ぶ流れ(Generative Agents・MemGPT・Mem0・Evo-Memory など)と、重みや状態の側で学ぶ流れ(test-time training・Titans・状態空間模型・継続の微調整・睡眠での固定)の比較。状態を持つ系列模型(RWKV-7・Mamba 系・混成)の日本語の能力・状態の大きさ・保存と再開の口。Qwen3-8B から替えずにできる範囲と、替えないとできない範囲を分ける。
3. **社会的認知の錨**(題 9-1 の追加の材料):印象の形成(連続体の模型)・ステレオタイプの内容の模型の日本での値・心の理論の計測・LLM の社会的な偏りの測り方。錨として使える実験の値を表に。
