## §0 構築原則(全段階に適用)

1. **決定論**: 各段階=純関数(入力ファイル群+パラメータ→出力)。出力ヘッダに `input_hash`(入力SHA256連結)・`param_hash`(canonical JSON)・`stage_version` を書く。乱数は `hash(seed, stage_name, entity_id)` から派生(段階追加が既存出力を変えない)。浮動小数の丸めは出力仕様(building_heights round_m 0.1・tran_lod3 quant 0.05)。
2. **版の凍結**: OSM attic日(2025-04-01・駅出入口/追加地物は2026-09-07=別attic・manifestに2本併記)・PLATEAUメッシュ・センサス年度(R3)・ODPT fetched_at・GTFS feed版・アメダス日付・PT=2018・混雑率=2024年度・e-Stat取得日。
3. **実行時ネットワーク禁止**(ODPT usage_noteを全ソースへ適用)。構築はオフライン一括、ランは資産のみ読む。
4. **出典表示**: OSM「© OpenStreetMap contributors (ODbL)」・PLATEAU「Source: PLATEAU (MLIT)」(渋谷区分のライセンス種別=サブ答申待ち)・ODPT定型文・国交省/e-Stat=政府標準利用規約2.0・気象庁PDL1.0。**ODbL share-alike**: 世界データ台帳(セル・可視性・騒音場)はOSM派生DB=公開形態は法務レーン(既存答申)で決めるまで**内部利用+集計値公開のみ**(D-W21)。
5. **holdout規律**: KDDI形状5指標・スクランブル通行量・訪日訪問率/滞在時間・商圏シェアは構築に**一切使わない**(総量1スカラーのみ)。構築コードがholdoutファイルを開いたらCI失敗(ファイル名パターンで検査)。
6. **カタログ写像**: 各段階の出力は世界カタログ57クラスのどれを埋めるかを宣言し、W18で被覆指標(C,Q,D,V,R)+X+孤児を自動算出→manifestへ。
7. **expedient登録**: 段階ごとに expedient を列挙し感度試験(対照ラン)を紐付ける。感度試験なしのexpedientは出荷不可。
8. **LLM呼は3段のみ**(W14看板・W15セル静的文・W17スケジュール生成)。いずれも1回限り(I1初期化予算)・温度とseedを固定・出力をバイト凍結。
