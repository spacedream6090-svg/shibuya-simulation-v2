# 作り方: 本体の .venv で `python -m pip freeze --exclude-editable` を回して出た 48 本を、`名==版` で全部書いた

#   Linux の印で評価して、無いと確かめた(この 48 本の閉包は Linux で 47 本=colorama を除いた全部)。

#   python -m pip install pip==26.2.1
#   python -m pip install -r requirements-lock.txt
#   python -m pip install --no-deps -e .
#   python -m pip check
#   python tools/ci/check_lock.py
# 上げ方: 手で 1 行だけ上げない(依存の組が崩れる)。上げる版を決めたら、その版を入れた venv で `pip freeze --exclude-editable`
#   から全部を書き直し(環境の印も付け直す)、byte-check の全構成を今の基準と比べ(tools/bytecheck/README.md)、
#   版上げの履歴(docs/ops/version-history.md)に 1 行足す。pip と Python の版を上げるときは、下の 2 行と ci.yml の
#   `pip==`・`python-version` も一緒に直す(tests/tools/test_ci_check_lock.py が食い違いを落とす)。
